# 学生学习空间

状态：2026-10-11 按用户“开始做吧”实施个人讲义第一版。学生自己的资料→应试/整体理解讲义→保存、重开、笔记与导出已接通并在隔离本地环境验证；完整课程授权、练习/错题、学习路径及项目实践仍待后续批次。依据：[学生学习](../apps/lingzhi/docs/功能设计/学生学习.md)；研究：[学习 Agent 与历史界面调研](../apps/lingzhi/docs/研究/学生学习Agent调研.md)。本变更不取代[教师生成链路收敛](生成链路收敛.md)。

## 本次差异

本变更的教师端、学生端均属于灵知（`apps/lingzhi`），不修改启智（`apps/qizhi`）。学生端独立服务系统学习、期末备考和项目实践；教师端继续服务备课。共享适用的材料、题目、保存和任务能力，页面按各自目的组织。右上角可作为过渡入口，教师临时预览与正式学习空间分别命名与处理。

复用现有资料解析、Qwen、讲义写作、内容块、公式、图表、目录及概念关系能力，参考 `9ae4cc7a`（3 月）与 `ffd2bad7`（8 月初），不恢复旧生成引擎。个人材料具有独立正文责任，不复制教师课程 Store；生成任务仍归原 TaskManager。个人讲义 AI 已在 2026-10-12 补齐，完整课程 AI、练习和错题流程沿后续批次接通。

## 个人讲义第一版

- `/study/:materialId?` 使用真实身份和本人材料库；本地账号仅在显式 `LINGZHI_LOCAL_STUDY_AUTH=true` 且未配置启智鉴权时开放，服务端保存密码散列和会话散列。启智已验证学生仅获准进入个人材料 API，教师 API 保持原角色限制。
- 原始资料进入本人命名空间，使用原 MaterialRepository 解析。选择真实标题范围，设置应试/整体理解、起点、阅读时间和要求；冻结原件哈希、正文与来源位置。概念关系只接受冻结证据引用，再调用原共用讲义写作能力，不生成隐藏教案或 PPT。
- 同一请求幂等创建本人材料及真实 task ID；正文块、章节、资料、修订和笔记独立持久保存。任务索引裁剪不承担材料保存责任。重启将活动个人任务留在暂停态，失败和暂停由本人主动继续，完成章节不重写；关闭页面只停止观察。
- 连续阅读复用目录、概念定位、重点框、公式和折叠解答；中文/英文操作同步。笔记关联当前材料修订，保存事件不宣称掌握；支持 Markdown 与原始资料下载。迟到回复和草稿按本人身份隔离。

验证边界：相关后端 42 项、前端 104 项及构建通过；隔离本地 `qwen3.8-27b` 对同一份线性代数资料生成应试/理解两版，各两章。规划阶段先遇到 JSON 围栏、来源与输出小节 ID 混淆，修正传输解析和输入投影后主动继续；无自动重跑或语义审核。中文浏览器验证阅读、公式、概念、来源和笔记重开；英文界面同样核对。个人任务不进入旧教师任务读取/控制或批量清理，伪造旧身份头不能操作本人任务。本轮证明真实生成与个人持久化闭环，未完成专业内容评议、学校联合身份实测或生产部署。实验资料、账号和截图均保存在仓库外。

## 个人图解与AI助手

2026-10-12 按用户“优化完成”补充个人讲义图解及右侧助手。二维向量 `vector_plot` 与矩阵消元 `matrix_steps` 扩展原共享注册表到 46 型，讲义提示合同更新为 `course_prompt_v39`；坐标、完整矩阵及行操作随原正文保存，使用同一 SVG 渲染和 Markdown 链。个人生成在原写作请求中按冻结来源选择学科图解，不新增图表规划、模型语义审核、改写或自动重跑。

阅读页默认 AI 助手，保留笔记、概念和来源切换；普通提问跟随章节，选段绑定同一正文块和材料修订。私人对话在原 `AITeacherRepository` 中使用带资源类型的本人/材料/修订命名空间，原教师课程会话键不改变。回复共用 Qwen 和 TaskManager，幂等问题保存一对消息，流式片段持久化；关闭只停止观察，重启暂停，主动继续原任务。教师任务接口、课程广播和批量清理不能触及个人任务。回复不改讲义或笔记，不产生掌握事件；未收到确认的提问草稿及请求 ID 按本人隔离保留。

验证边界：相关后端 73 项、前端 123 项及类型检查/构建通过，覆盖原教师会话、个人上下文与隔离、幂等提问、保存重开、流式片段、显式继续、任务裁剪和公式表格。原生图形检查补充了横纵尺度一致、完整矩阵元素以及判断菱形内的长标签布局。默认构建目录清理遇到 Windows 文件占用，改用独立输出目录完成同一构建，未覆盖正在运行的应用。

真实模型/API：本地 `qwen3.8-27b` 完成两章图解应试讲义（10/9 个正文块），正文包含向量、矩阵消元和解的分类三种图；原有讲义与笔记继续保留。原讲义的向量提问及新讲义的消元提问均返回完整回复和共享图解，会话重开仍是原来的一对消息；第二个真实学生账号对材料、会话、导出和回复继续均得到 404，伪造旧身份头得到 401，旧教师任务入口不能读取私人任务。输出图表的结构与来源锚点经共享解析器检查，以同一 SVG 引擎做原生图形核对，未追加模型语义审核或宣称专业内容评议通过。

失败与恢复：讲义前三轮遇到本地模型连续 90 秒无输出；日志显示解码速度停滞，机器可用内存约 1 GB。无新输出的续作还暴露了清空旧片段的问题，本轮已修复并加入专门回归。确认无活动任务后，仅调整隔离实验模型的上下文与缓存占用，再明确继续同一 task ID，最终两章完成；没有自动失败重跑，未停止其他应用或改接模型服务。实验参数未改变仓库默认配置。

浏览器/生产：本轮浏览器实看仍受此前工具 URL 策略拒绝限制，组件中英文检查和原生 SVG 图形核对不作为完整页面截图验收；学校联合身份、生产部署与专业内容评议未完成。原第一版验收与本轮证据分开，账号、实验资料、模型输出、截图和构建文件继续留在仓库外。

推送前整合了主分支同期的分讲知识树、读取投影与图表面板改动，产品状态保留双方记录。整合后再次通过后端 106 项、前端 190 项和构建，覆盖个人助手、教师会话、共享阅读、概念与身份；重启隔离后端后，已保存讲义与会话仍可读取，第二个学生仍不能访问。未为代码整合重复调用模型，也不将其他批次的业务状态改记为本功能完成。

## 执行顺序

| 批次 | 源码落点与工作 | 依赖和可交付条件 |
| --- | --- | --- |
| S1 正式学习入口与现有闭环 | 现有 `router/index.ts`、`App.vue`、教师头部入口、`CourseLibraryView.vue`、`LearnerCourseView.vue`；核查 `qizhi_auth.py`、课程访问、learning records、practice、review | 建议独立 `/study` 课程库；学生首页不落到教师日历，直接访问与刷新可用；正式记录持久化，预览无写入；两学生隔离、未授权课程不可读取；修正复习旧层级判断。先做代表性课程库和阅读页，再扩展 |
| S2 系统学习与期末备考 | 现有阅读、课程/材料入口、`PracticeWorkspace.vue`、`MistakeNotebookPanel.vue`、题库与作答服务 | 系统学习支持范围、资料、讲义与就地练习；备考支持考试时间、范围、复习材料、专题练习及错题再练；出题设置可追溯到来源，题型/数量/难度有效。未接通的新生成动作如实说明状态，不使用假成功 |
| S3 项目实践最小闭环 | 在同一学习空间增补项目任务视图；复用文件、个人记录、合法来源、AI 上下文及任务服务 | 一个明确小项目贯通：目标与成果要求→当前任务→分步帮助→本人提交→反馈→修订→阶段回顾→继续；重进可恢复；AI 示例不能被计为学生成果；反馈引用实际提交，任务完成与能力掌握分别表达 |
| S4 互动学习扩展 | 在当前阅读/项目工作区接入经过验证的互动组件 | 先选一个真实学科案例，验证交互和解释确实帮助理解，再扩展模拟实验/不同表达。具体技术与生成方案另外确定 |

各批次中文桌面与英文一起维护。S1 可对已有授权内容先完成，不要求 G2—G5 全部结束；S2 新出题需与 G4 的唯一题库路径衔接。学生新建材料的可用性依赖生成方案讨论与正式存储接通；不得恢复已退休的旧接口作为捷径。S3 的前端原型可以先做，持久保存与真实反馈接通前不报功能完成。
