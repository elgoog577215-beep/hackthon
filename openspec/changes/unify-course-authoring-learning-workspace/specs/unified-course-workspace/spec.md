## ADDED Requirements

### Requirement: 教师端必须使用日历首页、课程文件空间和正式课程三段主路径
系统 MUST 将课程选择与教学日历放在首页，将备课资产放在课程文件空间，将 `CourseDocument + CourseBlock[]` 与正式练习组装为正式课程运行态。界面 MUST NOT 再用“课程 / 大纲 / 正文 / PPT”重复 Tab 表达同一层级。

#### Scenario: 从首页进入课程
- **WHEN** 教师点击左侧一门课程
- **THEN** 系统进入该 `course_id` 的课程文件空间
- **AND** 不先进入独立教师总览或四阶段 Tab

#### Scenario: 先创建空课程空间
- **WHEN** 教师在首页输入课程名称、学年和学期并确认新建
- **THEN** 系统创建一个空的课程真源和绑定同一 `course_id` 的文件空间
- **AND** 系统立即进入该文件空间
- **AND** 系统不自动启动全课程生成任务

#### Scenario: 预览正式课程
- **WHEN** 教师在课次状态或文件空间点击“预览正式课程”
- **THEN** 系统按当前修订组装正文块和正式练习
- **AND** 预览显示与学生端一致的练习、笔记、错题、学习概况、知识库和学生 AI 老师
- **AND** 预演记录只归属当前教师身份，不读取或写入任一学生数据
- **AND** 教师可直接返回发起预览时的课程与课次位置

### Requirement: 课程文件空间必须分离目录、文件和详情责任
左侧 MUST 使用可逐级展开和收起的资源管理器式目录树，只显示整课、课次及真实子文件夹；中间 MUST 使用详细信息列表显示当前目录的直接子项，并至少区分名称、修改时间、类型、大小和状态，每列表头 MUST 支持升序与降序切换；右侧 MUST 在未选择文件时显示当前文件夹信息，选择文件后只补充该文件的来源、用途、版本与操作，不重复列表中已经清楚显示的修改时间、类型和大小。进入任一文件夹时，左侧 MUST 自动展开其祖先路径。

#### Scenario: 打开一个课次文件夹
- **WHEN** 教师在左侧选择一个课次
- **THEN** 中间显示该课次的教案、正文、资料、PPT 和练习
- **AND** 左侧不再重复这五个文件
- **AND** 左侧自动展开该课次，右侧显示该文件夹的位置、项目数和修改时间

#### Scenario: 使用并导出结构化正文
- **WHEN** 当前课次已有 `CourseDocument` 正文块但没有对应磁盘文件
- **THEN** 文件空间仍将正文显示为可用课程资产
- **AND** 教师可打开正文进入当前正式课程
- **AND** 教师可从右侧导出该课次正文为 Markdown 文件
- **AND** 导出文件只是当前课程修订的派生产物，不成为第二份课程语义真源

#### Scenario: 查看老师上传文件的详细信息
- **WHEN** 教师单击当前目录中的一个自己上传的文件
- **THEN** 中间列表保持当前目录不跳转
- **AND** 右侧显示该文件的状态、来源、用途、版本和可执行操作
- **AND** 右侧不重复中间列表已经显示的修改时间、类型和大小
- **AND** 教师双击文件或使用右侧主操作时才进入预览或编辑

#### Scenario: 排序当前目录
- **WHEN** 教师点击名称、修改时间、类型、大小或状态列表头
- **THEN** 当前目录按该列切换升序或降序排列
- **AND** 文件夹始终排在文件之前
- **AND** 空值稳定排在已有值之后

#### Scenario: 进入文件夹
- **WHEN** 教师单击当前目录中的文件夹
- **THEN** 系统立即进入该文件夹并同步展开左侧祖先路径
- **AND** 不要求教师使用网页中难以被发现的双击手势

#### Scenario: 在移动端切换文件夹
- **WHEN** 屏幕无法容纳桌面三栏
- **THEN** 系统将同一目录树收为可滚动的紧凑文件夹区，并把文件详情置于文件列表之后
- **AND** 不将桌面层级机械堆叠为多层卡片

#### Scenario: 固定课程资产作为常驻入口
- **WHEN** 教师进入整课或任一课次目录
- **THEN** 系统始终显示对应的大纲、教案、正文、练习和配套 PPT 资产位
- **AND** 未形成内容的资产位显示“未生成”
- **AND** 单击固定资产只选中该文件并在右侧显示真实状态与主操作
- **AND** 双击固定资产或使用右侧主操作时才打开当前版本或进入该类型的生成流程
- **AND** 页面不显示需要再次选择资产类型的泛化“新建”菜单

#### Scenario: 在资料目录管理教师文件
- **WHEN** 教师进入整课参考资料、课次资料或真实子文件夹
- **THEN** 系统显示“添加资料”和“新建文件夹”动作
- **AND** 资料可以多份并保留老师上传的原文件
- **AND** 该动作不与固定课程资产的生成入口混在同一菜单

#### Scenario: 当前目录搜索无结果
- **WHEN** 教师输入关键词且当前目录没有匹配文件
- **THEN** 系统明确显示“没有找到匹配文件”而不误报文件夹为空
- **AND** 教师可从搜索框或无结果状态一键清空搜索

#### Scenario: 重复生成唯一资产
- **WHEN** 教师对已存在的大纲、教案、PPT 或练习再次发起生成或上传
- **THEN** 系统为该资产创建新的待审阅修订
- **AND** 系统不在同一目录新建第二份并列同类文件

### Requirement: 教师端主路径必须使用直接且可读的界面语言

日历首页、课程文件空间、课程工作台、任务中心与核心新建对话框 MUST 优先呈现对象名称、真实状态和当前可执行操作。辅助文字 MUST 不小于 12px；当标题、列表或按钮已能说明用途时，界面 MUST NOT 再用副标题、装饰卡片、横幅或重复状态解释同一件事。

#### Scenario: 查看教师日历首页

- **WHEN** 教师进入日历首页
- **THEN** 页面直接显示课程列表、日历和当前或近期课次
- **AND** 页面不再显示“这是课表”、“可从左侧进入”等重复解释
- **AND** 搜索、状态、日期和主操作在正常视距下可直接读取

#### Scenario: 在已有课程中生成大纲

- **WHEN** 教师从课程文件空间创建大纲
- **THEN** 对话框标题明确显示“生成课程大纲”
- **AND** 对话框不将该操作重新包装为“新建课程”
- **AND** 既有课程不重复询问课程类型，非必要生成参数收入“更多设置”

### Requirement: 教案与 PPT 必须成为教师端优先备课资产
系统 MUST 为大纲、教案、资料、PPT 和练习提供按类型区分的新建对话框。教案与 PPT MUST 优先进入可恢复的生成、质量检查、审阅与版本链。

#### Scenario: 从课次文件夹生成或上传 PPT
- **WHEN** 教师点击课次中的 PPT 资产位
- **THEN** 对话框先要求选择 AI 生成课件或上传旧课件
- **AND** AI 生成分支要求来源教案、页数、风格与可选个人模板
- **AND** 上传分支要求 PPTX 原件，并允许选择只保存或解析生成教案草稿
- **AND** 两个分支的任务均可检查、可审阅、可恢复
- **AND** 上传的旧课件另行展示且不隐藏或取代固定 PPT 资产位

#### Scenario: 从老师旧课件反向生成教案
- **WHEN** 教师上传 PPTX 并选择解析生成教案草稿
- **THEN** 系统保留源 PPTX，按页提取可追溯文字证据并新增教案草稿修订
- **AND** 已确认教案与源 PPTX 均保持不变
- **AND** 草稿只有经过教师审阅和确认后才进入正式同源链

### Requirement: 结构化同源必须在语义变化时精确传播
教案、PPT、正文投影和练习 MUST 保存稳定源 ID、源修订和表达修订。底层语义变化时，系统 MUST 先标记受影响单元并展示影响，教师确认后才重建；系统 MUST NOT 静默改写正式课程。

#### Scenario: 底层模型版本名称改变
- **WHEN** 教师将同一语义源中的“DeepSeek 3”更新为“DeepSeek 4”
- **THEN** 系统列出引用该源修订的教案、PPT、正文与练习单元
- **AND** 教师确认后只重建受影响单元
- **AND** 重建失败时保留上一可用版本

### Requirement: 教师智能体必须使用教师视角且不越过确认边界
文件空间中的教师智能体 MUST 优先分析教学目标、原理、过程与课堂组织，MUST NOT 展示学生学习证据、创建学生笔记或开启互联网检索。学生视角预览 MUST 改用学生 AI 老师与学习工具，但个人记录只归属当前教师身份。任一视角提出正式变更时 MUST 进入影响预览和教师确认链。

文件空间和带 `teacherPreview=1` 的学习现场 MUST 使用稳定教师工作身份，不得因页面切换创建新的临时身份。退出预览时 MUST 回到发起预览时的课程与课次位置。

#### Scenario: 教师询问怎么教
- **WHEN** 教师在课程文件空间询问当前内容的教学方法
- **THEN** 教师智能体使用当前课程真源和知识绑定回答
- **AND** 回答区分课程事实与通用建议
- **AND** 不声称已修改或发布正式课程

### Requirement: 旧教师路由必须安全收束
系统 MUST 将旧教师课程路由重定向到课程文件空间或日历首页。重定向 MUST 保留 `course_id` 与可表达的课次定位，不得删除或静默迁移旧数据。

#### Scenario: 打开旧教师文件链接
- **WHEN** 用户访问 `/teacher/course/:courseId/files`
- **THEN** 系统进入该课程文件空间
- **AND** 文件读取继续受当前身份和课程绑定约束
