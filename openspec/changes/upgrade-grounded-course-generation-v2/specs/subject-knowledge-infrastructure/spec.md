## ADDED Requirements

### Requirement: 单门课程必须拥有丰富且可治理的局部知识图谱

课程局部知识图谱 MUST 为每个知识节点保存规范名、陈述、类型、条件、边界、正反例、难度、能力、易错辨别与修复、掌握标准、来源、课程内所有权、复用位置、置信度和修订。关系 MUST 保存类型、方向、理由、条件、来源和置信度。

#### Scenario: 教师查看一门课程的知识详情
- **WHEN** 课程知识图谱已经冻结
- **THEN** 教师 MUST 能看到知识的前置/后续、易混、迁移和应用关系
- **AND** MUST 能看到对应能力、易错表现、纠偏策略和掌握证据
- **AND** 缺失字段 MUST 显示治理缺口而不是空标题占位

### Requirement: 课程知识图谱冻结前必须通过全局结构与覆盖门

系统 MUST 在图谱冻结前检查稳定 ID、端点、孤立必讲节点、前置环、关系语义方向、所有权、易错覆盖、掌握标准覆盖、来源覆盖和低置信节点。课程树、关系图、能力图和易错图 MUST 只是同一图谱的不同投影。

#### Scenario: 图谱包含孤立必讲节点和反向前置边
- **WHEN** 全局质量门运行
- **THEN** 系统 MUST 返回节点与关系级阻断项
- **AND** MUST NOT 将该图谱冻结给教案、正文或练习消费
