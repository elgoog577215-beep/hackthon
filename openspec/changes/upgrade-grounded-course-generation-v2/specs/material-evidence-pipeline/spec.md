## ADDED Requirements

### Requirement: 多资料解析必须有界并行并输出高保真质量报告

系统 MUST 在共享资源预算内并行解析多份资料，并为每份 `ParsedDocument` 输出版本化质量报告。报告 MUST 覆盖页/幻灯片/工作表、OCR、阅读顺序、标题层级、表格、公式、图片/图注、讲者备注、乱码、截断和降级原因。

#### Scenario: 同时上传文本 PDF、扫描 PDF 和 PPTX
- **WHEN** 三份资料进入同一个课程任务
- **THEN** 系统 MUST 使用有界并行处理独立文件
- **AND** 扫描页 MUST 进入页级 OCR 降级
- **AND** 每份资料 MUST 独立报告可用于事实依据、讲法参考或必须人工复核

### Requirement: 联网研究必须使用主题检索与知识缺口补证两段流程

系统 MUST 在资料处理期执行主题级检索，并在课程知识候选形成后为低置信、时效、冲突和覆盖缺口执行定向补证。两段结果 MUST 进入同一不可变证据包并遵守来源分层、URL 安全、隐私脱敏和注入过滤。

#### Scenario: 必讲知识缺少可靠来源
- **WHEN** 第一段检索和用户资料仍未覆盖一个必讲知识
- **THEN** 第二段 MUST 针对该知识的陈述、边界、反例或易错生成定向查询
- **AND** 检索失败 MUST 保留可见覆盖缺口
- **AND** MUST NOT 用模型常识伪装为联网核验
