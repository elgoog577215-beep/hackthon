## Context

`slide-themes.json` 当前同时被 Vue 与 Python 读取，但运行时只支持仓库内静态主题；`SlideDeckTheme` 又被固定为五个 Literal。自定义模板若直接把 PPTX 当运行时母版，会让浏览器预览、PPTX 导出和 V5 容量规则产生三套解释。因此参考 PPTX 只作为一次性输入，系统将其归一化为受控模板包。

## Goals / Non-Goals

**Goals:**

- 一个模板版本拥有设计 token、7 类背景、10 类文本框、18 类语义布局映射、素材摘要和预览。
- 个人模板严格按 `X-User-Id` 隔离；旧课件继续读取已锁定的不可变版本。
- 不依赖图片生成服务也能从 PPTX/品牌字段产生可用草稿。
- Web 与 PPTX 使用同一模板快照，不允许仅前端换肤。

**Non-Goals:**

- 不支持组织共享、任意模板代码、宏、动画、插件和无约束母版克隆。
- 不重写整套 V5 课程语义规划。
- 不把用户上传文件或运行数据提交到源码仓库。

## Decisions

1. **模板包是受控 Manifest，不是可执行插件。** 语义角色只能映射到现有渲染器支持的布局；装饰通过安全 token 和素材 ID 表达。
2. **内置和个人模板共用解析结果。** 内置主题来自静态 Manifest；个人主题来自 `DATA_DIR/ppt_template_packs`。渲染器只接收解析后的模板快照。
3. **生成请求保留 `theme` 并新增模板引用。** `template_pack_id`/`template_pack_version` 存在时优先解析个人模板，其 `base_theme` 仍用于现有规划兼容。
4. **发布版本不可变。** 草稿可修改；发布生成新整数版本。删除只隐藏模板，已发布且被课件引用的版本保留。
5. **参考 PPTX 只做风格提取。** 提取页面比例、主题颜色、字体、代表页缩略图和可安全复用图片；4:3 输入在预览阶段标注已适配为 16:9。
6. **文本保持原生可编辑。** 图片只作为背景或无文字装饰；卡片本体、阴影、强调线和文字由 Web/PPTX 渲染器绘制。
7. **图片生成是增强而非阻断依赖。** 内置素材经审定后进入源码；个人模板未配置图片服务时使用确定性颜色、上传素材和可编辑形状回退。
8. **质量治理聚焦表现层。** 选择布局前检查内容项、必填槽位和真实视觉，合并可安全合并的稀疏续页，并禁止最终候选中的空卡片和假占位图。

## Storage and Security

模板元数据按拥有者哈希、模板 ID 和版本目录保存；所有路径经过固定 ID 校验并解析后必须仍位于存储根。上传只接受 `.pptx`、受支持的图片和字体元数据，限制文件数量、单文件大小、压缩展开大小及 Office ZIP 条目数量。素材接口先校验拥有者再返回文件，不暴露物理路径。

## Migration

五个现有主题 ID 和两个历史别名保持不变。启智课堂 Manifest 原样迁移到通用完整模板合同；旧生成请求继续只传 `theme`。个人模板功能由 `PPT_TEMPLATE_PACKS_ENABLED` 灰度开关控制。
