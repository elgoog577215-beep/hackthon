## ADDED Requirements

### Requirement: 教案和讲义默认只提供整课生成入口

教师工作台 MUST 为教案和讲义各提供一个默认可见的批量生成入口。初始或仍有缺失内容时显示“生成全部教案”或“生成全部讲义”；存在可恢复失败时同一位置显示“重新生成”。默认界面 MUST NOT 显示“只生成本讲”。底层单讲能力 MAY 在兼容期保留给批量恢复和旧客户端，但不得形成第二套生成状态机。

#### Scenario: 新课程生成教案
- **WHEN** 课程具有可用大纲且尚未生成教案
- **THEN** 页面 MUST 只显示“生成全部教案”主操作
- **AND** MUST NOT 显示“只生成本讲”操作

#### Scenario: 可用讲次不得换名保留单讲重生成
- **WHEN** 教案或讲义已有可用内容且当前没有失败恢复动作
- **THEN** 默认页面 MUST NOT 以“重新生成”或其他名称提供等价的单讲生成入口
- **AND** 教案与讲义的新生成和失败恢复 MUST 继续由正文上方的整课批量按钮承载

#### Scenario: 部分讲义生成失败
- **WHEN** 批量讲义生成部分失败
- **THEN** 原生成按钮 MUST 原位变为“重新生成”
- **AND** 重试 MUST 只恢复失败或未完成单元，不覆盖可用讲义

#### Scenario: 单讲兼容调用尚未归零
- **WHEN** 生产观察仍记录到批量执行器之外的单讲调用
- **THEN** 默认界面 MUST 继续隐藏单讲入口
- **AND** 底层单讲能力 MUST 保留为兼容路径，不得提前删除

### Requirement: 生成动作必须由唯一生产状态决定

生成、暂停、继续、重新生成和失败范围 MUST 由服务端生产状态投影和真实任务 ID决定。前端本地布尔值、选中讲次或最新批次不得重定义整课状态或触发自动动作。

#### Scenario: 页面刷新恢复批量任务
- **WHEN** 用户在批量生成期间刷新页面
- **THEN** 页面 MUST 从同一任务与生产状态投影恢复按钮、进度和失败范围
- **AND** MUST NOT 自动创建新任务

#### Scenario: 批量重试只恢复服务端授权任务
- **WHEN** 前端请求重新生成教案或讲义
- **THEN** 请求 MUST 携带投影 `action_targets.retry_generation` 中的 `resume_job_ids`
- **AND** 后端 MUST 在创建任何子任务前验证全部 ID 的课程、资产类型、讲次、来源修订与恢复资格
- **AND** 空 `resume_job_ids` MUST NOT 自动恢复 latest 或已取消任务

### Requirement: 教案知识前置顺序不得阻断生成

教案结构校验 MUST NOT 因 `prerequisite` 关系端点在本节知识注册表或课程小节中的相对顺序而判定生成失败。系统 MUST 继续校验关系端点存在、知识身份一致和必填字段完整。

#### Scenario: 同一小节的前置关系与注册表顺序相反
- **WHEN** 教案批次返回的 `prerequisite` 关系方向与同一小节的知识注册表顺序相反
- **THEN** 本讲教案 MUST 继续生成并保存
- **AND** 该关系 MUST NOT 产生阻断错误

#### Scenario: 前置关系引用未知知识
- **WHEN** 教案骨架或批次的前置关系引用不存在的知识键
- **THEN** 结构校验 MUST 阻断生成

### Requirement: 失败恢复必须区分冻结输入与修正输入

原任务恢复 MUST 使用冻结输入；教师补充要求后 MUST 创建关联原 job 的新尝试，使用新要求和当前来源重新决定复用范围。每种阻断失败 MUST 有具体恢复动作，禁止不改变输入或修复范围的确定性重复失败。

#### Scenario: 整讲质量阻断但单块检查通过
- **WHEN** 整讲失败而单块检查点均可用
- **THEN** 恢复 MUST 根据阻断原因产生有效修复范围或明确替代动作

#### Scenario: 失败后补充要求
- **WHEN** 教师选择补充要求后重新生成
- **THEN** 新尝试 MUST 实际使用新要求并保留原失败历史与最后可用稿

### Requirement: 完整大纲步骤必须绑定正式任务的继续事实

教师明确继续完整大纲后，页面 MUST 使用同一任务持久化的 `outline_detail_requested` 事实保持第三步。继续回执、WebSocket、轮询和浏览器恢复 MUST 保留该事实；课程目标、考核方案、分讲生成和校验等内部子阶段 MUST NOT 使步骤退回轻量讲次方案。该显示事实 MUST NOT 扩大任务动作授权。

#### Scenario: 完整大纲进入课程合同子阶段
- **WHEN** 已继续完整大纲的任务进入课程目标或考核方案生成与校验
- **THEN** 页面 MUST 保持第三步并显示真实子阶段进度
- **AND** 暂停、失败和刷新 MUST 保留步骤位置，恢复仍使用原任务 ID

#### Scenario: 新轻量方案明确等待教师继续
- **WHEN** 服务端任务明确未开始完整大纲并等待输入
- **THEN** 页面 MUST 显示第二步和正式授权的继续入口，不自动发送生成请求

### Requirement: 完整大纲必须在交付前自动处理可修正建议

完整大纲生成 MUST 在同一任务内执行自动审阅、确定性学时校正、最多两轮 AI 定点优化和复审。自动与手动优化 MUST 复用现有操作编译与审阅规则。优化 MUST 保持讲次身份、标题、顺序、真实来源和已填写的教师内容；不得在读取、刷新或保存正式内容时隐式生成。

#### Scenario: 轻量方案学时为全零对象
- **WHEN** 详情生成返回有效学时，而轻量方案只有全零默认对象
- **THEN** 汇编 MUST 使用有效详情，并使正式大纲与节点投影一致
- **AND** 已填写的非零教师学时 MUST 保留

#### Scenario: 新生成大纲包含可修正建议
- **WHEN** 自动审阅发现重复目标、缺少达成检验或其他可定点修正问题
- **THEN** 后台 MUST 合并同轮问题生成受限操作并复审，只采用有改善且没有越界或新增自动问题的候选
- **AND** 总学时校验 MUST 由确定性程序完成，不要求教师逐条点击

#### Scenario: 来源不足或者模型优化失败
- **WHEN** 没有可靠来源、候选无改善、越界、超时或模型不可用
- **THEN** 系统 MUST 保留最后可用草稿与真实剩余建议，不得编造来源、无限重试或声称全部解决

#### Scenario: 自动优化中断后恢复
- **WHEN** 同一任务在优化中断后恢复
- **THEN** 系统 MUST 恢复检查点中的已接受结果和已消耗轮次，不重放已完成优化
- **AND** 暂停、取消和第三步位置 MUST 沿用原任务合同

### Requirement: 教案和讲义也必须在正式交付前自动修正

教案与讲义的纯模型生成 MUST 在正式保存前执行质量检查、受限自动修正和复验，复用手动优化或既有块修复能力。每层自动修正 MUST 限定最多两轮，保留最好可用结果；硬校验仍失败 MUST 按现有恢复合同失败，MUST NOT 保存半成品或覆盖旧可用版本。教师编辑、采用候选和读取内容 MUST NOT 隐式启动自动改写。

#### Scenario: 教案最终检查发现抽象活动或缺少可执行字段
- **WHEN** 模型教案完成，但最终检查仍发现可修复的教学内容问题
- **THEN** 原 job MUST 自动调用已有教案优化器并复审后再保存
- **AND** 小节、教学块身份、顺序、知识、来源和时长 MUST 保持不变

#### Scenario: 讲义只有表达建议或者整讲重复
- **WHEN** 单块检查发现教材式表达、衔接建议，或整讲汇编发现跨块重复与深度不足
- **THEN** 系统 MUST 在交付前自动修正并复验，只采用改善的候选
- **AND** 优化失败 MUST 保留已有有效内容，硬校验未通过 MUST NOT 宣布正式完成

### Requirement: 临时生成异常必须先在原任务内自动恢复

教案与讲义 MUST 在原 job 内对可重试的模型请求、空结果和结构化输出错误最多追加两次恢复，记录各生成单元消耗次数并保留成功检查点。恢复 MUST 继续使用冻结输入与当前来源，不生成平行任务；暂停、取消、来源冲突、显式不可重试错误及权限配置错误 MUST 立即停止自动尝试。正式保存与持久化失败 MUST NOT 被模型重试包装器重放。

#### Scenario: 模型首次超时随后成功
- **WHEN** 当前教案或讲义生成单元首次模型请求超时，后续请求成功
- **THEN** 原任务 MUST 自动继续并交付，恢复期间保持生成中且无失败动作
- **AND** 其他成功单元及已有正式版本 MUST 保留

#### Scenario: 后台恢复耗尽
- **WHEN** 同一单元已消耗两次自动恢复仍未得到可用结果
- **THEN** 原任务 MUST 才记录最终失败与可行恢复动作，保留成功检查点
- **AND** 开发 MUST 在隔离环境验证该路径，不把故障测试交给教师

#### Scenario: 自动恢复期间用户暂停或来源变化
- **WHEN** 任务暂停、取消或来源修订变化
- **THEN** 自动恢复 MUST 停止，不再次调用模型或覆盖旧内容

#### Scenario: 普通建议优化没有改善
- **WHEN** 结果可用但优化无改善、引入硬错误或模型异常
- **THEN** 系统 MUST 保留最好可用结果并正常完成，不为消除所有建议无限生成
