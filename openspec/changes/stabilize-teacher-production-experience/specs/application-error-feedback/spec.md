## ADDED Requirements

### Requirement: 生产失败必须携带稳定定位

教案、讲义、大纲和 PPT 的生产失败 MUST 携带阶段、讲次、任务和可选教学块身份，恢复动作 MUST 与受影响对象就近呈现。失败信息 MUST 按职责分层：顶部只显示课程级失败数量，正文对象旁显示局部失败状态和恢复动作，右栏显示完整失败原因与恢复说明；同一条具体错误 MUST NOT 在三处重复。

#### Scenario: 用户从异常入口导航
- **WHEN** 用户点击“处理问题”进入失败对象
- **THEN** 页面 MUST 只完成定位、突出和错误展开
- **AND** MUST NOT 自动重试或修改任务

#### Scenario: 深链打开失败对象
- **WHEN** 用户从课程级异常入口进入一个生成失败的讲次
- **THEN** 顶部 MUST 只显示课程级失败数量，不复述具体错误
- **AND** 正文 MUST 显示该讲次的局部失败状态及原位恢复动作
- **AND** 右栏 MUST 完整显示具体失败原因与恢复说明

### Requirement: 资产主状态必须使用统一四态

资产的主显示状态 MUST 只使用“未生成”“生成中”“可使用”“生成失败”。暂停、过期、待核对和最近失败 MUST 作为辅助说明；课程级状态 MUST 继续只使用“备课中”和“备课完成”。

#### Scenario: 暂停中的首次生成
- **WHEN** 资产没有可用版本且生成任务已暂停
- **THEN** 资产主状态 MUST 保持“生成中”
- **AND** 辅助状态 MUST 显示“已暂停”及继续操作
