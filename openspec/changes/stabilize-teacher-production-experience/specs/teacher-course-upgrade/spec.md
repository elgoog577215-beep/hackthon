## Purpose

为历史章节式课程提供非破坏、可审计的讲次式课程复制升级路径，在保留旧课程与旧教学历史边界的同时让教师使用当前生产链。

## ADDED Requirements

### Requirement: 历史课程升级必须创建新课程

历史章/节课程升级 MUST 创建新的课程 ID 和讲次映射，旧课程 MUST 保持只读且内容校验和不变。系统 MUST NOT 原地改写旧课程，也 MUST NOT 导入旧整课教案历史。

#### Scenario: 教师复制升级历史课程
- **WHEN** 教师确认把历史课程复制为讲次式课程
- **THEN** 系统 MUST 创建新课程、稳定讲次映射和迁移报告
- **AND** 旧课程内容、身份和历史 MUST 保持不变

### Requirement: 升级失败必须可清理且不留下半成品入口

升级 MUST 先在隔离工作区编译和校验；只有完整通过后才能发布新课程入口。失败时 MUST 删除或隔离未发布半成品，并提供可安全重试的报告。

#### Scenario: 讲次映射校验失败
- **WHEN** 历史章节无法形成合法讲次映射
- **THEN** 新课程 MUST NOT 出现在正式课程列表
- **AND** 旧课程 MUST 继续可读
