# 变更：为教师讲义增加同源多模态表达

## Why

当前分讲讲义已经以有序教学块保存正式内容，课程侧也已有 `TeachingRepresentation`、结构化图解和可选图片生成能力，但这些能力尚未进入教师阅读讲义的真实路径。动画也没有可审阅、可暂停、可降级的正式场景合同。若把图片 URL、Mermaid 或 MP4 直接写进讲义 Markdown，会制造第二份媒体真源，并让 PPT 与学生端无法稳定复用。

## What Changes

1. 每个结构化讲义教学块下方增加紧凑的视觉表达工作区，支持图解、插图和代码动画。
2. 所有表达绑定课程、讲次、讲义修订、小节、教学块和块内容指纹，保存为 `TeachingRepresentation` 候选。
3. 教师采用后，表达才进入该教学块的 `RepresentationSet`；放弃、重生成和讲义修订变化都有明确状态。
4. 图解使用同源 `DiagramSpec`；动画使用可播放、暂停、逐步检查并带静态降级的 `scene_spec_v1`。
5. 插图复用现有图片提供方和不可变资产仓库；未配置提供方时仍保存提示词，并返回 `provider_unavailable`，不伪造图片。
6. 已采用表达由同一 `RepresentationSet` 向讲义、PPT 和学生端提供，不在下游复制媒体真源。

## Non-goals

- 本变更不把动画导出为 MP4；MP4 只是未来可选派生文件，不是正式场景真源。
- 本变更只提供已采用表达的统一消费接口；不在现有 PPT 编译器或学生页面中自动装配视觉表达。
- 本变更不允许媒体生成失败阻断讲义阅读、编辑、PPT 生成或学生学习。
- 本变更不把候选直接写入讲义 Markdown，也不新增平行媒体 Store。

## Capabilities

### New Capabilities

- `teacher-script-multimodal-expressions`：定义讲义块视觉建议、候选生成、教师确认、来源过期、图片降级、结构化动画控制与共享表达集合同。

## Impact

- 后端：扩展 `TeachingRepresentation` 类型与候选生命周期，新增讲义视觉编译服务和教师接口。
- 前端：新增讲义块视觉工作区、结构化动画播放器和独立状态 Store，并最小接入现有讲义页面。
- 资产：图片继续进入内容寻址的不可变资产仓库，读取时校验课程、表达与哈希。
- 验证：OpenSpec、后端生命周期与降级测试、前端候选与动画控制测试、类型检查和构建。
