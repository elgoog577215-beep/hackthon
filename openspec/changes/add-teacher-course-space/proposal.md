## Why

现有“资料上传”服务只支持在创建课程时逐个上传并作为生成证据使用，不能表达教师按课程、学年/学期维护整套教学材料的真实工作方式。教师需要把已有课程文件夹原样导入、在可校正的课程资料树中持续维护，并在需要时取回单份原件或完整课程包。

本变更优先完成需求书 A（教师个人空间与课程资产）。它为后续 B（教学大纲、教学设计、分讲教案、教学日历的生成与导出）提供稳定且可追溯的资料来源，但不改变 B 的生成链路。

## What Changes

- 新增按教师、课程和学年/学期隔离的课程资产工作包。
- 新建课程后默认进入备课工作台，并在工作台上选择“从零开始”或“基于已有资料”。
- 支持浏览器选择或拖入整课文件夹；保留相对路径、原文件、导入批次与校验结果。
- 根据路径、文件名和扩展名识别资料目录及大纲、教案、讲稿、PPT、题库、教务材料等备课用途，允许教师集中校正后再进入工作台。
- 各备课阶段首次打开时自动匹配相关原件作为主来源或参考资料；教师后续可以替换、增加或清空，系统持续记住人工选择。
- 提供课程资料树、单份原件下载、批量 ZIP 导出和增量导入记录。
- 复用已有材料解析/证据能力：资产可被课程生成流程引用，但本变更不自动触发生成。
- 正式文件之间不建立文件关系；正式文件只记录老师上传原件中的母文件和参考原件。

## Capabilities

### New Capabilities

- `teacher-course-space`: 教师拥有、按学年/学期组织、可持续维护的课程资料工作包。
- `course-folder-import-export`: 安全的整目录导入、分类、单文件下载与 ZIP 导出合同。

### Modified Capabilities

- `material-evidence-pipeline`: 已有材料资产增加可选的工作包归属和相对路径元数据，同时保持现有创建课程资料绑定兼容。

## Impact

- 后端：新增课程空间仓库、导入/分类/下载/ZIP 路由和权限校验；扩展材料元数据与引用。
- 前端：新增“我的课程”教师资料空间入口、工作包资料树、文件夹选择/拖入、分类校正和导出反馈。
- 验证：后端 API 的权限、路径安全、导入分类、增量和导出测试；前端组件测试、构建和真实浏览器流程验证。
