# 浙江大学本科毕业论文检查系统 — 用户使用手册

> 版本：0.1.0（Beta 测试版）

---

## 一、系统简介

本系统是一款基于 AI 大语言模型的毕业论文智能审查工具。用户上传毕业论文 PDF 文件后，系统会**逐页进行视觉识别与规范性检查**，最终生成一份完整的审查报告，涵盖格式规范、内容质量、文字规范、参考文献、思想政治等多个维度。

**适用对象**：浙江大学本科毕业论文作者、指导教师、教学管理人员。

---

## 二、快速开始

### 2.1 上传论文

1. 打开系统前端页面
2. 点击上传按钮，选择需要检查的 **PDF 格式**毕业论文文件
3. 系统接收文件后，会自动创建一个**任务（Task）**，并返回唯一的 **任务 ID**

> 系统限制：PDF 文件最多 100 页。

### 2.2 查询任务状态

1. 在搜索栏中输入任务 ID
2. 点击"查询"按钮
3. 页面会显示任务的基本信息和处理进度

### 2.3 查看处理进度

任务上传后，系统会在后台自动处理。任务状态流转如下：

```
uploaded → processing → summarizing → completed
                                      → failed（异常时）
```

- **uploaded**：文件已接收，等待处理
- **processing**：正在逐页分析（显示当前处理到第几页）
- **summarizing**：所有页面检查完毕，正在生成汇总报告
- **completed**：审查完成，可查看报告
- **failed**：处理失败（失败页面超过 50%）

页面顶部会实时显示：
- 总页数 / 已完成 / 失败 / 处理中
- 进度条百分比

> 提示：开启"自动刷新"功能后，系统每 3 秒自动更新一次进度。

## 三、审查报告解读

当任务状态变为 **completed** 后，页面会展示完整的审查报告。

### 3.1 总体评价

报告顶部显示**总体结论**，分为三档：

| 结论 | 含义 |
|------|------|
| **合格** | 论文基本符合规范要求 |
| **需修改** | 存在若干需要修改的问题 |
| **不合格** | 存在较多严重问题 |

同时提供一段 200-500 字的**总体评价**，从国家级教学名师的视角给出专业、具体的综合评价。

### 3.2 九大检查域

报告按照以下九个维度逐项展开（可折叠查看明细）：

#### 1. 规范管理
- 是否有毕业论文实施细则/任务书
- 任务书是否详实、起讫日期是否规范
- 各类签字、审核意见是否完整

#### 2. 前置部分
- 封面信息完整性（题目、作者、导师、专业等）
- 承诺书签字/日期是否完整
- 中文摘要是否包含背景、方法、结果、结论四要素
- 中文摘要是否符合三段论结构
- 英文摘要是否包含基本要素

#### 3. 主体部分 — 内容质量
- 绪论/正文/结论是否完整
- 算法描述是否正确、清晰
- 实验数据是否合理

#### 4. 主体部分 — 文字规范
- 错别字、病句、错词
- 语法错误、语句不通顺
- 口语化表达
- 语言不够专业的地方
- 数字夸大、浮夸表述

#### 5. 主体部分 — 数据与图表
- 数据合理性、是否存在捏造数据嫌疑
- 量化单位使用是否规范
- 图表标注是否规范（表名在表上方、图名在图下方）

#### 6. 主体部分 — 格式统一性
- 全文格式一致性判断

#### 7. 引文与参考文献
- 参考文献格式是否统一（GB/T 7714 或 APA 标准）
- 文献信息是否完整

#### 8. 思想政治与价值观
- 是否存在敏感词或不当用词
- 是否存在不当政治表述
- 内容是否符合社会主义核心价值观

#### 9. 考核材料
- 指导教师评语、签字、时间
- 答辩小组评语、打分、签字、时间
- 专家评阅意见
- 现场答辩记录

### 3.3 具体问题列表

报告中会单独列出：
- **参考文献问题**：红色标记，逐条列出格式不统一、信息缺失等问题
- **修改建议**：蓝色标记，给出具体的修改方向和建议

## 四、逐页检查功能

在"页面检查"区域，可以**逐页浏览**每一页的检查结果。

### 4.1 页面浏览

- **左半屏**：显示当前页的论文图片
- **右半屏**：显示该页的所有检查项及结果
- 使用左右箭头按钮或键盘 ← → 键翻页
- 支持直接输入页码跳转

### 4.2 筛选功能

勾选"**只看检查不通过**"复选框，仅展示存在问题的页面，方便快速定位需要修改的地方。

### 4.3 检查项说明

每一页的检查结果按以下规则显示：

- **通过（绿色背景）**：该检查项符合要求
- **不通过（红色背景）**：该检查项存在问题，并附带具体说明

## 五、特色功能

### 5.1 AI 多模态视觉识别

系统采用 **AI 多模态大模型**，直接"看"论文页面图片进行审查，而非简单的文本解析。这使得系统能够：

- 识别排版格式问题（字号、行距、缩进）
- 检查图表标注位置是否正确
- 判断公式书写规范性
- 识别手写签名是否存在

### 5.2 智能页面分类

系统自动识别每一页所属的论文部分，共支持 **15 种页面类型**：

| 类型 | 说明 |
|------|------|
| cover | 封面页 |
| commitment | 承诺书/原创性声明 |
| abstract_cn | 中文摘要 |
| abstract_en | 英文摘要 |
| toc | 目录页 |
| body | 正文页 |
| algorithm | 算法描述页 |
| data_table | 数据表格/实验结果页 |
| conclusion | 结论页 |
| references | 参考文献页 |
| appendix | 附录页 |
| task_sheet | 任务书页面 |
| assessment_form | 考核表页面 |
| expert_review | 专家评阅意见表 |
| defense_record | 现场答辩记录表 |

**不同类型的页面使用不同的检查标准和规则**，确保检查的针对性和准确性。

### 5.3 并发高效处理

- 系统采用**并发处理架构**，最多同时处理 10 个页面
- 支持**断点续传**：如果某个页面处理失败，系统会自动重试（最多 3 次）
- **服务恢复机制**：服务重启后，自动恢复中断中的任务继续处理

### 5.4 容错设计

- 如果某页面上不存在某类检查项（如正文页没有公式），相关检查点**自动视为通过**，不会产生误报
- 失败页面比例超过 50% 时，任务标记为 failed，避免生成不可靠的报告

### 5.5 键盘快捷操作

在页面浏览模式下：
- **← 键**：上一页
- **→ 键**：下一页

## 六、常见问题

**Q：支持哪些文件格式？**
A：目前仅支持 PDF 格式。

**Q：处理一份论文需要多长时间？**
A：取决于论文页数和模型响应速度。一般 50 页的论文约需 5-15 分钟。

**Q：如果任务处理失败了怎么办？**
A：系统会自动重试失败的页面（最多 3 次）。如果失败页面超过 50%，任务会标记为 failed，建议检查 PDF 文件质量后重新上传。

**Q：检查结果准确吗？**
A：系统基于 AI 大模型进行视觉分析，对格式、排版、规范性等客观问题的检查效果较好。对于内容质量等主观判断类检查项，建议结合人工审核综合判断。
