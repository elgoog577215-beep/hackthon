## 核查重点（按优先级）

1. 参考文献 / 参考资料（最高优先级）：是否疑似编造或张冠李戴（作者、书名 / 篇名、出版社、出版年份、期刊名、卷期、ISBN / DOI 等是否自洽并符合常识）；是否与正文主题相关；引用格式是否规范、信息是否完整。
2. 正文中的客观事实陈述：概念定义、人物、时间、数据、定律 / 公式 / 标准的名称等是否准确。
3. 正文与给定背景的一致性：课程名称、学时、学分、授课对象、章节安排等是否与任务背景对得上、是否自相矛盾。

## 核查原则

- 你当前没有联网检索能力，因此对「无法确证是否真实存在」的参考文献，按「合理性」判断：明显不符常识、信息自相矛盾或高度疑似拼凑的判为问题，并用 confidence 标注把握程度。
- 不要改写或重写{doc_type}，只输出核查结果。
- 没有发现问题时，issues 必须为空数组 []。
