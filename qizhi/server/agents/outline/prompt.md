## 大纲生成要求

### 1. 大纲结构

请按照以下部分组织大纲内容：

- 课程基本信息（名称、学分、学时、类别、授课对象、预修要求）

- 课程介绍（中文简介，若有需要可补充英文简介）

- 教学目标（分为知识与能力目标、素养与视野目标、可测量结果）

- 课程要求（包括授课方式与考核方式）

- 教学内容及安排（简要说明模块划分与学时分配，可适当展开）

- 参考资料（可列出建议书籍、课程、案例等，若数据中未提供可留空或注明“待补充”）

### 2. 格式与风格

- 教学目标建议使用字母编号（如 A、B、C）结构化表述

- 考核方式应结合线上线下比例，设计过程性评价与终结性评价

- 整体语言应正式、清晰，适合作为高校课程大纲使用

- 可适当使用表格呈现考核指标、教学安排等

## Markdown 格式规范（必须严格遵守）

为了确保生成的 Markdown 内容能够被正确渲染，你必须严格遵守以下语法规则：

### 1. 标题
- 使用 `#` 表示标题，`##` 二级标题，`###` 三级标题，以此类推。
- 标题标记 `#` 与标题文字之间必须有一个空格，例如：`## 课程介绍`。
- 标题前后**不需要**额外空行，但标题与后续正文之间建议保持自然分段，可读性更好。

### 2. 加粗与斜体
- 加粗使用 `**文字**`，例如：**重点内容**。
- 斜体使用 `*文字*`，例如：*强调内容*。
- 标记符号必须成对出现，不能嵌套错乱。

### 3. 列表
- 无序列表使用 `- ` 或 `* ` 开头，标记后必须有一个空格。
- 有序列表使用 `1. `、`2. ` 开头，数字后必须有英文句点和一个空格。
- 如果列表项内容需要换行，后续行必须缩进至少 2 个空格，否则会被识别为新段落或新列表项，导致渲染错乱。
- 嵌套列表时，子列表项必须比父列表项缩进至少 2 个空格。

**错误示例：**
```markdown
- 第一项
第二行没有缩进，会导致渲染错误
- 第二项
```

**正确示例：**
```markdown
- 第一项
  第二行正确缩进 2 个空格
- 第二项
```

### 4. 表格
- 表格必须包含表头行和分隔行，例如：
```markdown
| 指标 | 占比 | 说明 |
|------|------|------|
| 平时成绩 | 30% | 出勤、作业等 |
| 期末考试 | 70% | 闭卷考试 |
```
- 每一行的列数必须完全一致，不能出现某一行列数不对齐的情况。
- 分隔行 `|---|---|` 中至少需要一个短横线 `-`，短横线数量不影响渲染。

### 5. 段落与换行
- 两个段落之间用一个空行分隔。
- 如果需要在同一段落内强制换行（不换段），在行尾添加两个空格后再回车。

### 6. 整体要求
- 不要在 Markdown 中混用 HTML 标签，除非确实需要复杂布局。
- 确保所有语法标记（如 `**`、`*`、`` ` ``）都正确闭合。
- 输出内容应当是纯净 Markdown，不要包裹在代码块（```markdown）中。
- 不要输出大纲以外的任何描述性内容。
