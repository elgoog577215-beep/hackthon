## ADDED Requirements

### Requirement: 课程文件包必须绑定稳定课程身份
嵌入统一课程工作区的文件包 MUST 保存 `course_id`，并以 `owner_id + course_id` 作为默认查找边界。课程标题仅用于显示，不得作为长期关联键。

#### Scenario: 课程改名后打开资料
- **WHEN** 已绑定文件包的课程名称发生变化
- **THEN** 系统仍通过 `course_id` 打开原文件包
- **AND** 不创建新的空文件包或丢失原目录

#### Scenario: 创建课程文件包
- **WHEN** 用户在一门课程的资料子模块创建文件包
- **THEN** 创建请求携带当前 `course_id`
- **AND** 返回清单保存该课程 ID 与当前 owner

### Requirement: 旧文件包绑定必须可控且可恢复
系统 MUST 继续读取没有 `course_id` 的旧文件包。只有当前 owner 下存在唯一课程标题候选时，界面 MAY 提示并绑定到当前课程；有多个候选时 MUST 要求显式选择，不得静默绑定或删除数据。

#### Scenario: 唯一旧文件包候选
- **WHEN** 当前课程没有已绑定包且当前 owner 只有一个同名旧包
- **THEN** 系统可将其作为兼容候选显示
- **AND** 完成绑定后保留原 package ID、目录、文件和导入历史

### Requirement: 教师课程链路必须使用显式且一致的所有者身份
教师首页、新建课程、课程工作台、文件包、教学日历、生成任务和教师预览 MUST 使用同一稳定教师身份。客户端 MUST 由路由元数据或业务调用显式选择 `teacher` 身份域，MUST NOT 根据 URL 正则猜测身份。教师课程库 MUST 只返回当前所有者的课程；未发布教师课程及其子资源 MUST 对其他身份表现为不存在。

#### Scenario: 创建后立即生成大纲
- **WHEN** 教师在首页创建课程并进入工作台生成大纲
- **THEN** 创建课程、创建文件包和生成任务保存相同 `owner_id`
- **AND** 生成任务在调用 AI 前确认目标草稿属于当前教师
- **AND** 页面跳转不得改变该身份

#### Scenario: 外部身份访问未发布教师课程
- **WHEN** 非课程所有者读取、删除或控制该课程的文件、日历或生成任务
- **THEN** 服务返回不泄露存在性的 `404`
- **AND** 不读取、修改或删除目标资源

#### Scenario: 草稿所有者校验失败
- **WHEN** 生成请求中的身份与目标草稿所有者不一致
- **THEN** 服务返回一个包含稳定错误码与可读消息的错误
- **AND** 前端退出生成态并只显示该真实原因
- **AND** 前端不得继续显示加载动画或追加泛化“生成失败”提示

#### Scenario: 修复旧版本创建的错绑空草稿
- **WHEN** 审计发现教师空白草稿被旧路径推断逻辑写入随机学习者身份
- **THEN** 系统只在草稿没有结构化内容且从未启动生成时允许迁移
- **AND** 迁移前在仓库外备份课程和相关文件包
- **AND** 非空草稿或文件包内容冲突时停止自动迁移并报告原因

### Requirement: 原始资产与正式文件必须使用双向引用而不是复制
系统 MUST 为每一份上传原文件保存稳定资产 ID，并允许同一资产在多个课程逻辑位置建立引用。正式课程文件 MUST 保存其主来源和参考资料关系；原始资产 MUST 能反向列出引用它的正式文件。建立或移除引用 MUST NOT 复制或删除原始资产。

#### Scenario: 一份教案原文件被多个正式文件使用
- **WHEN** 教师把同一份 DOCX 作为某讲教案的主来源，并作为讲稿的参考资料
- **THEN** 系统只保存一份原始资产
- **AND** 两个正式文件分别保存自己的引用角色
- **AND** 从该 DOCX 的详情可反向看到教案与讲稿

#### Scenario: 移除正式文件中的参考资料
- **WHEN** 教师从一个正式文件移除某份参考资料
- **THEN** 系统只删除该条引用关系
- **AND** 原始资产及其被其他正式文件使用的关系保持不变

### Requirement: 配套文档必须是课程正式文件但不得进入教学主链路

系统 MUST 把评分细则、材料自查清单等面向学校提交、学生说明或课程归档的文档保存为课程正式文件，但 MUST NOT 将其纳入“课程基础 -> 教案 -> 题库 -> 讲稿 -> PPT”教学主链路。模板、课程结构化输入和不可变修订 MUST 是文档真源；导出文件 MUST 只是派生产物。

#### Scenario: 在文件空间查看配套文档

- **WHEN** 当前课程已生成一份评分细则或考试课程材料自查清单
- **THEN** 文件视图在整课层的“配套文档”文件夹显示该正式文档
- **AND** 文件详情可显示其模板、修订、主来源与参考资料
- **AND** 打开编辑时回到同一配套文档工作台，不创建平行编辑器

#### Scenario: 导出配套文档

- **WHEN** 教师从配套文档工作台或文件详情导出 DOCX
- **THEN** 系统从当前结构化修订编译带格式文档
- **AND** 导出不改变当前修订或源文件引用
