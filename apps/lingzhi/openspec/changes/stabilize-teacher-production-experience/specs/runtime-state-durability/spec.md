## Purpose

为任务状态、通用数据账本、服务启动、健康检查、备份恢复和故障观测建立统一运行时可靠性合同，在不打断活动用户任务的前提下消除静默丢状态和重复执行。

## ADDED Requirements

### Requirement: 生命周期边界必须严格持久化

任务创建、暂停、恢复、取消、确认、失败和完成等生命周期跃迁 MUST 在向调用方确认前完成持久化；持久化失败 MUST 回滚内存跃迁或进入明确 degraded 状态。高频进度 MAY best-effort 保存，但不得伪装成已持久化终态。

#### Scenario: 完成状态写盘失败
- **WHEN** 任务准备进入完成状态但持久化失败
- **THEN** 系统 MUST NOT 对外确认已完成
- **AND** MUST 保留可恢复的上一状态并产生运维告警

### Requirement: 任务索引必须从最后有效版本恢复

任务索引 MUST 保留可校验的 last-good 副本。主索引损坏或超限时 MUST 隔离原文件并尝试恢复 last-good；两者都无效时 MUST 进入 degraded 模式，允许读取正式课程但禁止创建、恢复或重跑任务。

#### Scenario: 主索引 JSON 损坏
- **WHEN** 服务启动时主任务索引无法解析而 last-good 有效
- **THEN** 系统 MUST 从 last-good 恢复并记录告警
- **AND** MUST NOT 将任务集合静默重置为空

### Requirement: 数据目录只能有一个任务调度领导者

使用同一数据目录的任务消费者 MUST 由单一领导者运行。服务 MUST 在读取和对账活动任务前取得领导者身份，第二实例 MUST 在触碰任务状态或执行恢复前退出或保持只读。

#### Scenario: 两个实例同时启动
- **WHEN** 两个进程竞争同一数据目录
- **THEN** 只有一个进程 MUST 启动任务消费者与重启恢复
- **AND** 另一个进程 MUST NOT 执行或改写任务

### Requirement: 通用数据更新必须原子且缓存一致

通用 JSON 数据的读改写 MUST 在同一互斥边界内重新读盘、写入同目录临时文件、同步并原子替换；只有替换成功后才能更新内存缓存。并发进程不得因旧缓存覆盖新数据。

#### Scenario: 原子替换失败
- **WHEN** 临时文件写入或替换失败
- **THEN** 磁盘正式文件和内存缓存 MUST 保持旧值
- **AND** 调用方 MUST 收到失败而不是成功回执

### Requirement: 健康检查必须区分存活与就绪

轻量存活检查 MUST 快速、无外部调用。就绪检查 MUST 返回版本、领导者状态、任务索引加载状态和数据目录读写能力；模型配置可检查但真实模型请求 MUST 留在发布探测，避免健康检查产生费用或延迟。

#### Scenario: 任务索引进入 degraded
- **WHEN** Web 服务仍可响应但任务索引不可恢复
- **THEN** 存活检查 MUST 成功
- **AND** 就绪检查 MUST 失败并给出安全原因码

### Requirement: 发布不得中断活动生成任务

发布流程 MUST 在停止服务前检查活动任务。存在不可安全中断的用户任务时 MUST 延迟发布并保留当前版本；不得只记录活动任务后仍继续重启。

#### Scenario: 发布前存在运行任务
- **WHEN** 发布检查发现活动生成任务
- **THEN** 发布 MUST 在停止服务前退出或等待安全窗口
- **AND** 当前任务 MUST 继续运行

### Requirement: 备份必须可校验和可演练恢复

运行数据备份 MUST 包含版本、文件清单与校验和，并能够在隔离临时目录完成解包和仓储读取验证。恢复演练 MUST NOT 覆盖生产数据。

#### Scenario: 验证最新备份
- **WHEN** 运维执行恢复演练
- **THEN** 系统 MUST 在隔离目录验证完整性和关键仓储可读性
- **AND** 生产数据 MUST 保持不变

### Requirement: 稳定性指标必须低基数且可行动

系统 MUST 记录任务等待时间、心跳超时、持久化失败、恢复结果、跨资产 partial 和模型错误分类。故障演练 MUST 在隔离环境覆盖磁盘满、损坏索引、双实例、跨资产中断和流中断。

#### Scenario: 任务持久化连续失败
- **WHEN** 生命周期持久化连续失败
- **THEN** 系统 MUST 产生带稳定原因码的告警
- **AND** 指标 MUST NOT 包含课程正文、提示词或其他敏感高基数字段
