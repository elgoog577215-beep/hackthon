## ADDED Requirements

### Requirement: 教师课程统一正式正文

系统 MUST 以教师工作台作为唯一新课程生产入口，讲义 MUST 保存在 CourseDocument 与 CourseBlock 中；教师仓储 MUST 只保存当前正式讲义引用及未发布草稿、候选和教案。正文、讲次来源和回执 MUST 原子提交。

#### Scenario: 两讲并发完成

- **WHEN** 不同讲次基于各自当前教案完成讲义
- **THEN** 系统 MUST 在课程锁中重新读取最新正文并仅替换目标讲次
- **AND** 同讲基线变化 MUST 返回冲突并保留候选，重复请求 MUST 不重复提交

#### Scenario: 教师试用学生所见

- **WHEN** 教师进入预览并试做或提问
- **THEN** 系统 MUST 使用正式公开正文与题目修订并验证所有权
- **AND** MUST NOT 新建正式学习事件、作答、画像或修改候选
- **AND** 来源变化 MUST 要求刷新，本次答案和对话 MUST 在退出预览时清除

### Requirement: PPT 显式选择来源后规划

PPT 工作台 MUST 依次提供选择内容、内容与排版、生成成品。来源 MUST 支持单讲、多讲、上传资料及组合；讲义生成 MUST NOT 自动启动 PPT 内容稿。系统 MUST 复用既有资料解析、内容稿和渲染器。

#### Scenario: 教师选择两讲和资料

- **WHEN** 教师选择两讲讲义与上传资料并点击下一步
- **THEN** 系统 MUST 绑定真实课程、讲次、正文修订和原件身份后解析规划
- **AND** 教师 MUST 可以编辑并确认当前内容与排版稿
- **AND** 最终渲染 MUST 使用该确认稿，不重新生成正文

#### Scenario: 来源过期或任务暂停

- **WHEN** 内容稿来源变化或教师暂停任务
- **THEN** 系统 MUST 拒绝迟到结果覆盖当前稿，保留最后成功成品
- **AND** 重试 MUST 复用与冻结来源匹配的既有检查点

### Requirement: 离线迁移与旧链退出

系统 MUST 提供预检、执行与校验；执行前 MUST 建立仓库外备份和校验清单。历史学生课程 MUST 保留，运行中的旧任务 MUST 按原协议恢复；旧整课新建请求 MUST 返回明确停用错误。

#### Scenario: 迁移来源冲突

- **WHEN** 教师稿与正式正文不同或身份无法映射
- **THEN** 系统 MUST 报告并停止该课程迁移，不覆盖正文，不调用模型
- **AND** 无冲突课程 MUST 可独立继续
