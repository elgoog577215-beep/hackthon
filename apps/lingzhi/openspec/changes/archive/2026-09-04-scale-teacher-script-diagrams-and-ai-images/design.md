## Decisions

1. **图解与 AI 插图是当前正式视觉类型。** 图解承担公式、概念、条件、因果、步骤和对比关系；AI 插图承担形象化解释、情境联想和版面节奏。系统不建立 `sourced_image`，也不把 AI 插图声明为历史证据。

2. **Prompt 是结构化产品政策的执行层。** 图解规划 Prompt 只能返回有界节点和关系，后端补齐来源锚点并验证；AI 插图 Prompt 从教学块内容和统一风格政策派生。两者不修改讲义生成 Prompt，也不写回讲义正文。

3. **图解先调用私有文本模型理解关系，失败后确定性降级。** 模型返回严格 JSON，最多修复一次；仍失败时使用已有句子编译器，保证正式入口不会因模型格式错误失效。前端始终消费 `DiagramSpec`，不执行 Mermaid 或模型代码。

4. **AI 插图只声明生成来源。** 候选保存 `image_origin=ai_generated`、提示词政策、模型和资产清单；未配置或失败时保留提示词，不创建占位图片。

5. **动画默认彻底退出运行面。** `TEACHER_SCRIPT_ANIMATION_ENABLED` 默认关闭。关闭时，后端不推荐、不返回、不生成讲义动画，前端不显示入口，共享消费者也不收到历史讲义动画；代码、旧规格和播放器保留，供未来重新评估。

6. **广泛使用不等于无差别自动插入。** 所有教学块都能生成图解或 AI 插图，系统按内容推荐；候选仍由教师采用后进入共享表达集，避免装饰性图片替代课程事实。

## Runtime flow

```text
当前讲义修订 + 教学块内容
-> 视觉类型建议（图解 / AI 插图 / 无）
-> 教师触发
   -> 图解：AI 关系规划 -> DiagramSpec 校验 -> 确定性降级
   -> AI 插图：提示词规划 -> 图片模型 -> 图片质量检查
-> 候选预览
-> 教师采用
-> RepresentationSet（teacher_script / slide_deck / learner）
```

## Boundaries

- 不新增真实图片检索、版权库或史料来源管理。
- 不删除动画代码或历史数据。
- 不让动画进入默认运行、推荐和下游装配。
- 不把 AI 插图当作事实来源。
