## Context

当前课程入口的主要等待链为：课程信息与整课正式预览 → 工作台挂载 → 大纲、全课备课、文件和其他阶段数据。正式预览由教师讲义投影完整 `CourseDocument`，而大纲页面只需要当前可用大纲。`GET /blueprint` 又通过 `get_course_or_404` 触发整课正文投影，然后重新构建和审阅大纲。全课备课接口同时返回所有讲次正文和任务摘要。这个顺序把不属于当前目标的数据放进关键路径。

## Goals / Non-Goals

**Goals:**

- 以大纲正文、当前讲教案和当前讲讲义真正可读为完成事件。
- 当前阶段只请求必要内容，父组件和子组件共享请求与修订快照。
- 保留正式正文、草稿、AI 候选、任务检查点、权限和版本冲突边界。
- 支持直接链接、阶段切换、断网恢复、迟到响应和多标签页修改。

**Non-Goals:**

- 不建立第二套课程正文、Store 或任务系统。
- 不删除历史修订、失败任务或恢复检查点来缩小响应。
- 不用简单延长超时、增加线程数或隐藏错误作为性能完成标准。
- 本 change 不改变课程内容质量规则、生成模型或教学流程。

## Decisions

1. **按当前目标选择读取，而不是先加载整课。** 路由阶段决定首个正文请求。大纲入口先读大纲；教案、讲义入口先读讲次摘要和目标讲；学生预览入口才读取完整正式正文。

2. **大纲读取使用原大纲真源选择。** 后端从原始课程记录和正式生成工作区选择当前可用大纲，不经过教师讲义全文投影。已提交课程、未发布工作区、失败新尝试与最后可用结果继续服从 `teacher_outline_source`。

3. **复用原 Store，并显式表达响应范围。** `courseWorkspace` 保存大纲的课程身份、修订和在途请求；`teacherLessonAuthoring` 保存讲次摘要及按讲正文。摘要中的“未加载”与“没有内容”必须可区分。

4. **缓存以内容身份失效。** 大纲响应 key 包含当前大纲来源修订、草稿修订、影响审阅的课程约束与质量规则版本。权限检查发生在缓存返回之前。服务端缓存有条数、单项和总字节限制；超大对象跳过缓存。

5. **当前讲优先，预取有界。** 当前讲正文完成后，只有网络空闲且无编辑冲突时才预取一个相邻讲次。快速切讲取消无用请求或拒绝迟到结果。

6. **HTTP 负责对账，事件负责通知。** SSE/WS 通知版本或任务变化；同一资源由一个 Store 发起 HTTP 对账。重连只执行一次必要读取，不因组件重复挂载并发请求。

7. **兼容按能力切换。** 新读取范围先由服务端提供明确 schema/capability，前端识别支持后启用。只有明确不支持才回退旧完整读取；权限错误、超时和服务错误不得触发更昂贵的隐式回退。

## Interface Direction

- `GET /api/courses/{course_id}/blueprint`：保持当前写入前置字段，读取实现绕开整课讲义投影；响应带 `schema_version`、`source_revision`、`draft_revision` 与 `quality_rule_version`。
- `GET /api/teacher/courses/{course_id}/lesson-authoring?view=summary`：返回讲次目录、当前修订、状态、任务摘要和生产状态，不返回各讲完整正文。
- `GET /api/teacher/courses/{course_id}/lesson-authoring?lesson_unit_id=...&content=plan|script`：返回目标讲当前正文、来源修订和相关候选。
- 现有无参数备课接口在兼容窗口继续返回完整视图。

## Failure and Recovery

- 有最后成功且修订仍匹配的内容时先显示，后台对账失败显示局部状态；编辑入口在版本未确认时禁用。
- 没有合法快照时显示真实加载状态，不能把空响应解释为未生成。
- 迟到响应必须同时匹配身份域、课程、讲次、内容种类和请求修订才能应用。
- 缓存异常只影响性能，不得绕过仓储读取、权限或冲突校验；必要时可关闭新读取模式回到兼容接口。

## Rollout

批次 A 交付指标、大纲直读和请求共享；批次 B 交付按讲读取与终态交接；批次 C 交付文件、列表、内存预算和渲染收尾。每批独立通过完整 CI、隔离浏览器性能验收和生产只读冒烟。出现串课、版本覆盖、正文消失或任务中断时恢复上一应用版本，保留用户新数据。
