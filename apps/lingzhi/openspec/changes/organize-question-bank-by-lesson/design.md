# Design

## Information hierarchy

题库正式浏览区使用三层关系：左侧第一列只负责选择讲次，第二列只显示当前讲次题目，中间区域显示选中题目的完整内容与操作。右侧真题资料栏保持原职责。

讲次列表读取工作台已经提供的稳定 `lesson_unit_id`、编号和标题。题目按 `node_id` 归入对应讲次；未匹配题目进入“其他题目”，避免历史或导入题目消失。未提供讲次列表时保持原全部题目行为。

## Compact rebuild state

重建状态与题库标题同层显示。默认态只保留结论、有效题目保护说明和重试动作；详细消息、失败讲次和进度放入原位展开层，不再改变题目工作区纵向位置。可访问进度条继续保留真实百分比。

## Interaction invariants

- 切换讲次会清空当前搜索和状态筛选，并定位到本讲第一题。
- 分页和相邻题导航不能跨讲次。
- 失败重试继续携带后端返回的精确失败讲次节点。
