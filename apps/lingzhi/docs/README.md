## 正式设计与差距

- [灵知产品蓝图](产品蓝图.md)：灵知教师备课与学生学习、教学核心与个人材料，以及共用能力、权限、版本和联动关系；按业务进入四层设计。启智项目保持不动。
- [当前阶段项目目标与开发准则](阶段项目目标.md)：AI 开发、评审和验收先读；以讲义自学 Agent 为产品定义，明确清晰讲解、三类教学块、画像自适应与教师联动。
- [学生学习](功能设计/学生学习.md)：自建/导入、学习教师课程、个人材料、阅读与练习；正文小框学伴、总体目标/计划与记忆、画像四类教学动作和主动程度已完成首版工程接入，见[本地验收](验收/学伴与师生学习闭环Spec落地验收-2026-10-23.md)。
- [课程修改与教学反馈](功能设计/课程修改与教学反馈.md)：课程影响、审阅采用与恢复；新增班级共性问题、授权依据下钻、教师主动请求建议及后续观察的二次备课规格。
- [课程知识树规格](功能设计/课程知识树.md)：先讲义再提取知识树，维护分类、知识身份与修订、教学关联和验收；v43补充短知识名、共享易错多对多与学习闭环的待实施规划，当前运行合同与实现证据分别标明。
- [产品状态](产品状态.md)：实现与蓝图的差距、待确认范围和验收依据。
- [教学内容模板](教学内容模板.md)：字段、术语、样例与尚待教师确认的学科设计。
