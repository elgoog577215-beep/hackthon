# 灵知项目文档

[应用 README](../README.md)负责介绍、安装和命令，[AGENTS.md](../AGENTS.md)负责项目约束。

## 正式设计与差距

- [灵知产品蓝图](产品蓝图.md)：灵知教师备课与学生学习、教学核心与个人材料，以及共用能力、权限、版本和联动关系；按业务进入四层设计。启智项目保持不动。
- [学生学习](功能设计/学生学习.md)：自建/导入、学习教师课程、个人生成材料与可调整路径，以及阅读、笔记、练习、错题、AI、继续学习及临时预览。
- [课程知识树规格](功能设计/课程知识树.md)：新课先知识基线再讲义；每课元知识树、完整教学关联、JSON、稳定 ID、关系强度及 24 项验收；经复核的限定样板已通过内容门槛，纯模型自动生成及产品接入尚未通过。
- [产品状态](产品状态.md)：实现与蓝图的差距、待确认范围和验收依据。
- [教学内容模板](教学内容模板.md)：字段、术语、样例与尚待教师确认的学科设计。
