# 学生学习

灵知面向学生成长，支持自主创建/导入课程和学习教师授权课程，并以这些教学内容为核心，形成个人学习路径与生成式复习、补充理解和应用材料。阅读、笔记、AI、练习、错题与继续学习承载实际使用过程。教师预览是临时模式，不代替正式学生服务。产品分工、共有课程、权限与版本规则见[产品蓝图](../产品蓝图.md)。

学生端围绕系统学习、期末备考和项目实践独立组织界面，不局限于讲义生成，也不要求与教师使用同一个生成控制台页面。个人讲义从本人资料与所选范围开始，共用原资料解析和讲义写作能力，按应试或整体理解组织正文，不以隐藏教案、行政字段或 PPT 为前置。完整业务设计与实施差距分别见本页及[产品状态](../产品状态.md)。参考依据见[学习 Agent 与历史界面调研](../研究/学生学习Agent调研.md)，开发范围见[学生学习空间](../../../../changes/学生学习空间.md)。

## 一、内容设计

### 三类学习需求

| 需求 | 学生提供什么 | 主要学习载体 | 怎样完成一次有效使用 |
| --- | --- | --- | --- |
| 系统学习 | 想学什么、现有基础、可用时间、选用资料 | 可调整的学习安排、系统讲义、例题、就地练习和个人笔记 | 学习一段内容，解释或练习，得到反馈，再选择继续或补充理解 |
| 期末备考 | 考试日期、范围、教师资料、已有错题或不熟悉内容 | 复习讲义、考点清单、专题练习、模拟练习、错题再练 | 在限定范围完成练习，定位具体问题，返回对应材料，之后再练；没有考试依据时不编造押题概率 |
| 项目实践 | 想完成的作品/问题、基础、约束、预期成果 | 项目任务书、里程碑、当前任务、所需知识、提示、作品提交与反馈 | 本人完成一个步骤并提交成果，依据反馈修订或继续，阶段回顾说明做出了什么、仍不会什么 |

三类用途沿用已有“系统学习、期末冲刺、项目实践”分类；“期末备考”是面向用户的场景表达，不新增重复业务类型。同一课程可以服务多种用途，切换用途不复制正文、笔记或题目历史。

项目内容不强制都变成讲义。任务应记录目标、当前步骤、需要提交的成果、完成标准和相关材料；提交应关联学生、任务、版本、作品与时间；反馈应引用具体提交并说明依据与未核实部分。文本说明、图片/文件和作品链接先作为提交形式，代码执行、互动实验等按具体任务再扩展。项目还可面向研究报告、调研或设计作品，不仅限于编程。

### 学习对象及其归属

| 对象 | 必须记录什么 | 保存责任 |
| --- | --- | --- |
| 学习中的课程 | 课程身份、来源、自有/获授权关系、当前可访问修订 | 共有课程与访问能力；课程库只查询和展示 |
| 学习内容 | 讲次、小节/内容块稳定身份、正文、学习目标和来源修订 | 正式课程拥有者；学习页不另存可独立修改的正文 |
| 笔记与引用 | 本人、课程、内容身份、来源修订、原引用、个人正文及记录修订 | 原学习记录仓库；随手记允许无原文锚点 |
| 作答与反馈 | 本人、题目修订、答案、提示使用、评分依据及反馈 | 原练习与作答仓库；草稿与正式提交分开 |
| 错题与再练 | 原作答引用、需要复习的依据、后续尝试关联 | 从正式作答派生，不另存第二套分数和答案历史 |
| 位置与进度 | 本人、课程修订、内容位置、真实学习事件 | 原学习进度/快照与事件能力；滚动不等于掌握 |
| AI 会话 | 本人、会话、发送时课程/内容/题目上下文及引用 | 原 AI 会话能力；不得冒充正式学习事件或课程正文 |
| 学习判断 | 使用的事实范围、解释与不确定性 | `LearnerModel` 可重算投影，不反写原始事实 |
| 个人学习材料 | 本人、用途、关联课程、来源对象/范围/修订、生成依据、正文及材料修订；区分课内、前置补充和拓展 | 独立材料对象复用共有内容与任务能力，拥有自己的写入责任，不成为教师正文副本 |
| 学习路径建议 | 当前目标、起点依据、建议顺序、材料引用、推荐理由、学生选择与路径修订 | 个人路径保存建议与选择；完成情况读取实际学习事实 |
| 应用成果与反思 | 本人提交的解释、作品/附件引用、自评和所用材料版本 | 复用个人记录与文件能力，区分学生作品、AI 示例和模型反馈 |

学生创建课程的输入包括学习目标、现有基础、希望覆盖的范围、时间与资料；课程名可编辑，行政代码、学分、班级课表、教案与 PPT 均非学习的必填前置。输入与生成细节由[课程生产](课程生产.md)维护。

### 生成式学习材料的内容

| 用途 | 材料应当提供什么 | 后续可以取得的学习依据 |
| --- | --- | --- |
| 复习与巩固 | 围绕选定目标整理要点、相互关系、个人疑问与代表练习，不把整课机械缩短 | 解释、检索回忆、练习及复习后的自评 |
| 补充理解 | 针对具体困难补前置概念、分步说明、例子与反例，保持原概念条件准确 | 学生能否解释原因、区分适用条件或独立完成相邻任务 |
| 应用与探究 | 围绕兴趣或真实问题给出可完成的小任务、支持材料和成果要求 | 学生实际提交的方案、作品、问题和反思 |

这些是本轮材料设计的代表用途，沿用已有“系统学习、项目实践、期末冲刺”学习目的，不新增一套互斥课程分类。每份材料讲清目标、与课程的关系、必要说明或任务、来源与后续行动；不强制每份材料都包含全部栏目。更广的跨课程、跨模态材料后续按真实需要扩展。

## 知识树联动的学生画像

2026-10-11 确认：以课程知识树的元知识点为学生知识画像的主坐标，通过真实学习证据更新个人掌握状态，再汇总分支与全课视图。目标、兴趣和时间安排保留为辅助个人信息，不合成为人格或成长总分。

### 初值、身份与证据

- 每个“学生 + 课程 + knowledge_id + 知识修订”维护可重算的个人状态；正式课程知识树不保存个人分数。沿用 `LearningEvent`、正式作答与学习记录仓储，不增加第二套事实写入。
- 初始实际掌握估计为 null、状态为“未评估”；界面允许已验证掌握进度显示 0%，同时明确“未评估不等于不会”。初测可直接提供证据，不要求从零刷起。
- 元知识点展示掌握参考值、证据充分程度、评估范围、更新时间、支持/反对证据与下一步。百分比是版本化规则的参考指标，未校准前不称为统计概率。
- 题目、被检查的解释和笔记内容必须精确绑定知识点及修订。综合题没有逐点评分时，只记录学习活动并提示待归因，不把总成绩分摊给所有关联点。未绑定或旧修订证据保留历史，不冒充当前掌握证据。
- 做题按独立完成、提示下完成、看过答案后完成分开。评分不可靠、未完成批改和缺少检查依据时不更新分数。一次错误可降低参考值，不能直接认定为稳定薄弱点。
- 阅读、保存笔记、复制 AI 回答、发起提问只形成活动/求助信号，不按次数加减掌握分；主动提问不扣分。学生自己的解释、例子、笔记内容可通过精确绑定的正式检查成为正负证据；AI 代写不算本人独立表现。
- 同一问题反复作答保留全部事实，当前评分只采用该题修订的最新有效结果，不重复刷分。接口重试和事件/作答双重记录不能重复计分。

### 首版参考算法与汇总

首版使用透明、可回放的规则 `knowledge_mastery_v1`，不调用模型来直接写掌握分：在当前知识修订下按不同题目修订取最新可靠结果（已完成批改且批改可信度至少0.72），独立作答权重为 1，提示下完成为 0.25；已看完整答案或检查依据无效时不提供掌握证据；评分规则明确不允许用于掌握验证的普通练习，只保留0.25权重的练习性证据，不计入独立掌握检查数。使用 `(1 + 正向权重) / (2 + 总权重)` 得到 0—100 的掌握参考值，没有有效检查时仍为 null。该算法是待校准的产品初版，不宣称其分数是客观能力概率；后续替换规则须保存规则版本并可从事实重算。

评估覆盖指存在有效检查，并不保证掌握。证据程度按不同独立检查数分别为有限（0—1）、中等（2）、较充分（至少3）；提示结果不能独自形成高置信掌握。参考值至少80且至少3个独立检查通过才展示“有掌握证据”；低于50且至少2个独立检查未通过才展示“待巩固”，其余显示“继续验证”。这些阈值是初版配置，须通过学科样例与真实使用校准。

首版对已采用范围内、非前置/拓展的唯一有效元知识点等权汇总：

1. 已验证掌握进度 = 各点当前参考值之和 / 全部计入范围的元知识点数；未评估点贡献0。这是课程进度，不能解释成实际只会相同比例的知识。
2. 评估覆盖率 = 已有当前有效检查的元知识点数 / 全部计入范围的元知识点数。
3. 已评估部分平均值 = 各已评估点当前参考值的平均数；没有已评估点时显示“—”。例如10点中6点已评估、平均70，依次为42%、60%、70%。

父分支只汇总唯一叶子；交叉引用不重复计入。分支与全课使用同一知识基线修订。关联强度不作为评分权重；前置知识可用于推荐检查，但不传播无直接证据的掌握结论。新增、合并和拆分节点必须标明基线变化，不把分母变化说成学生退步；跨修订复用需要显式等价映射，不能把旧高分复制给所有新叶子。

### 页面和验收

“学习概况”增加知识画像视图：顶部保留三项汇总，主体采用从左向右展开的真实树状图：课程为根，分类为可展开/收起的分支，叶节点为元知识点。叶节点用百分比圆球呈现掌握参考值，未知值使用灰色虚线圆球和“未评估”，不能伪装成0能力。点击圆球在中间栏打开知识点详情，展示当前点的参考值、证据、未评估/历史/辅助完成说明与来源定位；桌宠飞至右上角，展开带当前知识点引用的学伴对话。返回知识树或按 Esc 后保留树的浏览状态，并将焦点交还触发圆球。画布支持拖动平移、缩放、适应视图与全展开/收起；默认展开第一条路径，避免大量叶子同时挤在屏幕内。搜索和分支筛选只影响浏览，不能静默改变全课汇总分母。存在未知点时明确展示未评估数量；知识树未就绪与学生尚无证据分别呈现。

知识点详情默认只保留名称、分类、一个掌握度圆球与状态、核心规则和已有的具体例子。掌握度解释放入可展开的信息说明；学习记录按检查次数汇总，默认折叠，展开后保留检查结果、时间、支持程度与讨论入口。删除重复百分比、面向学生的“元知识点”标签、空泛下一步卡片和重复的“请学伴讲解”按钮；讲义为次级入口，仅在有明确对应题目时提供“练一道题”。例子来自课程内容或明确标记的演示材料，不能从掌握度推断或伪造。

学伴面板以对话为主体，支持新建、历史、收起，以及“切为浮窗 / 停靠右栏”按钮。切换展示方式复用同一组件、会话和草稿；浮窗首次居中，左侧知识详情、右侧对话；无背景遮罩、虚化或焦点锁定，正文可继续操作。标题栏可拖拽，右下角可缩放，均支持方向键；位置与大小限制在视口内，并可重置；停靠模式回到中间详情与右栏对话，收起后不为桌宠新增占位。知识点切换只更新显式上下文，不自动发送问题。提问引用知识点 ID 与修订；保存回答为笔记以该回答发送时的上下文为准，避免切换知识点后错绑。检查证据不足以还原完整作答时显示“讨论这次检查”，不伪装成完整作答回看。动画约 380ms，遵循减少动态效果偏好。

学伴顶部采用小头像、标题与紧凑工具栏，取消独立宣传语和大形象预留区；阅读侧栏不再显示“笔记 / AI 助手”切换，笔记与助手分别从底部入口打开。笔记对话保留“对话 / 整理稿 / 理解检查”功能，来源和输入区收紧，为消息阅读留出空间。浏览器本地只保存侧栏或浮窗的展示偏好；重新打开、刷新和切换课程都沿用该偏好。关闭浮窗直接隐藏，不先停靠，也不重建会话或清空草稿；知识点选择与退出不覆盖用户选择的布局。

正式课程学习页底部“知识树”进入同一横向知识树，点击叶节点打开精简知识详情并展开学伴；停靠后详情留在中间栏，学伴回到右栏。课程内容读取正式学习资产；知识树先行课程读取当前已采用的知识基线，不读取候选稿或历史稿作为当前知识。例子只使用当前讲义修订中精确绑定同一知识点修订的例子块，缺失则不伪造。讲义入口定位对应正文块；有精确题目关联时打开对应题目修订。个人分数只合并同课程、课程版本、基线版本与知识点修订的正式画像；教师预览展示真实课程知识，个人掌握状态保持未评估，不读写学生记录。

教师预览明确提示“不读取或写入正式个人画像”。本地交互演示与正式入口分开，标记示例证据，沿用同一后端投影规则生成结果，不污染真实课程和学生数据。正式页只消费真实接口；缺失的知识基线与评分绑定必须如实显示。

验收至少覆盖：初值未知、独立通过/未通过、提示与完整答案、仅提问/笔记不涨分、同题重复幂等、综合题不全点扣分、用户隔离、课程与知识修订隔离、叶子去重、分支与全课计算一致、范围变更提示、教师预览隔离、中英文和可访问的证据查看。

## 二、逻辑设计

### 三条正式使用路径

| 路径 | 使用过程 | 完成条件 |
| --- | --- | --- |
| 自主创建 | 目标/资料 → 可编辑学习范围 → 明确开始 → 共有生成任务 → 阅读与练习 | 本人拥有课程，过程可观察，可读结果保留，中断可继续 |
| 导入已有课程 | 选择文件 → 解析与范围核对 → 明确导入 → 正式课程 | 原文及来源保留，结构和公式问题说明，不凭重复提交创建副本 |
| 学习教师课程 | 服务端验证授权 → 可用内容与修订 → 学习现场 | 不出现教师私有内容/写入权限，个人记录真实独立保存 |

课程生成失败、题目尚未生成或来源暂不可用都应分别表达，不用整课失败遮住已有可读正文。正式学习不强制执行教师备课界面的每一步，也不调用教师预览 API 来代替持久学习。

### 从学习需要到个人材料

1. 学生从当前讲、自己选定的笔记/错题或一个学习目标进入，明确要理解、复习或应用的范围。只使用本人选择或该用途已获授权的证据，不默认扫描全部私人对话。
2. 系统展示生成依据与材料范围，区分课程要求、前置补充和兴趣拓展；缺少证据时使用学生自述及明确范围，不编造薄弱项或画像。
3. 学生明确启动后，沿[共同生产能力](课程生产.md#个人材料的生成与保存)生成、保存并打开材料；已有材料继续可用，生成失败可恢复。材料不必成为新课程，也不自动替换正式教材。
4. 学生阅读、编辑、练习或完成应用任务，形成与材料和题目修订绑定的真实记录。AI 示例不作为学生成果，保存材料不自动计为学习完成。
5. 学生结合实际困难与反馈选择继续、补充、重练或调整材料；再次生成有新修订与理由，保留原有记录和手工修改。

灵知独立运行时使用自建/导入内容作为来源；启智接入后，消费获授权的教材及边界，保留同源引用。学生材料可以拓展，正式教材的规范审查状态不会自动传给这些材料。

个人讲义右侧默认显示 AI 助手，可切换笔记、概念和来源。普通提问绑定发送时的当前章节；正文选段优先绑定该材料修订、章节及同一正文块，之后滚动不改变已发送问题的上下文。助手只读取这份本人材料、冻结来源和该修订的近期会话，使用真实章节和文件名说明依据；解释、举例与图解不自动改写讲义或笔记，也不记录为掌握。

对话复用原 AI 会话仓储，以本人、个人材料与修订隔离，回复复用原模型和持久任务。关闭页面只停止观察，重开读取同一会话；失败保留问题和真实片段，重启后暂停，由学生明确继续同一回复任务。二维向量和矩阵消元图与正文一起生成，坐标与步骤对应来源或明确假设例子的计算，不能用装饰性统计图代替学科含义。

进入助手先恢复本材料的对话，恢复期间仍可写问题，恢复完成后再发送。引用正文时，解释快捷操作明确指向选中内容；每条已发问题显示原章节和正文块，切换当前章节不改原范围。等待回答时可先写下一条问题，回复到达不得清掉新输入。停在末尾时跟随新增文字及随后绘制的图表；向上阅读旧消息后保持位置，可显式返回最新回复。切到笔记再回来保留未发送草稿。来源或草稿修订冲突时，提交操作显示为不可用，并提供重新读取入口，不能让按钮看似可用却静默不执行；重新读取不丢弃本人未保存的编辑。

### 路径调整与学生成长

首版先在单门课程、明确范围内建议下一步：沿课程顺序学习、补充前置、针对练习或应用任务。每条建议说明依据、通向的目标和可选动作，学生可跳过、调整或恢复默认顺序；跳过内容不自动记为掌握。面向有界教材的路径仍须保留共同必学要求，不足之处明确可见。

学生选择的学习目标可以包括理解与表达、迁移应用、问题探究或自主规划。系统结合解释、作答、作品和反思提供反馈，不将它们压成未经验证的“成长总分”，不以考试分数、点击次数或一次答对替代整体判断。推荐策略及效果需要真实样本验证；[课程知识树](课程知识树.md)提供元知识、问题、教学关联与来源定位，基础阅读和学习记录不以其生成完成为前置条件，复杂长期画像仍需独立验证。

### 阅读、记录与提问

阅读位置、原文引用与笔记在同一课程修订下定位。就地记录和笔记本使用同一个保存入口；慢网、重复提交和版本冲突时保留输入，明确正在保存/已保存/失败，不提前关闭编辑器造成误判。再次进入能恢复已保存结果和合法位置。

AI 问题锁定发送时的正文或题目范围，随后滚动不改变上下文。解释、举例和简化先作为个人帮助；保存笔记或应用课程修改是显式动作。学生可以按正式命令修改自有课程；学习他人课程时补充留在本人范围，无正文写权就不展示或接受“应用到课程”。

### 练习、错题与复习

学生出题从当前讲、选定资料、考试范围或本人错题进入，提供来源范围、题型、题量与难度选择；按场景提供随堂自测、专题练习和模拟练习。材料不足时说明依据缺失，不能将模型生成题标成教师原题或历年真题。沿用正式题库的正确性验证和题目修订，个人题目按本人作用域保存，不覆盖教师题库；完整答案与解析按练习模式在适当时机展示，避免生成结果直接泄露答案。

AI 帮助建议提供“给一点提示”“检查我的思路”“解释原因”“看完整解答”等就近动作；学生控制帮助深度，不强制反复问答，也不把看过解答等同独立做对。具体提示与生成方式不在本轮固定。

练习读取有权限的正式题目修订，草稿、提示、提交、评分与反馈沿原练习链完成。重试同一次提交不得重复记分，主动再次作答形成新尝试；错误提示不能假称已经保存成功。

错题本从本人正式作答及复习状态取数，可回看原题、原答案、解析和再次练习。再练关联原尝试，新结果不覆盖旧结果；错题列表、学习概况和 AI 引用必须能对账。同一题新修订与旧题区分，历史答案不按新题强行重判。

复习与继续学习按有正文及学习目标的内容身份计算，不把 `node_level == 2` 作为所有新课程的资格条件。阅读、提问和答对一次是不同证据，不能直接合成未经验证的精确掌握率。

### 课程更新与访问变化

遵守[蓝图的版本规则](../产品蓝图.md#版本更新与个人历史)：明确当前学习版本、受影响范围及返回位置。未变化内容继续使用；失去原定位的笔记保留原引用并提示重新定位；未提交的旧题草稿先核对题目版本，不能悄悄换题提交。切换新版本不得抹掉旧作答和学习记录。

访问撤销、课程删除或来源暂不可用时，区分无权、已删除和临时失败。本人记录按约定保留和管理，原文回跳受当前权限检查；不从缓存或历史引用接口绕过访问限制。

个人材料和路径同样遵守上述规则：来源变化先提示实际影响，学生决定采用哪个材料修订；受限原文与个人原创部分按来源许可处理，不能通过保存为个人材料绕过撤销。历史练习引用当时材料和题目，更新不静默重判。

### 教师预览

教师预览使用明确预览作用域和 owner 权限，锁定正文与题目修订。试做、问答和临时笔记只留本次会话内存，退出清除，不写任何身份的正式事件、作答、画像或记录。来源变化要求刷新。教师自己进入正式学习空间时则以本人身份保存学习事实，两种模式不能根据页面相似程度混用。

## 三、交互设计

### 学生课程库与入口

学生工作空间保留“我的课程”作为内容入口，首页优先显示继续学习及系统学习、期末备考、项目实践三类行动，同时提供新建、导入及可访问教师课程；明确课程来源与可执行操作。恢复早期以学习为中心的功能关系，沿用当前视觉与组件，不回退整套旧代码。

教师端右上角可暂放“进入学习空间”，进入正式学生首页；已有“学生视角预览”仍是课程预览，两者不共用临时记录语义。学生登录后可以直接进入学习空间，不必先取得教师身份或打开教师日历。入口位置不承担权限判断。

建议首版页面关系为：学习首页/课程库 → 阅读与练习，或复习工作区，或项目工作区。笔记、错题、材料在对应任务内可达，沿用现有工具入口，不为每种能力增加独立顶级页面。系统学习与备考共用阅读器，项目工作区按当前任务组织。

新建输入围绕目标、基础、范围、时间与资料；必要规划由共有能力承担。任务显示真实范围、已完成内容、等待或失败原因及继续入口。导入在正式写入前核对识别结果，识别失败保留原件与输入。

教师切入学习空间不改变角色和归属；学生不能通过切换按钮获得备课管理权。导航保持课程和位置，工作空间切换不取消已有后台任务。

### 学生学习现场

- 左侧显示讲次目录，中间显示连续课程正文。
- 学习者直接看见本讲要学会什么、完成什么和怎样证明学会。
- 正式练习从对应正文位置或课程练习视图进入，关闭后回到原内容锚点。
- 桌面阅读页右栏默认收起，仅保留放大的悬浮学伴；由底部笔记或学伴入口按需展开，切换保持 AI 会话、输入草稿和笔记编辑结果。全课程笔记本继续从底栏进入，负责搜索、分类、排序和导出。
- 有原文锚点的笔记以短条贴近对应正文位置，随正文滚动，密集笔记向下错开避免重叠；手动滚动笔记栏暂停跟随，可显式恢复。随手记与未定位的引用笔记归到本讲其他笔记，不伪造段落位置；点击笔记短条回到助手中的对应笔记会话，定位操作回到原文。
- AI 助手显示当前讲与小节。普通问题携带发送时的阅读位置，引用提问优先使用引用位置；之后滚动不改变已经发送问题的上下文。教师预览笔记仍只留在本次内存会话。
- 错题、复习与学习记录读取正式学习事实，不建立各自的进度副本。[课程知识树](课程知识树.md)作为课程内工具，按元知识查看问题、能力、易错与补救，并返回正文来源；实现状态单独验收，教师预览与正式个人学习事实保持隔离。
- 学习位置、笔记草稿和人工智能会话在合理范围内保持连续。
- 教师预览不读取或写入学生数据。

### 学生讲义中的教学图解

学生讲义应当支持教学图解，帮助独立阅读者理解概念、条件、步骤和证据。讲义是师生共用教材式材料，教师备课与学生阅读消费同一份已采用表达及其来源修订；学生不必先取得 PPT 才能看到图解。具体外部参考、44 种类型的适用性及阅读示例见 [Diagram Design 融入评估](../研究/diagram-design/README.md)。图型范围按内容需要选择，首批示例不成为永久白名单。

图解组织在连续正文中：图前说明当前问题与必要条件，图中呈现有依据的关系，图下注明结论、条件和来源；必要时接一个解释、判断或应用的小问题，解析沿已有答案展开规则处理。保留完整文字、公式和中间推导，学生能够只靠讲义完成理解；图解不替代正文或变成每段必有的装饰。

| 内容要解释什么 | 适合的图解 | 阅读中怎样使用 |
| --- | --- | --- |
| 前置、推导、因果与适用条件 | 带关系标签和条件的局部关系图 | 放在对应说明或推导旁；完整步骤与来源可回看 |
| 分类、包含与集合交集 | 分类树、嵌套图、Venn 图 | 区分父子、范围和交集；没有交集依据时用比较表 |
| 方法差异与易混概念 | 同维度对照表或并列比较 | 放在辨析处，保留共同条件；图后可接选择理由的问题 |
| 算法、实验、交互与状态 | 过程、分支流程、时序或状态图 | 条件出口、消息方向与转换触发须明确，按教学内容选择 |
| 发生时间、阶段与真实循环 | 时间轴或循环图；采用参考库的 Loop 布局时须有共同汇总状态 | 时间间隔如实编码，循环须确实返回起点；没有时间数据时只表达顺序，不假装有时间尺度 |
| 数量、变化与分布 | 条形、折线、散点及其他有数据依据的统计图 | 数值、单位、尺度、统计条件和来源就近可见；缺失值不当成零 |

核心图默认在相应正文位置可见；复杂细节可展开或放大，返回保持阅读位置。已有概念关系面板用于概览、定位和回跳，不能承载所有正文图解，也不占用学生“笔记 / AI 助手”右栏或新增全课程知识图谱。图型数量和密度由本段教学任务决定，内容不需要图时继续使用文字或表格。

AI 回答解释当前内容时也可按同一类型库选择图表，继续遵守当前文件范围、来源与答案披露。回答图表保存在原 AI 消息中，不自动采用到正式讲义或记录为掌握。侧栏保留可读字号，复杂图可滚动或放大；图表未完成、格式不支持或数据不成立时保留文字说明。当前实现复用共有阅读组件；此项接入不开放冻结中的学生身份、个人材料任务或学习记录入口。

图解的语义来自正式内容、已有明确关系或已采用的图解候选；不能根据标题、段落邻近或模糊相似性补出箭头。老师提供课程中的图解由有编辑权者维护，学生只读；学生自有课程按本人权限编辑，个人补充表达归本人材料，不覆盖教师正文。私有答案、讲者备注、教学指令、未采用候选及过期表达不进入公开学习投影。

图中的来源、正文跳转、引用笔记和提问使用同一内容身份与修订。查看、展开或下载图解不自动计为掌握；正式作答仍走原题目与记录链。打印/导出保留获准公开的图、图注和来源，复杂图提供清楚的静态表达及完整文字；暂不可用时不阻断已有正文阅读。

### 笔记本、错题本与继续学习

笔记本支持课程内查找、分类、编辑和返回原文；错题本支持按讲次/复习状态筛选、回看原作答与针对再练。二者是原记录的整理视图，不再独立维护学习事实。课程内这些能力是本轮交付范围，跨课程聚合可以复用相同记录后续扩展。

继续学习展示上次位置和有依据的可选行动，不把模型猜测写成必须执行的路径。练习打开时能看见相关题面和上下文，退出返回原内容锚点；笔记或答题保存失败就近提示并保留草稿。

预览模式明确说明记录不会保存；正式模式显示真实保存状态。内容更新、无权限和暂不可用都给出原因及合法恢复动作，不展示一个笼统空页。

### 我的学习材料与下一步

课程内提供“我的学习材料”，从正文、笔记或错题进入时保留选定范围。生成前简要呈现目标、来源、所用个人记录及材料用途，允许修改；已有目标足够时不重复填写整套建课表单。

材料列表按课程及用途组织，显示名称、目标、来源更新状态和上次使用位置。打开材料沿用连续阅读、笔记、AI 与练习组件，明确标识“个人学习材料”；来源可访问时能返回正式课程，拓展内容显示与课程要求的关系。编辑、重新生成与删除作用于当前个人材料，不作用于教师教材。

继续学习保留上次位置，并在有依据时给出可选择的下一步及简短理由。学生可直接继续、调整目标或选择其他行动；不强制接受画像和推荐后才能阅读，不增设独立的成长排行榜或复杂导航。具体视觉布局在实现时沿用现有组件验证。

### 项目实践工作区

建议左侧显示里程碑与当前步骤，中间显示任务要求、学生作品与反馈，右侧复用笔记/AI 辅助；需要补知识时就地打开相关材料并能返回原任务。每一步都能看清“要做什么、做到什么程度、提交什么、卡住怎样求助”。任务讨论、资料阅读和作品提交共享当前上下文，彼此不冒充完成状态。

完成当前步骤后呈现实际成果、反馈依据、待改事项和继续动作；学生可以修订、回看或稍后继续。首版不以 AI 多人讨论、自动代做整个项目或额外生成长报告作为主要体验。实验模拟、画布与运行环境属于后续按任务验证的载体。

### 个人材料与路径的实现责任

现有课程、笔记和 AI 会话不能直接充当个人生成材料的存储合同。材料拥有者、来源引用、修订与授权检查按[共享对象与数据合同](../产品蓝图.md#共享对象与数据合同)实现，并复用已有文件/正文保存、生成编排及 TaskManager；新增领域对象不意味着复制底层能力。生成输入绑定实际采用的个人证据及版本，日志不保存这些私人内容。

路径建议与实际学习事实分离；建议改变只形成新路径修订，不能回写完成状态。材料中的正式练习沿同一题库/评分规则创建独立题目修订，并绑定个人可见范围；未保存的 AI 示例不进入正式分数与错题。应用任务的反馈保留证据与不确定性，首版不新增独立自动评分系统。

跨应用来源按[蓝图的同源边界](../产品蓝图.md#同源数据与跨应用边界)检查授权；课程、材料、学习者、生成任务和缓存之间保持同一作用域。私有材料及其下载不可因引用公开课程而变成公开内容。

### 现有代码怎样承接数据关系

| 现有位置 | 可以复用什么 | 必须补齐或保持的边界 |
| --- | --- | --- |
| `course_repository.py` 与 `teacher_content_projection.py` | 正式课程读取与教师正文投影 | 从统一访问能力取得合法来源；投影不能承担个人材料的写入 |
| `learning_asset_storage.py`、`routers/learning_assets.py` | 全课程学习资产的不可变修订与题目等关联 | 当前资产按课程保存，没有个人材料归属；不得直接把个人材料塞入全课共享 bundle |
| `learning_records.py`、`routers/learning_records.py` | 用户/课程隔离、记录修订、幂等及笔记生命周期 | 扩展课程内容/个人材料作用对象和锚点解析；慢网与冲突不丢输入，跨进程读写按共同存储规则核验 |
| `learning_events.py`、`learning_runtime.py` | 真实事件、实体引用与运行协调 | 材料使用事实绑定材料修订；生成与推荐不伪造阅读、作答或掌握 |
| `jobs/manager.py` | 持久任务、状态、队列、停止与恢复 | 新任务类型须一起接入执行、状态查询、重启恢复、暂停/取消、幂等及清理；私有输入不随公开任务响应泄露 |
| `LearnerCourseView.vue`、`LearningDock.vue`、现有阅读与笔记组件 | 连续阅读和课程内操作 | 扩展当前学习对象上下文，材料页面与课程页面调用同一记录规则；教师预览仍不写正式数据 |

当前 `get_course_or_404` 负责加载，不是统一授权服务；`qizhi_auth.py` 默认仍只接收教师/管理员；旧课程发布标记也不是新设计的共享授权。接入个人材料前联合落实身份与资源判断，不能单独放开角色白名单或凭课程可读取就允许生成个人材料。

### 作用对象与阅读连续性

学习页和原记录 Store 使用[蓝图的作用对象引用](../产品蓝图.md#学习记录怎样关联个人材料)。当前阅读对象可以是正式课程内容，也可以是某份个人材料修订；原课程、讲次和来源回跳同时保留，但不混用正文位置。切换对象前处理未保存输入，异步返回须核对当前对象，旧请求不能覆盖新材料。

“我的学习材料”列表按本人和课程查询，只返回有权限的摘要；详情读取指定材料及修订，再解释来源更新状态。进入阅读后恢复该对象上次合法位置及记录；回到课程恢复课程自己的位置。两名学生看同一讲时，列表、记录、生成进度和 AI 上下文不能串用。

生成按钮沿[请求与持久任务合同](../产品蓝图.md#个人材料请求与持久任务)工作：首次提交保存请求身份，断连重发对账原任务，主动改变要求才建立新尝试。浏览器不独立保存第二份材料正文或推断任务成功。任务已完成但详情读取失败时重读产物，不重新请求模型。

### 联合验收

至少覆盖学生自主创建、导入、学习教师课程、教师正式学习与教师预览；两名学生共用一门课时个人数据隔离。逐项验证读取、记笔记、提问、练习、错题再练、关闭后再次继续，以及重复提交、慢网、并发保存、版本变化与授权撤销。

已有 `backend/tests/test_teacher_preview_unified.py` 只能证明相应预览边界；正式学习还须运行实际完整流程，教师生产回归与学生验收同时通过才证明共用能力可交付。

个人材料至少以两名学习者、同一核心内容、不同目标/困难验证差异的依据，覆盖复习、补充理解和一个应用任务。检查默认路径、调整/拒绝建议、材料保存与再次进入、来源变化、授权撤销、手工修改保护及失败恢复；作品与反思确由本人提交。能生成不同材料只是功能证据，理解或应用是否改善还需真实学习样本。

存储与接口验收须额外覆盖：相同请求 ID 重发与不同输入冲突；材料 A 的迟到响应不覆盖材料 B；保存后任务历史被清理仍可读取来源与正文；旧修订笔记仍能追溯；只读课程权限不能越权编辑教材或读取他人材料；排队期间撤销授权与保存前来源变化都能阻断旧写入。以上是目标验收条件，当前源码存在相应模块不代表已经通过。

课程页继续沿用原顶部工具栏、左侧课程目录、中间讲义与右侧笔记/学伴的三栏布局。知识树复用底部原入口位置，打开时中间切换为树，未开启的侧栏不占位；保留进入前的课程版本、章节、正文块与块内位置。“返回讲义”或再次点击底部“知识树”恢复原阅读位置与侧栏状态；“查看相关讲义”和主动选择目录则进入明确目标，不被旧位置覆盖。切换课程或版本后不恢复失效位置。

已采用知识树自带的经核验检查题可作为正式练习的只读来源：材料修订或知识规则/条件不匹配时停止暴露旧答案；题目及绑定冻结到知识点修订，不因页面刷新而换身份。精确数值/类型名题使用确定性判分，解释类仍按正式评分合同处理。例子、题目、知识点和评分使用同一当前基线，候选不自动覆盖。

笔记定位先尝试原文标注，再依据笔记持久锚点定位仍存在的对应正文块；旧来源失效需要重新确认时不冒充精确定位。保存 AI 回答使用该回答提问时的上下文，不采用之后切换到的新知识点或当前阅读的引入块。

### 学伴主动提醒

学伴在正式学习页读取当前课程本人的记录；教师预览不后台检查。保存笔记后等待输入稳定，再串行检查最多三条未检查的已保存笔记，优先当前讲；使用现有模型和课程原文，只提示有原文引用的明确矛盾，不因省略、提问或不确定表达报错。结果显示“可能需要核对”，同时可展开课程依据，不改笔记、课程、掌握度或正式学习事实。检查失败不当作检查通过，不自动循环重试。

同一笔记修订不重复检查或弹出；切换课程、版本、语言、笔记修订或暂停时取消旧观察并丢弃迟到结果。气泡另支持到期复习记录、当前讲未解决疑问；只显示一条，点击定位笔记及原文，可忽略或暂停，并从学伴铃铛恢复。页面隐藏时停止发起检查，提醒依据仅来自本课程已授权记录，不扫描其他应用或私人对话。

用户首次进入已加载的正式课程时，学伴复用现有气泡说一句欢迎语，介绍选中文字记笔记、提问，以及底部的笔记和知识树入口，不做多步导览。点击“知道了”或关闭后，按学习者身份在当前浏览器记忆，刷新或进入其他课程不再重复；教师预览、生成预览和专注模式不弹出。欢迎语优先于普通提醒，不创建 AI 会话或学习记录；文案同步支持中英文。

### 笔记与讲解共用学伴会话

保留讲义原有文字选区菜单（问 AI、记笔记、稍后处理、标色和格式）及块级解释、举例、简化、提问入口，不翻新入口样式。正式学习页的问 AI、记笔记和块级讲解进入同一个学伴组件，历史以笔记/讲解标签区分。一个来源复用一个会话；已保存笔记以记录身份回到原会话，讲义文字标注和块后简短标记均可进入。

会话提供对话、整理稿、理解检查三个视图。用户可直接编辑整理稿；相邻笔记只取本人同讲同版本、按正文块距离排序的最多三条，并可打开原记录。每轮对话由 AI 同时返回回复和更新后的整理稿，结合引用、近期对话、当前手工编辑及邻近笔记持续完善同一段内容；不再要求点击整理或采纳。没有实质新增内容时保留原稿。用户随时可查看和修改，只有确认保存才更新正式笔记。AI 等待期间产生的手工修改优先保留；其他客户端已修改时拒绝过期回复覆盖。保存更新同一条学习记录，保存版本可恢复到整理稿，恢复并不立即覆盖正式笔记。历史与草稿归属原 AI 会话，正式笔记仍由原学习记录仓库唯一保存。

来源、知识修订和编辑修订发生变化时拒绝旧请求。网络失败保留输入；本机恢复稿与最新会话不一致时提示核对。教师预览只在会话内存试用，不新增正式笔记、检查事件或个人画像。旧来源会话可查看，不能沿用旧绑定写入当前知识结果。

理解检查要求用户单独提交自己的解释，服务端只检查当前正文块精确关联的一个原子知识点及其修订。保存、对话和自动更新整理稿都不直接加分；可信度不足或无精确绑定时不更新掌握度。已有 AI 帮助按辅助证据处理，完整 AI 整理稿已展示时本次检查只反馈、不提供掌握分；用户可从知识树使用新题独立验证。检查事实进入 LearningEvent，画像使用原有权重规则重算；同一知识问题跨笔记和重复提交只保留最新可靠检查，不能靠多建笔记积累独立检查数。
