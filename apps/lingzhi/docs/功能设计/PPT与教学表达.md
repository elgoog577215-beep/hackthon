# PPT 与教学表达

PPT 把当前讲义变成面向学生的课堂画面；内容稿、网页预览和最终文件共享来源与页面定义。它不能反向改写课程知识。共享定义见[产品蓝图](../产品蓝图.md)。

## 一、内容设计

`ppt_manuscript_v1` 是讲义与 PPT 之间唯一的逐页内容合同：页数、教学任务、主要结论、可见文案、页型、版式、构图、来源范围及证据关系。模板保存不可变版本、几何、槽位和容量，页面稿保存对应版本与摘要。

学生画面只保留当前教学动作需要的定义、条件、推导、例题、步骤、结论和任务；完整来源及讲述备注进入 notes。讲义正文、内容稿、已确认稿和导出文件是不同对象，不能由导出器二次总结覆盖内容稿。

图解与插图绑定讲义修订、内容块及指纹；AI 插图明确标记来源。教师上传原有 PPTX 保留不可变原件，页面与文字索引服务独立审阅，不默认重生成。

### 在启智与灵知中的位置

PPT 与教案、日历一样，是课程上的教学用途能力，不是学生创建、导入和学习课程的前置条件。学生课程已有可用正文或题目时即可学习；不因没有 PPT、教案文件或模板认证而阻断。

本业务承接启智基础生成链中的课堂表达，并参与联动分析与更新。灵知的个人复习/学习材料由[学生学习](学生学习.md)组织，按用途复用内容表达与渲染能力，不强制把每份材料做成 PPT。个人材料需要拓展解释时在其生成阶段明确来源，最终 PPT 渲染仍只消费已确认稿件。

教师授权提供课件时，学习者按相同课程访问规则读取允许的成品及其来源版本；内容稿、原件、讲者备注、私有答案和审阅候选不会因为课件共享而全部公开。正式课程正文仍是内容来源，课件阅读不生成第二份课程。

## 二、逻辑设计

1. 当前讲义完成后可独立使用；进入 PPT 读取已有稿，没有稿时由教师显式生成。
2. 内容稿从当前讲义及允许资料形成，保持来源完整与顺序，教师可编辑和预览。
3. 内容稿有独立质量门和确认；未确认可以查看快速预览，但不能直接发布最终成品。
4. 最终渲染只编译已确认修订，不再调用内容或视觉模型改写知识；模板版本或摘要不一致则阻断。
5. 来源更新先形成同步建议，经教师采用再更新稿件；PPT 编辑不改变讲义修订。
6. 导出是持久任务。失败保留合法检查点和最后可用文件，恢复只处理缺失单元；普通预览不生成文件或启动持久导出任务。
7. 上传原件单独对照课程审阅，手工/AI 修改形成可恢复修订，教师决定后成为当前 PPT。

多讲合并、纯上传资料、实验三阶段链已有历史实现与验证材料；当前分讲主链的适用范围按[产品状态](../产品状态.md)核实，不能把历史成功样本当作全链默认开放或新增需求确认。

### 课程更新后的学习使用

新讲义只把实际受影响稿件/课件标记过期，最后可用成品与既有下载保持对应来源修订。教师决定何时更新和提供新成品；学习者看到明确版本或更新提示，不以旧课件冒充当前正文。图解与插图仅在已采用、未过期且获准公开时进入学习投影。

联动更新尽量复用来源与模板未变的页面，对受影响页面形成候选，不因局部知识或日历日期变化全量重生成。教材规范审查、内容稿确认和渲染通过是不同结论；PPT 新页面或个人材料不能自动继承来源教材的审查状态。

## 三、交互设计

### 演示课件工作区

PPT 直接使用工作台选中的讲次，左侧固定二级目录切换不同讲次；顶部只有“内容｜渲染”两个同级 Tab。内容默认连续显示整讲页面正文，编辑与导出沿用教案右上操作栏。当前讲次 PPT 不显示右侧状态资料栏，也不要求创建项目或确认后才预览。

进入 PPT 时读取当前讲次已保存的页面内容稿，并准备当前页预览；尚无内容稿时，由教师主动启动生成，以当前讲义修订为来源独立形成内容稿。讲义完成后即可独立使用，不等待内容稿生成。编辑停止 400 毫秒后自动保存，保存成功更新相应预览；两个 Tab 共用当前页位置。冲突和保存失败保留输入，切讲前完成保存保护。讲义变化后提示同步，生成候选供教师采用。导出是独立持久任务，不阻塞快速预览。

历史 PPT 项目、原件上传审阅保持独立入口和既有恢复能力。新旧讲义缺少页面内容稿时，均通过当前讲次的显式操作生成；已有内容稿继续编辑，讲义变化后通过同步建议审阅更新。学生预览保持原完整学习界面的布局和组件。

PPT 局部视觉采用浅灰工作区与白色正文纸面，紫色用于当前选择和主要状态。复用系统字体、`TeacherDocumentCommandBar`、`UiSegmentedControl` 与现有图标；正文及主要操作不低于 15px，稿件阅读约 17px。顶部轻分隔，纸面少量圆角，不堆叠重卡片、渐变标题、装饰图标或密集小字。保留悬停、焦点、加载、禁用和未保存保护。

## 四、技术设计

### 共享消费与权限

PPT 生成和编辑继续归教学产物能力，学生读取已有成品复用资源授权与下载规则，不获得生产接口写权。学习侧与教师预览使用同一来源解析能力、各自身份和数据行为；给学习者的公开投影必须过滤备注、候选及私有资料，不能直接返回教师工作台响应。

### 当前讲次入口与来源

显式 `/ppt-v6/manuscript/complete` 复用 `teacher_script_ppt.py` 的页面合同，以当前讲义修订独立形成稿件。PATCH 检查预期修订，来源同步先保存候选再由教师采用。`ppt_preview.py` 从已保存稿件输出与 PPTX 共用的页面执行数据，缓存键包含课程、讲次、页面、模板、字体、素材及运行版本，不生成文件。`ppt_projects.py` 承担历史入口，不能取代当前讲次流程或回写讲义。

稿件以 `ppt_manuscript_v1` 保存页面内容、来源 ID/范围/修订、教学单元及模板版本；正式导出由 `compile_slide_deck_v6_from_manuscript` 消费已确认修订。来源变化阻断旧稿直接更新，模板摘要漂移或版本缺失阻断编译。模型输入可以压缩，但未压缩来源仍是校验依据，不能以压缩输入覆盖原文。

### 内容规划与容量

页面先选连续来源再写可见文字，数字、公式、专名和代码须有来源；来源全覆盖与首次使用顺序均需验证。模型只选择页面语义、组合和字段，不决定几何、字体或颜色，也不能自行补出未知教案时长。整讲保留开场、学习路径和收束；教学块数不机械等于页数。

整讲模型投影由 `compact_teaching_request` 去除重复背景和可还原元数据，保留稳定 ID、标题、必要摘录和保护符号。每页容量错误返回该页修复，局部修复只改变允许字段，不影响其他已通过页面；篇幅建议不能挤掉后续来源。

`ppt_page_repair_units` 可按标题、段落和代码行切成逐字连续的来源范围。纯代码按真实模板容量确定性生成续页；正文可返回有界页面表单。提供方持续不可用时停止重复请求，允许的降级只能按原文顺序形成可完整拼回来源的短要点页或代码续页，明确记录降级，不发布截断摘要。恢复只处理缺失合法页面的范围。

### 页面、模板与渲染

| 责任 | 实现入口与约束 |
| --- | --- |
| 原件与组合 | `ppt_compositions.PRIMITIVES / COMPOSITIONS` 保存节点、连线、卡片、图表与有限页面组合 |
| 内容合同 | `PageContentContract` 固定意图、结论、对象、关系、证据、组合与区域容量 |
| 设计变量 | `slide-themes.json.component_tokens` 保存颜色、字体、图标、间距、圆角及线宽 |
| 固定版式 | `ppt_fixed_templates` 与 `ppt_classroom_design` 固定页型、槽位和坐标，旧稿按锁定版本读取 |
| 页面表单 | `ppt_fixed_draft` 转为既有 `PageTeachingV2`，只让模型填当前页面所需字段 |
| 精确绑定 | `ppt_layout_binding` 将语义 `layout_key` 绑定冻结版本 ID；只有结构唯一匹配时可纠正未知布局，歧义和冲突阻断 |
| 共享画面 | `ppt_page_scene` 生成 Web 和 `ppt_native_scene` 共同读取的场景，不能由浏览器重新解释稿件 |
| 质量门 | `ppt_manuscript_quality` 统一保存、API、编排器与最终编译的准入；篇幅建议和来源/结构阻断分开 |

`ppt_presentation.presentation_states` 是规划、编辑和局部重生共用的分页入口：完整页、问答分步与关键停顿分别说明理由；连续相同可见集合合并，讲述备注及身份保留。公式和引文不能挤进只接受简短文字的比较槽位。图表保持共同单位、零基线和一致比例，比较表按实际内容分配行高；固定换行按字体和行距检查横纵溢出。

最终文件须回读对象、文字、字体、颜色、对齐、关系及备注，再通过溢出检查。固定版式不强依赖 PDF/OCR；复杂 `teaching_layout_v2` 模板还需相应原生及 LibreOffice/PDF 认证。字体、编译器、渲染器和工具版本参与恢复身份，本机认证不能替代生产 Linux 认证。

参考模板导入确定性解析 Slide/Layout 关系、继承占位符、几何和容量，保留来源页及对象 ID。AI 在合同内选择结构，不能改模板几何。个人模板先认证及维护者校对，再发布不可变版本；不能静默换成内置卡片。

### 图解、插图及历史路径

图解/插图候选精确绑定讲义修订、小节、块及内容指纹。图解规划只产生带逐字来源的有界 JSON，关系使用白名单，经校验编译为 `diagram_spec_v1`；不执行模型生成的脚本或任意 SVG。失败可以使用明确同源的确定性图解。

插图先保存提示词与 pending 候选，图片通过校验后进入不可变仓库，保留 `image_origin=ai_generated`；未配置提供方或失败时不造占位图。只有已采用且未过期的表达进入共享消费投影，来源变化标记 stale。PPT 和学生页面是否已经装配这些表达由[产品状态](../产品状态.md)说明。

上传 PPTX 保留原件和页/文字块索引，独立形成审阅与修改修订，不冒充完整视觉编辑器。V5 保留历史读取和导出，新写入使用 V6。讲义动画与三阶段实验链由既有开关控制；实验链复用原稿件和 TaskManager，不新增课程或任务真源，不因文档调整改变开关。专用运行时和依赖显式安装、独立认证，不随普通发布顺带升级。

### 验证与材料

[定制模板与上传清单](../PPT定制模板与上传清单.md)保存页型和上传要求；[模板参考](../研究/PPT模板参考/README.md)保存第三方来源与授权；[固定评测样例](../评测/课程与课件样例/README.md)包含成品与质量反例。它们不重复定义生成流程。

验收同时证明无 PPT 的学生课程仍可完整学习、成品访问不泄露教师私有内容，并分别检查稿件来源、确认后无模型改写、网页与文件一致、公式/代码/表格、字体与溢出、模板版本、来源过期和失败恢复。预览能显示不等于最终文件通过；真实导出通过不等于教师教学质量通过。

局部更新还须核对未受影响页面与人工修改被保留，以及实际生成/渲染范围；个人材料的来源和公开权限不因复用渲染能力而改变。性能比较必须在同等成品质量下进行，不以漏页或截断内容换取低成本。
