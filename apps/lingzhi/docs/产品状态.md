# 灵知产品状态

维护 `apps/lingzhi` 当前实现、设计差距与证据入口；`apps/qizhi` 保持原范围。以下由既有记录整理，未重新运行模型、浏览器或生产验收。不同能力按各自证据的日期和版本判断。

## 1. 当前重点

1.1 师生界面：教师课程表、课程内备课与学情入口，学生课程卡片、个人讲义阅读及底栏已完成本地核对。学校联合登录、完整班级画像、红绿时间线及自适应效果仍未验收。详见[10月20日界面记录](验收/产品状态历史记录-截至20261020.md#当前师生界面2026-10-20)。

1.2 课程生产：大纲整份、教案与讲义整讲生成已完成 G1/G2 局部实施与验证，支持恢复、流式读取和完整保存。旧链退出、跨学科质量及完整发布条件未全部关闭；按[生成链路变更](../../../changes/生成链路收敛.md)与 [G1](验收/生成链路G1大纲验收.md)、[G2](验收/生成链路G2教案与讲义验收.md)证据继续判断。

1.3 学生学习：个人讲义、教师授权课程、固定版本发布、作答回执、提问回复与错题再练已有本地证据。个人资料不随课程交换；学生自主正式课程、项目实践、完整知识绑定和生产恢复仍有缺口。详见[学生学习空间](../../../changes/学生学习空间.md)。

1.4 知识树：现行入口从已保存讲义按讲提取，支持候选、版本、采用及跨讲关系；早期资料先行过程留作历史。结构通过不等于教学语义通过，实际采用范围与失败记录见[历史核对](验收/产品状态历史记录-截至20261020.md#讲义后知识树2026-10-12)及下表。

1.5 画像与笔记：逐知识点投影、版本冻结、笔记及 AI 会话已有实现；活动计数不等于掌握，旧版本、答案揭示和不精确绑定不构成独立掌握证据。真实效度、综合题逐点评分、长期校准及统一权限恢复仍待验证。
