# PPT 三阶段工程验收样本

记录日期：2026-09-06。下文描述当时分支和运行结果，不代表当前合并、部署或验收状态。

这份样本用于检查“讲义 → 页面内容稿 → 已确认稿确定性生成”的实现。源讲义仍有把矛盾行与非阶梯形混淆的知识问题，尚未通过教师教学评阅，请勿直接作为正式授课版本。

| 环节 | 本次结果 |
| --- | --- |
| 内容 | 当前真实线性代数讲义的 21 个源块形成 35 个内容页；逐步展示确定为 119 张物理页。来源原文保存在备注中。 |
| 模板 | 两主题各 13 个组件版式，共 76 张合成样本通过本地认证；整讲实际使用 7 类版式。 |
| 交互 | 教师 API 保存、确认、生成及下载成功；过期保存与确认均被 409 拒绝。比较维度的浏览器修改已真实保存、重新确认，并出现在预览中。 |
| 导出 | 119 页通过原生对象、PDF 文本和 OCR 检查；重复导出的语义对象、来源、页序和备注一致，最终模型调用为 0。 |
| PowerPoint | 已实际打开 119 页文件，抽检矩阵比较页、行内公式与引用页；矩阵文字对象可选择，字体为 Noto Sans CJK SC 20pt。 |

PPTX 与 PDF 对应同一套已确认场景。PPTX 中的公式采用可编辑符号文字；数据图表支持原生文字与形状，不代表 Office 原生公式或可编辑数据系列图表。

本轮还修复了固定换行文字被重复估算换行、行内公式标记残留，以及新建生成任务误用内容规划检查点的问题。完整工作台导航、分支与练习的 PowerPoint 抽检、另外两类真实讲义、教师评阅和生产灰度仍待完成。功能默认开关保持关闭，分支未合并 main，未部署。
