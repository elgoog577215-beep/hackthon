# 课程与课件评测样例

这些文件是项目构造或生成的固定测试材料，供团队检查生成质量、版式和来源一致性。不是教师上传的原始教材，也不是生产课程数据。历史检查通过仅覆盖各自记录的范围，不代表当前功能或教学质量已验收。

| 样例 | 用途 | 检查方法与边界 |
| --- | --- | --- |
| [生成链路收敛](生成链路收敛/README.md) | 三组自编合成输入，覆盖计算、代码和公式；单项及完整链对照方法 | 仅准备输入，未运行模型；不得视为验收通过 |
| [固定版式](固定版式/) | 9 页课堂评价设计课件及内容稿 | 对照内容稿、PPTX 和文件检查，检查文字及页序；文件检查通过不等于教学评阅通过 |
| [平均数与中位数](平均数与中位数/) | 讲义到内容稿、PPTX/PDF 及预览 | 核对示例数据 4、5、5、6、30；平均数 10、中位数 5；原始检查随附 |
| [线性变换烟测](线性变换烟测/00-材料说明.md) | 人工恢复后的单页正式链路 | 区分人工编辑与模型生成；不是完整课程的一次生成成功记录 |
| [深度学习反例](深度学习反例/README.md) | 后台检查通过但内容仍不合格的反例 | 检查大纲范围、可训练参数、数值依据、逐讲学时和达成检查五项问题 |
| [PPT 三阶段](PPT三阶段/验收记录.md) | 来源、确定性导出及过期修改拒绝的历史证据 | 119 页输出及摘要；有已知讲义知识问题，禁止当作合格授课版 |
| [跨学科生成](跨学科生成/) | 2026-08-13 V37 的微积分和机械设计阅读样本 | 各三课时，检查概念递进、跨课案例数据与计算依据；不是完整学期课程 |

打开 Markdown/JSON 阅读输入与检查结果，PPTX 用 PowerPoint 或兼容软件打开，PDF 和 PNG 用于快速比较。上述材料不依赖原作者的绝对目录。重新运行生成须从当前应用的正式入口创建独立测试课程；不要把样例中的历史标识当作生产任务 ID。
