# 第1讲 深度学习概述与 PyTorch 基础

## 本节任务

本节解决深度学习入门中最常见的问题：读者能识别“张量”“模型”“损失”“优化器”等名词，却无法把它们组合成一条可运行的训练管线，也无法判断运行结果是否符合预期。学完本节内容后，读者应能在已知数据张量形状与损失函数定义的前提下，独立编写一个使用 PyTorch 的完整训练循环，使其连续 10 个 epoch 后损失值不高于初始值的 70%；能正确调用 `torch.optim.SGD` 并解释 `loss.backward()` 与 `optimizer.step()` 的执行顺序；能写出一个继承 `nn.Module` 的自定义层，并验证其前向输出形状与随机初始化参数的梯度非零。可观察行为包括：在无注释代码上运行后，能根据 `loss.item()` 的打印序列判断训练是否收敛；将 `optimizer.step()` 移到 `loss.backward()` 之前后，能预测并确认损失不下降的报错或数值现象；修改输入张量形状为不匹配 `nn.Linear` 的 `in_features` 时，能定位到 `RuntimeError` 并给出形状核对依据。这些行为构成本节验收的直接判据。

## 核心教学

深度学习用多层可微函数 $f = f_L \circ f_{L-1} \circ \cdots \circ f_1$ 把输入 $x$ 映射为输出 $\hat{y}$。每层 $f_i$ 通常由线性变换与非线性激活 $\sigma_i$ 组成。单层线性函数只能表达仿射关系；加入非线性后，两层即可逼近连续函数（通用逼近定理），多层则通过逐层变换扩大可表达函数族。表达能力增强依赖两个前提：各层参数可学习，且整个组合对参数可微，使反向传播能求出 $\partial \mathcal{L} / \partial W_i$。PyTorch 把这一机制拆成四个接口：`torch.Tensor` 承载数据与中间张量；`nn.Module` 封装参数与前向传播 `forward`；`nn.functional` 或 `nn.Module` 提供损失计算；`torch.optim` 提供基于梯度的参数更新规则。训练管线即：前向传播生成 $\hat{y}$，损失函数计算 $\mathcal{L}$，`loss.backward()` 依据计算图累积梯度到每个可训练参数，`optimizer.step()` 用梯度更新参数。`optimizer.zero_grad()` 防止梯度跨 epoch 累加。四者的调用顺序构成训练循环的最小契约，调换 `backward` 与 `step` 或遗漏 `zero_grad` 都会破坏参数更新语义。

## 最小可运行示例

环境前提：Python 3.9 及以上，PyTorch 2.0 及以上（CPU 版即可）。代码完整可运行，无外部依赖。输入为合成数据集，无需加载文件。

```python
import torch
import torch.nn as nn

# 1. 数据：100 个样本，2 维输入，线性关系 y = 3*x1 - 2*x2 + 噪声
torch.manual_seed(0)
X = torch.randn(100, 2)
y = 3 * X[:, 0:1] - 2 * X[:, 1:2] + 0.1 * torch.randn(100, 1)

# 2. 模型：单层线性回归，输出 1 维
model = nn.Linear(2, 1)

# 3. 损失：均方误差
criterion = nn.MSELoss()

# 4. 优化器：SGD，学习率 0.1
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

# 5. 训练 50 个 epoch，每轮打印一次损失
for epoch in range(50):
    optimizer.zero_grad()       # 清空上一轮梯度
    y_pred = model(X)           # 前向传播
    loss = criterion(y_pred, y) # 计算 MSE
    loss.backward()             # 反向传播，累积梯度
    optimizer.step()            # 用梯度更新 model 中所有参数
    if (epoch + 1) % 10 == 0:
        print(f"Epoch {epoch+1:3d} | loss: {loss.item():.6f}")

# 6. 验证：固定权重，检查预测偏差
with torch.no_grad():
    y_true = 3 * X[:, 0:1] - 2 * X[:, 1:2]
    y_check = model(X)
    err = (y_check - y_true).abs().mean().item()
    print(f"Final mean |pred - truth|: {err:.4f}")
```

运行方式：保存为 `train.py`，执行 `python train.py`。预期输出每 10 个 epoch 损失严格递减，第 50 个 epoch 损失低于第 10 个 epoch 损失的 0.7 倍；最后一行 mean 误差应小于 0.05（因噪声标准差 0.1，理论极限约 0.04）。排错检查：若出现 `RuntimeError: mat1 and mat2 shapes cannot be multiplied`，检查 `X` 的最后一维是否为 `nn.Linear` 的 `in_features`；若损失不下降，确认 `loss.backward()` 在 `optimizer.step()` 之前调用，且 `optimizer` 构造时传入的是当前 `model.parameters()` 而非旧模型的参数。

## 学习者行动

**任务条件**：在上一节示例基础上，将数据维度从 2 改为 5，目标关系改为 $y = x_1^2 - x_3 + 0.5 \cdot x_4$，噪声标准差 0.05。要求自定义一个 `nn.Module` 子类 `QuadraticModel`，其 `forward` 先对第 1 维做平方，再线性组合其余维度，最后加偏置。训练 80 个 epoch，SGD 学习率 0.05。

**操作步骤**：(1) 生成 `X = torch.randn(100, 5)`，按公式构造 `y`；(2) 实现 `QuadraticModel(nn.Module)`，`forward` 中不直接调用 `nn.Linear` 完成全部计算，至少使用一次 `x[:, 0:1] ** 2`；(3) 完整训练循环，打印每 20 个 epoch 的损失；(4) 训练结束后，断言最终损失 < 初始损失的 0.3 倍。

**输出要求**：提交完整可运行代码，末尾附加一行 `print("PASS")`，仅当断言通过时打印。

**参考解法要点**：`forward` 中 `out = x[:, 0:1] ** 2 + x[:, 1:2] * 0 + x[:, 2:3] * (-1) + x[:, 3:4] * 0.5 + x[:, 4:5] * 0` 可简化为 `out = x[:, 0:1]**2 - x[:, 2:3] + 0.5 * x[:, 3:4]`，无需偏置项（关系无常数项）。损失用 `MSELoss`。80 epoch 后损失应降至 0.001 量级，断言成立。

## 修改任务

**任务条件**：将上一步 `QuadraticModel` 的输入特征数从 5 改为 8，新增第 6~8 维对目标无贡献（系数为 0）。同时把优化器从 SGD 改为 Adam（学习率 0.001），epoch 数保持 80。要求：(1) 修改数据生成，`X = torch.randn(100, 8)`；(2) 修改 `forward`，新维度通过 `x[:, 5:8] * 0` 参与计算以保证梯度图连通；(3) 验证 Adam 下损失下降速率是否快于 SGD。

**操作步骤**：(1) 保留上一步代码框架，仅修改上述三处；(2) 训练结束后打印最终损失；(3) 将 `lr=0.001` 的 Adam 与 `lr=0.05` 的 SGD 各跑一次，比较第 40 epoch 的损失值。

**输出要求**：提交修改后完整代码，末尾打印最终损失与 PASS 标记（断言最终损失 < 初始损失 0.1 倍）。

**参考解法要点**：Adam 在 40 epoch 时损失通常已低于 0.005，SGD 同 epoch 约 0.01~0.03（取决于学习率）。最终损失两者均可达标。关键检查：`x[:, 5:8] * 0` 使这三维参数有零梯度但不报错；若直接省略，`forward` 输入 8 维但只用前 5 维，不会报错但梯度图不含后三维，功能正确。验收标准：代码运行无异常，打印损失单调递减，最终断言 PASS。

## 检查与反馈

### 学习者行动

**核对标准**：代码中 `forward` 必须显式使用 `x[:, 0:1] ** 2`；`QuadraticModel` 继承 `nn.Module` 且实现 `forward`；训练循环含 `zero_grad`、前向、`backward`、`step` 四步；断言逻辑正确（比较最终损失与首次记录损失）。

**参考结论**：80 epoch 后最终损失约 0.0002~0.001（噪声方差 0.0025，MSE 理论下界 0.0025，因模型完美拟合信号部分）。若损失停留在 0.1 以上，大概率是 `forward` 中系数写错或未更新 `y` 的生成公式。

**典型错误**：将 `forward` 中 `-x[:, 2:3]` 误写为 `-x[:, 3:4]`，导致模型学习错误关系，损失下降缓慢。修正原因：索引 2:3 对应第 3 维（$x_3$），索引 3:4 对应第 4 维（$x_4$）。再次验证：打印 `model(X)` 与手动计算 `X[:,0:1]**2 - X[:,2:3] + 0.5*X[:,3:4]` 的差值，应接近 0。

### 修改任务

**核对标准**：数据张量形状 `(100, 8)`；优化器为 `torch.optim.Adam(model.parameters(), lr=0.001)`；`forward` 中 `x[:, 5:8]` 以乘法 0 形式参与；比较实验同时保留 Adam 与 SGD 两组运行。

**参考结论**：Adam 第 40 epoch 损失约 0.001~0.005，SGD 约 0.01~0.04。最终损失两者均 < 初始损失 0.1 倍。若 Adam 损失反而高于 SGD，检查 `lr` 是否误设为 0.1。

**典型错误**：切换优化器时忘记 `optimizer = torch.optim.Adam(...)` 仍指向旧 SGD 实例，实际仍用 SGD 更新。修正原因：Python 对象引用需重新赋值。再次验证：`print(type(optimizer))` 应输出 `<class 'torch.optim.adam.Adam'>`。

## 需求与设计

设计一个可复用的训练组件时，需先明确约束：输入张量形状 `(N, D)` 可变，模型结构可变，损失函数与优化器可替换，但训练循环的接口签名固定。方案取舍：将数据生成、模型定义、训练循环、验证拆为独立函数，通过参数传递张量与模型实例，避免硬编码维度。组件接口如下：

```python
def train(model: nn.Module, X: torch.Tensor, y: torch.Tensor,
          criterion: nn.Module, optimizer, epochs: int = 50) -> list[float]:
    losses = []
    for _ in range(epochs):
        optimizer.zero_grad()
        loss = criterion(model(X), y)
        loss.backward()
        optimizer.step()
        losses.append(loss.item())
    return losses
```

验收条件：(1) `train` 接受任意 `nn.Module` 与任意张量形状匹配的 `criterion`；(2) 返回损失列表长度等于 `epochs`；(3) 调用者无需知道优化器类型，`optimizer` 只需实现 `zero_grad`、`step` 方法（鸭子类型）。输入验证：`X.shape[-1]` 必须等于模型第一层 `in_features`，否则 `model(X)` 抛 `RuntimeError`。运行前提：`criterion` 输出为 0 维张量（如 `MSELoss` 默认 `reduction='mean'`），确保 `loss.item()` 返回标量。若 `criterion` 返回向量，`loss.item()` 报错，调用者需显式取均值。排错：`loss.backward()` 报 `RuntimeError: element 0 of tensors does not require grad` 时，检查 `X` 是否被 `detach()` 或模型参数是否被 `requires_grad_(False)` 冻结。
