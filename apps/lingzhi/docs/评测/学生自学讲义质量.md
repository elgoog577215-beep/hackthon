## 2. 可复查输入

共同输入：C 语言自学；初学者；整门课 30 分钟。第一讲为“整数除法与类型转换”，目标是区分 `5/2`、`5.0/2` 与赋值转换；下一讲才引入数组和多步计算。

1. 备考：为大学 C 语言期末复习，判断表达式结果并解释易错原因。没有提供历年题、考频或分值依据。
2. 游戏：计算小游戏角色每次移动的距离，避免整数除法丢掉小数；任务应明确距离、步数或时间单位，说明取整策略。
3. 上传资料变体：将下列自编事实作为选定来源；保留相同目标与场景，检查补充说明不冒充资料原文。此变体的传递链已做模拟测试，真实模型生成尚未复查。

自编事实：`5/2` 得到整数 2；`double x=5/2` 得到 2.0；`5.0/2` 和 `(double)5/2` 得到 2.5；`(double)(5/2)` 不能恢复已丢掉的小数。一般算术运算不能笼统描述为“float 都按 double 处理”；需区分表达式类型、默认实参提升及求值精度。

类型转换依据：[WG14 C 标准委员会草案 N1494，6.3.1.8](https://www.open-std.org/jtc1/SC22/wg14/www/docs/n1494.pdf)。上述表达式用 C17 编译检查复核，不以模型自评代替事实核验。
