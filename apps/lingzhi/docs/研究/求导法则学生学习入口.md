# 求导时，先看清算式是什么样

已经会求 $x^2$、$\sin x$ 这些简单函数的导数后，遇到长一点的式子，可以先看：它是几项加减，两个函数相乘、相除，还是一个函数套在另一个里面？

先选你现在需要学的那一部分，不用一次读完。

| 看到这样的式子 | 这次学什么 | 开始学习 |
| --- | --- | --- |
| $7$、$3x^2$、$3x^2-2x+5$ | 固定的数导数为0；固定倍数保留；几项加减就分别求导 | [常数、倍数和加减，怎样求导？](线性法则学生学习稿.md) |
| $x^2\sin x$ | 每次只对一部分求导，另一部分保留，写出两项再相加 | [两个函数相乘，怎样求导？](乘积法则学生学习稿.md) |
| $\frac{x^2}{x+1}$ | 分子按顺序写两项相减，分母用原来的整个分母平方 | [两个函数相除，怎样求导？](商法则学生学习稿.md) |
| $\sin(x^2)$ | 对外面求导，里面先保留，再乘里面的导数 | [复合函数求导：别漏掉里面这一步](链式法则诊断深化样板.md) |

每一份都有一道完整例题、容易漏掉的步骤和可以自己试的练习。先做题，再展开答案；需要帮助时，也可以只选当前卡住的一小步。

一个式子也可能同时用到几条规则。例如 $3x^2+x\sin x$ 中，先分别处理两项，第二项再用乘积法则。先看清各部分怎样连接，不用急着一次写出整题答案。
