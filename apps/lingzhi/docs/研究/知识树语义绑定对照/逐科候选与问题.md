### 本轮知识叶子

- **P1 赋值操作的指向性**：在Python 3中，列表赋值语句 `b = a` 使变量 `b` 指向与 `a` 相同的列表对象，执行后 `a` 和 `b` 是两个名字指向同一列表，列表本身未被复制。
- **P2 别名下的原地修改可见性**：当 `b` 是 `a` 的别名（指向同一列表）时，通过其中一个名字（如 `a`）对该列表进行原地修改（如 append 或索引赋值），另一个名字（如 `b`）在后续访问时会观察到相同的变化。
- **P3 别名下的重新绑定独立性**：当 `b` 是 `a` 的别名时，对 `b` 执行重新绑定操作（如 `b = [9, 9]`），只会使 `b` 指向新的列表对象，`a` 仍指向原列表对象，`a` 的内容和指向均不受影响。
- **P4 浅拷贝的外层独立性**：调用 `a.copy()` 生成新列表 `b`（浅拷贝）后，`b` 和 `a` 是相互独立的外层列表对象；对 `b` 进行原地修改（如 `b.append(x)` 或 `b[0] = y`）不会改变原列表 `a` 的元素个数或整体指向。
- **P5 浅拷贝中嵌套元素的共享性**：对于包含嵌套列表的列表，使用 `.copy()` 进行的浅拷贝中，新列表 `b` 的原对应元素（如 `b[i]`）与 `a` 的对应元素（如 `a[i]`）仍然指向同一个内层列表对象。
- **P6 浅拷贝中内层列表的修改可见性**：在浅拷贝中，若通过任一外层列表（`a` 或 `b`）访问到共享的内层列表并对其进行原地修改，另一外层列表在访问同一内层位置时也会观察到该变化。
- **P7 浅拷贝中内层引用的重新绑定**：在浅拷贝列表中，若对 `b` 的某个索引位置（如 `b[0]`）重新赋值为一个新的列表对象，仅改变 `b` 中该索引位置的引用，不会改变 `a` 中对应索引位置的引用。

### 本轮知识叶子

- **P1 函数在点a处连续的定义**：函数f在定义域内点a处连续，当且仅当f(a)有定义，且x趋于a的双侧极限存在、有限并等于f(a)。
- **P2 函数在点a处可导的定义**：函数f在点a处可导，意味着差商[f(a+h)-f(a)]/h在h趋于0时存在有限的双侧极限。
- **P3 左右导数不同时不可导的判定**：若函数在点a处的左导数与右导数极限值不同，则该点处的双侧导数不存在，即函数在该点不可导。
- **P4 点a可导则必连续的逻辑关系**：在定义域内点a处，函数可导必然意味着函数在该点连续。
- **P5 点a连续不一定可导的逻辑关系**：函数在点a处连续，不能作为其在该点可导的充分条件；存在连续但不可导的反例。
- **P6 绝对值函数在0点的不可导反例**：函数f(x)=|x|在x=0处连续，但由于其左导数为-1、右导数为1（左右导数不同），所以该函数在0点不可导。
- **P7 不连续则不可导的逆否命题**：如果函数在点a处不连续，则必然不可导；这是“点处可导必连续”的逆否命题。
- **P8 不可导不能反推不连续**：函数在点a处不可导，不能反推其在该点一定不连续，存在不可导但连续的反例。

### 本轮知识叶子

- **P1 相互作用力大小与方向**：在两物体的一次相互作用中，一方对另一方施加的力，其大小必等于另一方对此方施加的力，且方向相反。
- **P2 相互作用力作用对象**：两物体相互作用时，A对B的力仅作用于B，B对A的力仅作用于A，二者作用对象不同。
- **P3 作用反作用定律的适用前提**：两物体间作用与反作用力等大反向的结论，不要求两物体的质量相等，也不要求物体处于静止状态。
- **P4 力与加速度的推断边界**：两物体间作用力与反作用力等大反向，不能据此直接推断这两物体的加速度必然相等。
- **P5 单物体受力图的列力原则**：绘制某个单个物体的受力图时，仅列出该物体受到的外部其他物体的力，不将由于该物体施加给其他物体的反作用力画入该受力图中。
- **P6 作用反作用力在受力图上的性质**：一对作用力与反作用力分别作用在两个不同的物体上，因此不能把其中任意一个力视为单个物体的受力平衡力，两者也不能在单物体的受力图中相消。
- **P7 平衡力的考察条件**：一对力要在力学分析中被认定为平衡力，必须同时作用于同一个受力对象上。
- **P8 多体系统的内力定义**：将A与B合并为一个系统进行整体受力分析时，A与B之间相互作用的力（作用力与反作用力）属于该系统的内力。
- **P9 内力抵消与外力合力的关系**：在包含两物体的系统中，A与B相互间内力在配对求和时相互抵消，这一结果仅说明内力总和为零，不能据此推断该系统的整个外力合力为零。

### 本轮知识叶子

- **P1 区分观察与推断**：分析史料时，必须将原文中可观察的内容与分析者基于材料做出的推断区分开来。
- **P2 推断的依据要求**：任何对史料的推断都必须明确说明其依据和推理过程，不能只给出结论。
- **P3 材料背景对主张的限制**：史料的作者、写作时间、受众和目的会影响该材料所能支持的主张范围，不能脱离背景孤立解读。
- **P4 一手材料的客观性限制**：不能仅因为某材料是一手材料就认为它完全客观，也不能仅因为其有立场就认为它毫无价值。
- **P5 互证的前提：独立性与可比性**：材料互证前，必须比较来源是否独立，以及记载的对象和时段是否可比，否则不能简单视为相互印证。
- **P6 矛盾材料的处理原则**：当材料相互矛盾时，应列出具体差异、考察其历史背景，并寻找新的证据，而不是通过比较材料数量或预设立场来决定真假。
- **P7 证据强度与结论强度的匹配**：有限的来源只能支持有限强度的结论；分析时必须区分‘可以说什么’、‘不能确定什么’以及‘下一步需要查证什么’。
- **P8 应用案例：材料A的局限**：对于材料A（工厂经理致投资人的年度报告），其作者、受众和目的决定了它更可能强调对投资人有利的信息，其关于‘所有工人生活改善’的推断需要结合背景检验，而非直接接受。
- **P9 应用案例：材料B的独立性**：对于材料B（工人私人日记），作为个人记录，它可能反映个体经验，但其代表性和与材料A的可比性需结合写作背景和时间段判断，不能直接用来否定或证实A的全称主张。
- **P10 应用案例：材料C的依赖关系**：材料C（报纸转载A）与材料A不构成独立见证，因此C不能为A提供额外的互证支持，其价值在于传播路径而非内容本身的独立性。
