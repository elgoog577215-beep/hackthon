### 知识叶子

- **P1 赋值操作的指向性**：执行赋值操作 b = a 时，变量 b 被绑定到 a 指向的同一个列表对象，不会创建新的列表副本。
  - 前提：使用普通内置列表（非自定义复制协议对象）
  - 元问题：执行 b = a 后，b 指向的是 a 的副本还是同一个对象？
  - 回答：b 指向的是 a 指向的同一个列表对象，两者指向相同地址。
- **P2 别名下的共享修改可见性**：当两个名字指向同一列表时，通过其中一个名字对该列表进行内容修改（如 append、修改元素），另一个名字访问时会观察到相同的变化。
  - 前提：两个名字绑定到同一个列表对象；操作是修改列表对象本身的内容，而非重新绑定变量
  - 元问题：b=a后，通过a执行 a.append(1)，b 的值是否改变？
  - 回答：会改变，因为 a 和 b 指向同一个列表，列表内容的变化对两个名字可见。
- **P3 重新绑定的独立性**：对一个指向某列表的变量进行重新赋值（如 b = new_list），只改变该变量的指向，不会影响另一个原本指向旧列表的变量。
  - 前提：两个变量之前指向同一个列表；操作是变量级别的重新赋值（=），而非列表对象的内容修改
  - 元问题：b=a后，执行 b=[] 会使 a 变成空列表吗？
  - 回答：不会，b 被重新绑定到了一个新的空列表对象，a 仍然指向原来的列表。
- **P4 外层列表的新建**：调用 a.copy() 会创建一个新列表对象（新外层），包含与 a 相同的元素，且新外层与原外层是两个独立的列表对象。
  - 前提：a 是普通内置列表；使用 .copy() 方法
  - 元问题：b = a.copy() 后，向 b 执行 append 操作，a 的内容会改变吗？
  - 回答：不会，b 是新建的独立列表，修改 b 不会影响 a 的外层列表。
- **P5 嵌套元素的共享引用**：在浅拷贝中，新外层列表中的嵌套列表元素（如子列表）与原外层列表中的对应元素仍引用同一个内层列表对象。
  - 前提：原列表包含嵌套列表；使用浅拷贝 a.copy()
  - 元问题：a=[[1,2],[3,4]]，b=a.copy()，修改 a[0].append(3) 会影响 b[0] 吗？
  - 回答：会，因为 a[0] 和 b[0] 指向同一个内层列表对象 [1,2]，修改其内容双方均可见。
- **P6 浅拷贝内层元素的重新赋值**：对浅拷贝列表的某个嵌套元素位置重新赋值一个新列表（如 b[0] = [9,9]），只改变 b 中该位置的指针引用，不影响原列表 a 中该位置的引用。
  - 前提：b 是 a 的浅拷贝；操作是重新赋值（=）b 中的嵌套位置，而非修改内层列表对象的内容
  - 元问题：b=a.copy() 后，执行 b[0]=[9,9]，a[0] 的值会变为 [9,9] 吗？
  - 回答：不会，b[0] 的指针指向了新列表 [9,9]，a[0] 仍指向原来的内层列表对象。

### 能力与教学候选

#### 列表赋值与别名操作辨析

学生能够区分变量绑定（=）与对象内容修改（.append/[i]=）对列表别名的不同影响，并通过代码执行结果预测两个变量指向关系及最终值。

给定代码：
1. `a=[1,2]; b=a; b.append(3)`
2. `c=[4]; d=c; d=[5]`
请回答：
(1) 执行代码1后，a和b分别是什么？
(2) 执行代码2后，c和d分别是什么？
(3) 画出代码2执行后的内存引用简图（可用文字描述）。

需提交：包含(1)和(2)的具体列表值，以及(3)中显示c指向原列表对象[4]，d指向新列表对象[5]的文字描述或图示。

- P1 → Q1：正确判断a is b为True，或在任务(1)中隐含承认b与a指向同一对象从而得出一致结论。
- P2 → Q2：在任务(1)中正确给出a=[1,2,3]，表明理解通过别名修改内容双方可见。
- P3 → Q3：在任务(2)中正确给出c=[4], d=[5]，并在引用图中正确表示d指向新对象，c未变。

错因候选：认为赋值操作 b = a 会深拷贝或浅拷贝列表内容，创建一个新的独立列表对象。

预测（待核验）：若持有此错因，面对 `a=[1]; b=a; b.append(2); print(a)` 会预测 a 仍为 [1]。

补救：在Python解释器中执行 `a=[1]; b=a; print(a is b)` 并观察结果。；执行 `b.append(2); print(a)` 并观察 a 的变化，核对“指向同一对象”的含义。

错因候选：混淆“变量重新赋值”与“列表元素内容修改”，认为 `d=[5]` 会修改 d 指向的列表对象，从而影响 c。

预测（待核验）：若持有此错因，面对 `a=[1]; b=a; b=[9]; print(a)` 会预测 a 变为 [9]。

补救：执行 `id(a)` 和 `id(b)` 观察初始地址，再执行 `b=[9]` 后再次执行 `id(b)` 和 `id(a)`。；对比 `b.append(9)` 前后 `id(b)` 是否变化，以区分“换对象”与“改内容”。

区分依据：Q1区分是否理解指向共享；Q2区分是否理解共享修改的可见性；Q3区分是否能识别重新绑定的独立性。若学生答对Q1但答错Q2，说明知道是同一对象但误以为修改不可见（可能混淆了值类型和引用类型的修改语义）；若答对Q1和Q2但答错Q3，说明混淆了变量绑定和对象修改。

局限：无法判定学生是否能在非列表容器（如字典或集合）上应用相同的别名逻辑，仅基于列表证据。

#### 浅拷贝行为与嵌套共享分析

学生能够准确预测 a.copy() 产生的新列表在外层独立性、内层共享性上的具体表现，并能区分对共享内层的内容修改与对浅拷贝位置的重绑定。

给定代码：
a = [[1, 2], [3, 4]]
b = a.copy()

请判断以下操作执行后 a 和 b 的值：
操作1: b[0].append(9)
操作2: b[1] = [7, 8, 9]
操作3: b.append([5, 6])

请分别给出操作1、2、3独立执行（即每次从初始状态开始）后 a 和 b 的值。

需提交：三组 (a, b) 的列表值。其中操作1后 a 和 b 的 [0] 元素均变化；操作2后仅 b 的 [1] 元素变化；操作3后仅 b 的长度增加。

- P4 → Q4：在操作3的预测中，正确给出 a 不变，b 增加新元素，表明理解 copy() 创建独立外层。
- P5 → Q5：在操作1的预测中，正确给出 a 和 b 的 [0] 元素都变为 [1, 2, 9]，表明理解内层共享。
- P6 → Q6：在操作2的预测中，正确给出 a 不变，b[1] 变为 [7, 8, 9]，表明理解浅拷贝中重绑定内层位置的独立性。

错因候选：认为 a.copy() 是深拷贝，会递归复制所有嵌套列表，因此修改内层不会影响原列表。

预测（待核验）：若持有此错因，面对 `a=[[1]]; b=a.copy(); b[0].append(2); print(a)` 会预测 a 仍为 [[1]]。

补救：执行 `a=[[1]]; b=a.copy(); print(a[0] is b[0])` 并观察结果。；执行 `b[0].append(2); print(a)` 并观察 a 是否变化，核对“浅拷贝只复制外层”的含义。

错因候选：混淆“修改共享对象的内容”与“重新绑定引用”，认为对 b[0] 赋值新列表会修改该共享列表对象本身，从而影响 a。

预测（待核验）：若持有此错因，面对 `a=[[1]]; b=a.copy(); b[0]=[9]; print(a)` 会预测 a 变为 [[9]]。

补救：执行 `id(a[0])` 和 `id(b[0])` 确认初始相同，然后执行 `b[0]=[9]` 后再次比较 `id(b[0])` 与 `id(a[0])`。；对比执行 `b[0].append(9)` 后的 id 变化，以理解“换指针”与“改内容”的区别。

区分依据：Q4区分是否理解外层独立；Q5区分是否理解内层共享；Q6区分是否理解内层位置重绑定的独立性。若学生答对Q5但答错Q6，说明能识别共享修改但混淆了重绑定语义；若答对Q4但答错Q5，说明知道外层独立但误以为内层也独立。

局限：无法判定学生是否能将此逻辑推广到非列表的可变嵌套对象（如字典中嵌套字典），仅基于列表证据。

- `teaching.S1.mistakes.A.reason`：用“没有尖角/拐点”描述可导，混淆尖角与可导函数也可具有的拐点；补救直观不宜替代差商条件。

### 知识叶子

- **P1 定义域内点条件**：本单元的所有分析仅适用于函数定义域内的点a，不讨论端点或定义域外的点。
  - 前提：讨论对象为函数定义域内的点a
  - 元问题：本单元讨论可导和连续性时，对点a在定义域中有何要求？
  - 回答：点a必须严格属于函数的定义域内，非端点。
- **P2 连续性的定义**：函数在定义域内点a连续，需同时满足：f(a)有定义；当x趋于a时双侧有限极限存在；该极限值等于f(a)。
  - 前提：点a在定义域内
  - 元问题：判断函数在内部点a连续的三个条件是什么？
  - 回答：1. f(a)存在；2. lim(x→a) f(x)存在且为有限值；3. lim(x→a) f(x) = f(a)。
- **P3 可导性的定义**：函数在定义域内点a可导，意味着差商 [f(a+h)-f(a)]/h 当h趋于0时存在有限的双侧极限。
  - 前提：点a在定义域内
  - 元问题：根据差商的极限定义，可导的核心要求是什么？
  - 回答：差商 [f(a+h)-f(a)]/h 在h→0时的双侧极限必须存在且为有限值。
- **P4 可导性的判定方法**：判断点a不可导的判定方法是：若左差商极限与右差商极限不相等（或至少一侧不存在），则该点导数不存在。
  - 前提：点a在定义域内；分别计算h→0+和h→0-的差商极限
  - 元问题：如果某点左差商极限和右差商极限不同，能得出什么结论？
  - 回答：该点不可导。
- **P5 可导推连续**：在定义域内点a，若函数可导，则函数在该点必然连续。
  - 前提：点a在定义域内
  - 元问题：如果已知函数在某内部点可导，能否直接推出其在该点连续？
  - 回答：能，可导是连续的充分条件。
- **P6 连续推可导的反例逻辑**：在定义域内点a，若函数连续，不能保证其可导；不可导也不能反推不连续。
  - 前提：点a在定义域内
  - 元问题：函数在内部点连续，是否一定可导？
  - 回答：不一定。存在连续但不可导的情况。
- **P7 不连续推不可导**：在定义域内点a，若函数不连续，则函数在该点必然不可导（可导必连续的逆否命题）。
  - 前提：点a在定义域内
  - 元问题：如果函数在内部点a不连续，可导吗？
  - 回答：不可导，不连续是不可导的充分条件。
- **P8 反例：绝对值函数**：函数 f(x)=|x| 在点 x=0 处连续，但左导数为 -1，右导数为 1，由于左右极限不等，故该点不可导。
  - 前提：函数为 f(x)=|x|；考察点为 x=0
  - 元问题：以 f(x)=|x| 为例，为什么它在 0 点不可导但连续？
  - 回答：因为虽然左右极限（均为0）等于f(0)满足连续，但左导数(-1)与右导数(1)不相等，差商极限不存在。

### 能力与教学候选

#### 基于极限与差商的单点性质判定

针对给定的具体函数和定义域内点，计算左右极限/差商，并依据数值相等性判断连续性与可导性。

针对 f(x)=|x| 在 x=0 处，请分别计算左右极限和左右差商极限，并判断该点的连续性与可导性。

需提交：包含左右极限值、左右差商极限值，以及基于这些数值得出的连续/不可导结论。

- P1 → None：隐含在所有对 x=0 的计算中，确认 0 在 |x| 的定义域内
- P2 → None：指出左右极限均为0且等于 f(0)，判定连续
- P3 → Q3：正确写出差商定义并计算其极限
- P4 → Q3：明确指出左差商极限为-1，右差商极限为1
- P8 → Q3：得出“连续但不可导”的结论，且理由是基于差商极限不相等

错因候选：认为可导性的判定等同于函数连续性，忽略了差商极限的独立性。

预测（待核验）：回答“可导”，因为学生将连续性判定标准错误地应用到了可导性判定上，未能意识到左右斜率（差商）不一致。

补救：分别计算 h→0+ 和 h→0- 的差商极限；核对左右差商极限是否数值相等，不等则直接判定不可导，不受连续性影响

区分依据：能区分那些正确计算了左右极限（连续）但错误计算或未计算左右差商极限（不可导）的学生。

局限：无法直接判定学生是否清楚 P1（点必须在定义域内），因为对于 |x| 在 0 处，该条件是显见的。

#### 连续与可导的逻辑边界论证

给定函数的连续或可导状态，能正确推导另一状态，并在逻辑不成立时能准确援引反例。

已知函数 f 在内部点 a 连续，请判断“f 在 a 可导”这一结论是否必然成立？如果已知 f 在 a 不可导，请判断“f 在 a 不连续”是否必然成立？

需提交：针对两个逻辑推导分别给出“是/否”的结论；若为“否”，需提供明确的逻辑反例（如 |x| 在 0）。

- P5 → Q4：指出若已知可导，则可断定连续（可导是连续的充分条件）
- P6 → Q5：指出连续不能断定可导，并能援引 f(x)=|x| 在 0 作为反例
- P7 → Q6：指出不可导不能断定不连续（因为连续不可导的函数存在），且说明不连续必然推不出可导

错因候选：错误地认为连续与可导互为充要条件，或未能区分“充分条件”与“逆否命题”的适用方向。

预测（待核验）：回答“能断定”，因为学生错误地建立了双向推导逻辑。

补救：画出一个具体的连续但不可导函数（如 |x|）来反驳“连续推可导”；利用逻辑真值表确认“不可导”在逻辑上不能直接等同于“不连续”

区分依据：能区分正确理解“单向充分性”的学生与错误认为“双向等价”的学生。

局限：此题侧重于逻辑推导，无法检测学生对具体点（如 x=2 处）计算差商细节的准确性。

### 知识叶子

- **P1 作用反作用力等大反向**：在A与B的一次相互作用中，A对B的力与B对A的力大小相等、方向相反。
  - 前提：经典力学；宏观低速情境
  - 元问题：在宏观低速情境下，两物体相互作用时作用力与反作用力的大小和方向关系是什么？
  - 回答：大小相等，方向相反。
- **P2 作用反作用力作用对象**：作用力与反作用力分别作用于相互作用的两个不同物体上。
  - 前提：经典力学
  - 元问题：相互作用产生的两个力分别作用在哪里？
  - 回答：分别作用在A和B上。
- **P3 作用反作用力的前提限制**：作用力与反作用力大小相等，不以两物体质量相等或处于静止状态为前提。
  - 前提：经典力学
  - 元问题：判断作用力与反作用力是否等大反向，是否需要两物体质量相等或静止？
  - 回答：不需要。
- **P4 力与加速度的独立判断**：不能依据作用力与反作用力大小相等，直接推导出两物体的加速度相等。
  - 前提：经典力学；宏观低速情境
  - 元问题：如果A对B的力等于B对A的力，能否直接得出A和B的加速度相等？
  - 回答：不能，需结合质量等因素判断。
- **P5 单物体受力图规则**：绘制单个物体受力图时，只列出该物体所受的力，不将其施加给其他物体的力画入该物体受力图中。
  - 前提：受力对象为单个物体
  - 元问题：画物体B的受力图时，是否需要画出B对物体A的力？
  - 回答：不需要，只画作用于B的力。
- **P6 作用反作用力非平衡力**：作用反作用力分别作用于不同物体，不能在同一物体的受力图上作为平衡力相消。
  - 前提：受力对象为单个物体；存在相互作用力对
  - 元问题：在单个物体的受力分析中，相互作用力能否相互抵消？
  - 回答：不能，因为它们作用在不同物体上。
- **P7 平衡力的受力对象限制**：判断平衡力必须在同一受力对象上考察。
  - 前提：受力对象为单个物体或整体系统
  - 元问题：判断两个力是否平衡，需要满足什么受力对象条件？
  - 回答：必须作用于同一受力对象。
- **P8 系统内力抵消性质**：若将A+B选为整体系统，A与B间的相互作用力为内力；内力配对求和抵消不代表外力合力为零。
  - 前提：系统包含相互作用物体A和B；经典力学
  - 元问题：当把A和B选为系统时，A与B间的相互作用力如何处理？能否据此认为外力合力为零？
  - 回答：作为内力，配对抵消；不能据此推断外力合力为零。

### 能力与教学候选

#### 作用反作用力配对与逻辑边界

在给定物体与质量/运动状态的力学情境中，学生能准确配对相互作用力，明确其作用对象与前提条件，并在受力分析中阻断由'力相等'错误推导'加速度相等'的逻辑跳跃。

提供情境：质量不等的两物体A与B发生相互作用（如手推墙，或甲推乙）。1. 找出并配对相互作用力，指明施力者与受力者。2. 判断该相互作用力是否等大反向，是否受物体质量或静止状态影响。3. 在给出物体质量关系后，判断A与B的加速度是否必然相等，并给出受力分析推理。

需提交：1. 明确的力的配对清单（如：F_A对B 与 F_B对A）。2. 受力对象标注图（标出A受力、B受力）。3. 基于牛顿第二定律 $F=ma$ 的代数推理步骤，对比两物体质量与受力，指出加速度关系。

- P1 → Q1：正确配对A对B与B对A的力，并表述其大小相等、方向相反。
- P2 → Q3：明确指出F_A对B作用在B上，F_B对A作用在A上，未混淆受力对象。
- P3 → Q2：在质量不等的情境中，正确判断两物体间相互作用力大小相等，未受质量差影响。
- P4 → Q2：结合受力（相等）与质量（不等）推理出两物体加速度不等，拒绝了'力等则加速度等'的错误结论。

错因候选：根据物体质量差异或运动状态（如静止），错误判断作用反作用力大小不相等。

预测（待核验）：回答者会指出较轻物体受到的力较小，或静止物体施力较小，并试图据此推导较轻物体（或受力较小物体）的加速度更大或不匹配。

补救：复习牛顿第三定律的定义，强调'一对相互作用力'的大小与方向关系独立于质量、速度或静止状态。；在受力图上仅对单一受力对象列力，明确力的等量关系是力对自身的属性，然后针对每个受力对象独立使用 $F_{net} = ma$ 计算各自的运动学响应。

区分依据：Q1与Q4区分了学生是否受'墙未动'（静止状态）的干扰而误判反作用力不存在或不等；Q2结合质量差情境，区分了学生是否会将'力相等'直接错误映射为'加速度/运动状态相等'（P4的边界测试）。

局限：无法仅凭这些题判定学生在多力复合系统（如多个物体同时存在摩擦力和重力时）能否正确隔离内力与外力。

#### 受力图绘制与内力/平衡力辨析

根据选定系统，学生能绘制正确的单物体受力图，准确排除施加给其他物体的力（反作用力），区分平衡力与相互作用力，并在选取整体系统时正确识别内力相消但不能推导外力为零的逻辑界限。

提供情境：桌面上的一本书（或相互推的车+外部拉力系统）。1. 画出书（或车A）的受力图，并标注重力、支持力等。2. 判定书中某两个力（如重力与支持力）是否为作用反作用力，并说明理由。3. 若将相互推的车（A、B）及外部拉力系统选为整体，判断内部推车力相消是否代表整体所受外力合力为零。

需提交：1. 包含受力对象和所有外部施加力的受力图（无多余力）。2. 平衡力与反作用力的受力对象对比说明（受力对象同/不同）。3. 对整体系统的受力分析，分离内力与外力。

- P5 → Q3：书（或车A）的受力图中未画出'书对桌面的压力'，只保留了作用于书（车A）的力。
- P6 → Q5：正确识别书中重力与支持力不是作用反作用力对，因为二者作用在同一物体上，并指出书的重力的反作用力是书对地球的引力。
- P7 → Q5：论证重力与支持力平衡时，明确前提'必须作用于同一受力对象'。
- P8 → Q6：选出两车为整体后，指出内部推力相消仅代表内力合力为零，不能因此忽略外部绳子的拉力（外力），并画出外部绳拉力。

错因候选：在绘制单一受力对象的受力图时，将施加给其他物体的反作用力画出，或将同一物体上的平衡力错误标记为作用反作用力对。

预测（待核验）：在受力图环节，学生可能画出作用于其他物体的力；在辨析环节，学生会错误地用'力抵消'来解释静止，或者指出重力和支持力是'大小相等方向相反的作用反作用力'，并忽略它们作用在同一物体上的事实。

补救：重新审视受力图的定义：以圈出的受力对象（如书）为原点，只画有实际接触点（或引力场）且箭头指向受力对象的力。；通过受力对象检验法：写出'施力者→受力者'。若施力者与受力者互换且受力者变为别的物体，则是作用反作用力对（不可相消）；若受力者相同，则可能为平衡力（可以相消）。

错因候选：将整体系统中内力相互抵消的结果，错误推广至系统所受的所有外力合力为零。

预测（待核验）：学生会列举A推B和B推A，并直接写出'内力抵消=0，因此外力合力也为0'，遗漏或抹杀外部绳子的拉力在整体受力分析中的作用。

补救：使用系统切割法：画一个虚线框包住A和B。；区分穿框的力（外力，必须画出）和不穿框的力（内力，可以相消），对穿框的力（外部绳子拉力）单独进行矢量和计算。

区分依据：Q5区分了平衡力与反作用力在受力对象上的根本区别；Q6区分了学生是否能在选取系统时正确区分内力（相消）与外力（不可相消），检测出将内力抵消错误等价为系统平衡的能力缺失。

局限：不能判定学生在涉及非接触力（如电场力与重力）或三维空间斜拉力的具体受力图投影计算能力。

## 历史学习：史料观察、推断与互证

### 复核问题

- `tree.P8.meta_answer`：将收入与工时同时变化写成“作为代价”，加入材料没有给出的因果解释。
- `teaching.S1.criteria[P8] / S2.criteria[P6]`：把工人日记中的陈述写成已证明的个人事实；应区分“材料记载如此”和“事件已经被证实”。
- `teaching.S1.criteria[P2] / repair`：将可能的选择性呈现、争取资金或隐瞒劳资纠纷写成确定动机，超出虚构材料；也不能要求学生必须采用这些特定解释。
- `teaching.S1.expected_evidence`：要求明确提及固定关键概念，缺少接受同义表达和其他有证据论证的显式标准；开放评价的方向已有，但边界未稳固。

### 知识叶子

- **P1 观察与推断的区分**：在分析史料时，应将原文中可直接观察到的事实（如文字记录）与分析者基于这些事实进行的推断明确分开。
  - 前提：适用于所有涉及分析者主观解读的史料阅读过程
  - 元问题：如何在史料分析中区分客观记录与主观推断？
  - 回答：应明确列出原文的可观察内容，单独标注并说明分析者的推断依据和逻辑链条，不将两者混淆。
- **P2 史料背景要素对主张的影响**：史料的作者身份、写作时间、受众及写作目的构成了背景要素，这些因素决定了该材料能够支持哪些主张以及不能支持哪些主张。
  - 前提：必须结合具体的作者、时间、受众信息进行判断，不可脱离背景。
  - 元问题：为什么评估史料的可信度时不能忽略其背景和意图？
  - 回答：因为背景要素（如作者立场、目的）限制了材料的有效信息范围；忽视它们会导致错误地赋予材料超出其背景支持范围的证明力。
- **P3 一手材料与客观性的关系**：材料属于“一手材料”并不自动等同于其内容“完全客观”；同样，材料具有特定立场也不意味着其“毫无价值”。
  - 前提：适用于判断一手材料的证明力和局限性
  - 元问题：一手材料的身份如何影响对其客观性和价值的判断？
  - 回答：一手材料提供了原始视角但不保证绝对客观；评估价值时，应在承认其立场局限性的同时，提取其在特定视角下仍具价值的信息，避免绝对化。
- **P4 互证的独立性标准**：在进行史料互证时，必须比较不同来源是否具有独立来源，以及其记载的对象和时段是否具有可比性；若两个文本仅是同一报道的转载，则不能视为两份独立的见证。
  - 前提：必须确认来源间的原始独立性，排除因转载或共同来源导致的重复。
  - 元问题：判断两份史料能否作为互证的前提条件是什么？
  - 回答：前提条件是来源的独立性和记载范围（对象与时段）的可比性；若来源相同或存在从属关系，则不构成有效互证。
- **P5 矛盾史料的处理方法**：当材料之间出现矛盾时，应当列出具体差异，考察各自的背景，并寻找新的证据；不得仅凭支持某一说法的材料数量多，或预设立场来判定真假。
  - 前提：适用于发现史料间记载冲突时的处理流程。
  - 元问题：面对相互矛盾的史料，正确的处理步骤是什么？
  - 回答：列出矛盾点，调查矛盾双方的背景与动机，寻找第三方或新证据以辅助判断，拒绝用“数人头”或预设立场来强行定论。
- **P6 有限来源的结论边界**：当可获得的史料数量有限时，所支持的结论强度也是有限的；分析时必须明确区分“可以确定的陈述”、“无法确定的空白”以及“下一步需要查证的方向”。
  - 前提：适用于所有基于现有不完整材料做出的任何总结或判断。
  - 元问题：在史料有限的情况下，如何规范地表述分析结论？
  - 回答：结论应受证据强度约束；需明确说明哪些是证据支持的，哪些是未知的，以及后续可采取哪些查证行动，避免过度概括。
- **P7 虚构工厂年报（材料A）的语境**：在虚构材料中，A是一份由某工厂经理写给投资人的年度报告，其中包含了“产量增加，所以所有工人的生活都改善了”的主张。
  - 前提：仅适用于针对该特定虚构情境的评估，材料本身为教学用虚构内容。
  - 元问题：材料A中经理的主张具体是什么？
  - 回答：经理声称由于工厂产量增加，所有工人的生活质量都随之得到了改善。
- **P8 虚构工人日记（材料B）的语境**：在虚构材料中，B是同一年度内一名工人的私人日记，其中记录了“我家收入增加，但工作时间更长了”的陈述。
  - 前提：仅适用于针对该特定虚构情境的评估，材料本身为教学用虚构内容。
  - 元问题：材料B中工人描述的切身情况是什么？
  - 回答：该工人的个人收入有所增加，但作为代价，其劳动时间（工时）也随之延长了。
- **P9 虚构报纸转载（材料C）的属性**：在虚构材料中，C是一份报纸的内容，该报纸并非原始调查，而是对材料A（工厂经理的年度报告）中相关表述的原文转载。
  - 前提：仅适用于针对该特定虚构情境的评估，材料本身为教学用虚构内容。
  - 元问题：材料C的信息来源是什么？它与材料A有怎样的关系？
  - 回答：C的来源是对A的原文转载，这意味着C不具备独立于A的见证价值，两者在信息上是重复的。
- **P10 虚构情境中的证据缺口**：在给定的虚构情境中，除了A、B、C三类材料外，并未提供其他工人的记录、物价数据、工资账簿或工时统计数据，这构成了评估整体工人生活状况的证据缺口。
  - 前提：指代特定虚构教学案例中明确缺少的数据维度。
  - 元问题：在该虚构情境中，如果要验证“所有工人都改善”的主张，目前缺乏哪些关键数据？
  - 回答：缺乏能够代表工人整体的群体性数据，具体包括：其他工人的个人记录、物价水平、系统性的工资账簿以及工时统计。

### 能力与教学候选

#### 史料语境下的观察-推断区分与背景评估

学生能准确分离史料原文的可观察文本内容与分析者的主观推断；能结合作者身份（工厂经理）、受众（投资人）及写作目的，评估材料A的主张支持范围，避免将一手材料等同于完全客观事实，也不因立场而全盘否定其特定视角下的价值。

阅读虚构材料A（工厂经理致投资人年报）和材料B（工人日记）。1. 从材料A中挑出一句‘可直接观察到的文字记录’和一句‘经理的推断’，并分别标注。2. 基于材料A的作者、受众和目的，解释为什么‘产量增加’这一记录不能直接证实‘所有工人生活改善’，并指出该材料在什么特定方面仍有研究价值。3. 简述材料B中工人的描述，指出其中哪些是具体事实，哪些属于个人感受。

需提交：一份包含两个部分的书面分析：第一部分为文本内容分类表（列明可观察事实vs推断）；第二部分为段落式论证，明确提及‘受众为投资人’、‘选择性呈现’、‘一手材料局限性’等关键概念，并基于材料B给出具体事实与感受的区分。

- P1 → Q1：学生能清晰列出材料A中经理写下的‘产量增加’等陈述作为观察对象，而不将其直接等同于事实；同时识别出‘所有工人的生活都改善了’是基于产量增加的推断，而非原文直接观察到的生活状态指标（如工资、物价）。
- P2 → Q2：学生明确引用‘受众是投资人’和‘年度报告的目的’，指出这会导致经理在报告中倾向于突出积极方面（如产量增加）并淡化消极方面（如工时增加或工人不满），从而限制了材料A证明‘生活全面改善’的有效性。
- P3 → Q1：学生在评价材料A时，未使用‘因为是年报所以绝对客观’或‘因为是资本家写的所以一无是处’等极端表述，而是承认其作为原始视角的价值（如反映管理层当时的叙事逻辑）并指出其立场局限。
- P7 → Q1：学生准确复述材料A的主张内容：经理声称因产量增加，所有工人的生活质量随之改善，并识别出这是核心待验证主张。
- P8 → Q4：学生准确引用材料B内容：该工人记录收入增加和工时延长。学生能够指出这是个人层面的具体事实，而非群体统计数据。

错因候选：混淆观察与推断，认为一手材料的文字记录等同于客观真理。

预测（待核验）：学生的回答中会将‘所有工人的生活都改善’标记为‘可观察事实’，或者在解释时完全不提及经理在此句中使用了归因（推断）和全称概括（逻辑跳跃）。

补救：回到材料A，用高亮笔将‘产量增加’（动作/记录）与‘所有工人的生活都改善了’（结论/状态评估）圈出。；自问：‘生活改善’是经理眼睛看到的数字，还是他根据产量做出的判断？如果是判断，它就是推断。

错因候选：忽视史料背景要素，仅凭文本表面信息做判断。

预测（待核验）：学生的论证中缺乏对‘投资人’这一受众的分析，或者虽然提到受众，但得出的结论是‘投资人关心的内容就是事实’，未能指出受众与写作目的对‘选择性呈现’的塑造作用。

补救：识别材料A的三个元数据：作者（经理）、受众（投资人）、目的（年度报告/争取资金或信任）。；推理：向投资人汇报时，经理最需要展示什么指标？（效率/产量）。他最不想让投资人知道什么？（潜在的劳资纠纷/高工时导致的成本或风险）。

区分依据：Q1区分了学生是否仅停留在字面提取（观察）还是进行了逻辑归因分析（推断）；Q2区分了学生是否将材料A视为孤立文本，还是置于‘经理-投资人’的社会互动语境中评估其偏见与局限。

局限：无法单独区分学生是否具备‘区分一手与二手’的深层理论素养，因为这主要依赖于材料A自身的属性（一手），需结合S2的互证任务来全面评估。

#### 史料互证的独立性与矛盾处理的证据边界

学生能准确判断材料C因系转载而不具备独立见证价值，无法与A构成有效互证。当面对A（全面改善）与B（收入增但工时增）的矛盾时，学生能列出具体差异并拒绝数量投票。针对证据缺口（无群体数据、物价等），学生能严格限定结论强度，并提出明确的下一步查证计划。

基于材料A、B、C及情境描述：1. 评估材料C是否能作为支持材料A主张的‘第二份独立证据’，并说明理由。2. 分析材料A的主张（所有工人改善）与材料B的记录（个人收入增、工时增）之间存在的张力/矛盾，说明为何不能简单地判定谁对谁错，以及需要关注哪些具体指标差异。3. 鉴于缺乏其他工人记录、物价和工资账簿（证据缺口），明确陈述目前证据能支持的有限结论是什么，并列出至少两项具体的下一步查证方案（如查阅何种档案或询问何种人群）以检验A的主张。

需提交：一份包含三个部分的评估报告：1. 独立性判断（明确指出C非独立）；2. 矛盾分析表（列出A与B在对象、指标上的差异，并解释为何不能直接定论）；3. 结论边界与查证计划（明确区分‘已证实’、‘未证实’和‘待查证’，列出具体的数据收集方法）。

- P4 → Q3：学生明确指出C是A的转载，两者来源不独立，因此C不能增加证据的独立见证数量，不能用于互证A的真伪。
- P5 → Q5：学生能够识别A与B的矛盾点（如‘所有工人vs单个工人’、‘生活改善vs工时增加’），并提出通过考察背景、寻找新证据（如工资单、物价）来缓解矛盾，而非依据‘A+ C’两份材料反对‘B’一份材料来判定A为真。
- P6 → Q4：学生明确表述：现有材料只能证明‘某个特定工人的收入与工时变化’以及‘经理声称产量增加’，但不能证明‘所有工人’或‘整体生活水平’。结论受限于样本大小和数据维度。
- P9 → Q3：在分析C的属性时，学生能准确识别其‘报纸转载’的身份，并将其作为非独立来源的特征加以说明。
- P10 → Q6：学生准确指出缺失的关键数据（物价、群体记录、工时统计等），并在查证计划中提出获取这些具体数据的方法（例如：查阅工厂的工资账簿、调查当地物价指数、收集更多工人的日记）。

错因候选：混淆证据数量与独立见证价值，认为转载文本增加了证据强度。

预测（待核验）：学生的结论中会包含‘A和C共同支持了...’或‘双重来源证实了...’等表述，忽略了‘转载’意味着信息链的单一源头。

补救：画出信息流向图：经理(源头) -> A(年报) -> C(报纸转载)。；自问：C的信息是从经理那里独立获得的，还是从A那里复制的？如果是复制的，C是否提供了经理没说的新信息？如果没有，C就是冗余证据。

错因候选：在证据不足时强行定论或进行过度概括。

预测（待核验）：学生的回答中缺乏‘待定’或‘需进一步查证’的表述，而是直接给出了‘A错’或‘B错’的二元结论；或者将B的描述直接当作全体工人的代表数据。

补救：列出A与B差异的维度：对象（所有工人 vs 1个工人）、指标（生活改善[模糊] vs 收入/工时[具体]）。；自问：现有的A和B能否解决‘其他工人’和‘生活综合指标’的问题？如果不能，结论应该是什么？（答案：结论应限于已知事实，其余标注为未知/待查）。

区分依据：Q3区分了学生是否理解‘独立性’在互证中的核心地位；Q5区分了学生是陷入二元对立的思维定势，还是能运用差异分析处理矛盾；Q6区分了学生是否能将‘证据缺口’转化为具体的、可操作的查证步骤，而非仅停留在口头承认‘证据不足’。

局限：无法直接区分学生是否具备‘评估史料时效性’的能力，因为本情境中材料均为‘同年度’，时效性差异不是主要矛盾，主要矛盾在于来源独立性和数据维度。
