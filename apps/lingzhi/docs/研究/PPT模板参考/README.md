# PPT 模板参考来源

目录包含 39 套参考：28 套 A 级、11 套 B 级。用于模板结构与课程页型设计；原件、第三方图片、字体及预览缓存不纳入本仓库。

- [模板清单](模板清单.md)：来源链接、页面比例、版式数量和授权条件。
- [模板目录](模板目录.json)：同一批样本的结构信息与 SHA-256。`source_entry` 是采集时的分类路径，不是本仓库文件；SHA-256 对应当时获取的文件，上游新版不一定相同。
- [质量初审](质量初审.md)：A/B/C 的判断、已删除的 7 套 C 级模板及首批提炼建议。
- [PPT Master MIT 许可](授权说明/PPTMaster-MIT-LICENSE.txt)、[Presenton Apache-2.0 许可](授权说明/Presenton-Apache-2.0-LICENSE.txt)：原采集时保留的许可文本，获取新版时仍需核对其随附声明。

需要原件时，从清单中的上游页面按模板名称获取；保存在本地参考目录。PresentationGO 仅按其许可作本地参考或保留署名的成品，不将原模板再分发。PPT Master / Presenton 的仓库许可不自动覆盖所有内嵌图片和字体；正式内置时逐项核对资源授权并保留必要声明。
