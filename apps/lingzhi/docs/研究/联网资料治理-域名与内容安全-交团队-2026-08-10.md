# 第一部分：中文教育域名信誉分级

## 1.1 问题：中文课题的可用来源显著偏少

真实 SearXNG 实测（2026-08-08，每次查询间隔 12 秒避开上游限流）：

| 课题 | 网关 admitted | 其中 tier_a（真正自动进链） |
| --- | --- | --- |
| 线性代数 特征值 | 14 | 3 |
| 高等数学 极限 | 14 | 1 |
| 大学物理 电磁学 | 11 | 3 |
| 数据结构 二叉树 | 10 | **0** |

合计 tier_a 7 条 / tier_b 42 条。`admitted_sources()` 只放行 tier_a
（tier_b 需教师逐条接受），所以中文课题常常没有资料能自动进入生成上下文。
英文课题同口径下 tier_a 稳定 3–4 条（MIT OCW、Purdue、CUNY 等）。

## 1.2 先纠正一个容易误判的事实

`.edu.cn` 与 `.gov.cn` **已经在** `_DEFAULT_TIER_A_DOMAINS` 里
（当前共 8 项），中国高校课程站（如 `course.ynu.edu.cn`、`dxwl.bnu.edu.cn`）
本来就判 tier_a。

**所以缺口不是"中文域名全被排除"**，而是三类站点用的是独立商业域名：
国家级教育平台、权威出版社与学术数据库、主流 MOOC 平台。

## 1.3 建议加入 tier_a（分三级，按风险递增）

### P0 国家级教育平台（风险最低，建议先做）

| 域名 | 说明 | 当前判定 |
| --- | --- | --- |
| `smartedu.cn` | 国家智慧教育公共服务平台（教育部主办） | tier_b |
| `eduyun.cn` | 国家教育资源公共服务平台（中央电化教育馆） | tier_b |

理由：主办方权威性等同 `.gov.cn`，实测检索中确有产出。

### P1 主流 MOOC 平台

| 域名 | 说明 | 当前判定 |
| --- | --- | --- |
| `icourse163.org` | 中国大学MOOC（高教社+网易） | tier_b |
| `xuetangx.com` | 学堂在线（清华发起） | tier_b |
| `cnmooc.org` | 好大学在线（上海交大发起） | tier_b |

理由：课程由 985/211 高校官方开设，等同高校课程站。
⚠ 注意这类站点课程页多为**导航页而非正文**，摘要往往很短，
加入后需观察 `missing_excerpt` 拒绝率是否上升。

### P2 出版社与学术数据库（需先定版权口径，见 1.5）

| 域名 | 说明 |
| --- | --- |
| `hep.com.cn` | 高等教育出版社 |
| `pep.com.cn` | 人民教育出版社 |
| `cnki.net` / `wanfangdata.com.cn` | 知网 / 万方 |
| `sciencedirect.com` / `springer.com` | Elsevier / Springer（与已在名单的 arxiv、pubmed 同级但当前缺失） |

## 1.4 明确**不建议**提升的域名（同样重要）

实测中占 tier_b 大头的是 UGC/博客平台，**当前判 tier_b 是正确的**：

| 域名 | tier_b 出现次数 | 不建议理由 |
| --- | --- | --- |
| `zhuanlan.zhihu.com` / `zhihu.com` | 10 | 用户生成内容，无编审，质量方差极大 |
| `blog.csdn.net` | 7 | 同上，转载与错误内容常见 |
| `cloud.tencent.com` / `developer.aliyun.com` | 5 | 厂商开发者社区，非教学材料 |
| `cnblogs.com` / `juejin.cn` | 5 | 技术博客平台 |
| `baike.baidu.com` | 5 | 可编辑百科，不宜作教学事实源 |
| `bilibili.com` | 3 | 视频站，摘要不足以支撑生成 |
| `mp.weixin.qq.com` | 3 | 公众号文章，无稳定出处 |

**关键理由**：`classify_source()` 里
`accepted_for_generation = (trust_tier == "tier_a")`（`web_retrieval.py:913`），
加入 tier_a 等于**允许该域名内容不经教师确认直接进入教学材料**。
名单只应包含"机构有编审责任"的站点。教师若确认某条 UGC 内容有用，
仍可逐条接受，这条路没堵。

## 1.5 需要团队决策的两点

1. **付费墙与版权口径**：知网/万方/ScienceDirect 多数内容在付费墙后。
   检索能拿到摘要，我方落地的也是网关给的 `excerpt`（摘要），
   不绕过付费墙，理论上合规；但"把论文摘要作为教学材料"是否恰当，
   建议与法务确认。出版社站点内容受版权保护，当前落地策略是
   `reuse_policy=reference_only`（未标注开放许可时只引用不逐字复用），
   这层保护仍在。
2. **灰度方式**：建议先只加 P0，观察一周（tier_a 产出量、
   `missing_excerpt` 拒绝率、教师反馈），再决定 P1/P2。

## 1.6 配置写法与一个坑

```bash
WEB_RETRIEVAL_TIER_A_DOMAINS=".gov,.gov.cn,.edu,.edu.cn,arxiv.org,doi.org,openstax.org,pubmed.ncbi.nlm.nih.gov,smartedu.cn,eduyun.cn"
```

⚠ **`WEB_RETRIEVAL_TIER_A_DOMAINS` 一旦设置就整体替换默认清单**
（`RetrievalGateway.__init__`：`tier_a_domains or configured_domains or _DEFAULT`），
必须把原有 8 项一并写进去，不能只写新增项。
**建议团队考虑改成"默认清单 + 追加项"的语义**，这个坑很容易踩。

# 第二部分：语义级内容安全

## 2.1 问题：只有形式安全

进入教学材料前的门全部是形式判定：

| 现有门 | 判什么 |
| --- | --- |
| `unsafe_url` | 是否公开 https、host 是否合法 |
| `prompt_injection` | 是否含"忽略之前指令"类注入话术 |
| `low_relevance` | 查询词与标题/摘要重合度 < 0.55 |
| 域名信誉 | 是否命中 tier_a 清单 |

加上搜索引擎侧 `safesearch=2` / `moderation=true`，但那是**通用色情暴力过滤**，
不解决教育场景问题。

**缺口**：一个 `.edu` 域名下、相关性高、无注入话术的页面会被判
`accepted_for_generation=True` 直接进生成上下文，而它可能是：
事实性错误（过时结论、被撤稿的研究）、学术争议内容（未定论假说被表述为定论）、
价值观敏感内容、教学不适宜内容（面向研究者而非学生的深度内容）。

教育产品对这几类的容忍度显著低于通用搜索。

## 2.2 四条设计原则

1. **只做内容标记，不做内容审查。** 不替教师判断对错，只标出
   "这条需要你看一眼"。教师是最终决策者。
2. **不引外部依赖。** 不引第三方审核 API（延迟、成本、数据出境风险）。
3. **不阻断生成。** 判定失败降级为"标记未知"，与现有 `degraded` 语义一致，
   内容安全不能成为新的生成失败源。
4. **复用既有分级，不新建平行真源。**

## 2.3 三层方案（按成本递增）

### 第 1 层：敏感主题词表 —— **已实施**

`backend/web_content_safety.py`，commit 9cecc549。

- 初版只覆盖 **medical_advice**（剂量/处方/禁忌症/不良反应/dosage…）与
  **unsettled_science**（尚有争议/有待验证/hypothesis…）两类。
  这两类在教学场景最常见、最容易误导学生；其余主题留配置位。
- 英文词做词边界匹配（`prescriptionless` 不误命中 `prescription`），
  中文词包含匹配。
- 命中则把 `accepted_for_generation` 从 True **降为 False**
  （自动进链 → 需教师确认），**但仍保留在候选列表里，内容原样不动**。
- 回传命中主题与命中词（上限 5 个），教师能看到"为什么被标"。

**接入点说明**：原设计写在网关 `classify_source()`，实际落在我方
`web_material_search.candidate_from_source()` —— 那是所有联网来源进资料链的
必经点，且不与团队 `web_retrieval.py` 争同一文件，效果等价。
**若团队认为应当收归网关统一处理，这段逻辑可以整体搬过去**，
`assess_sensitivity()` 是纯函数，无状态、无外部依赖。

11 个测试函数 / 17 个执行用例（含参数化），覆盖"必须标记"与"必须放行"两组样本（对应开发禁区 3.3），
并做了变异测试确认守卫会真失败。

### 第 2 层：时效与撤稿信号 —— 待评审

教育材料里"过时"比"错误"更常见。已有 `published_date` 字段但只用于
`missing_date_for_current_query`。建议扩展：

- 学科时效分三档：fast（技术/医学，2 年）、medium（社科，5 年）、
  slow（数学/基础学科，不限）；超期标 `stale_for_subject`。
- 检测 `retracted` / `撤稿` / `更正声明` / `erratum`，命中直接降 tier_c。

### 第 3 层：LLM 教学适宜性评审 —— 待评审

对已过前两层、准备进入正文的来源调一次轻量 LLM 判定：

```
输入：标题 + 摘要（≤800 字）+ 课程主题与学段
输出：suitability: suitable | needs_review | unsuitable
     reasons: [factual_risk | age_inappropriate | ideological_sensitive | out_of_scope]
     one_line_note: 给教师看的一句话
```

约束：用 fast 模型控成本；每次生成调用数 ≤ `max_sources`（即最多 8 次）；
**调用失败一律降级为 `needs_review`**，不阻断生成、不默认放行；
结果写入 `sensitivity.llm_review`，与规则层结果并存不互相覆盖。

代价：每门课最多 8 次 fast 调用，成本可忽略，生成时长 +2–5 秒（可并发）。

## 2.4 教师端呈现（未做）

审阅面板已有"采用/排除"两栏，建议增加**第三栏"建议复核"**：

```
联网资料                              已就绪
采用 3 条 · 建议复核 2 条 · 已排除 5 条

⚠ 建议复核
  《XX 疗法的临床应用》  medical_advice · 含"剂量"表述
  https://example.edu/...     [采用] [剔除] [打开原文]
```

后端字段已就绪（候选上挂了 `sensitivity`），只差界面接线与 i18n。

## 2.5 明确不做的事

- 不自动删改内容（只标记与降级，不改写来源正文）
- 不做政治立场判定（词表只标"该主题需人工看"，不判对错）
- 不引第三方审核 API
- 不把安全判定做成阻断门

（`127.0.0.1:8080`，镜像 `sha256:f4c8e59de166...`）2026-08-08 的实际检索，
