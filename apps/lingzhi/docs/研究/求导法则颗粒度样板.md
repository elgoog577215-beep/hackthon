## 知识树样板

```text
导数与求导（分类，非元知识）
├─ 基本函数求导（分类）
│  └─ K-CONST：常数函数的导数为零
├─ 求导运算法则（分类）
│  ├─ 线性运算（分类）
│  │  ├─ K-MUL：常数倍求导法则
│  │  └─ K-ADD：和函数求导法则
│  ├─ K-PROD：两函数乘积求导法则
│  ├─ K-QUOT：两函数商求导法则
│  └─ K-CHAIN：复合函数求导法则
└─ 前置知识引用入口（只用于本样板说明，不另建正式分类）
   └─ K-COMP：函数复合的含义与顺序 → 复用本课“函数”分支原节点
```

共列出 6 个求导元知识候选和 1 个前置概念引用，不以这 7 个编号要求实际课程新增 7 个节点。K-COMP 在正式树中只保留一个主要位置；求导分支引用它，不复制正文。单个乘积、商或链式规则直接作为叶子，不再套同义分类。此片段不代表基本函数求导或整门课程已覆盖。

减法、有限线性组合、含多个因子的具体求导题、多层复合题，先作为已列知识的应用或综合检查。若真实材料明确给出具有独立内容的一般命题或方法，再按正式规格判断是否新增元知识；不能仅因题目更难就另建知识身份。

## 元知识候选档案

各档案独立带条件，不能依靠父分类补齐条件。`x₀` 为被求导的点，`c` 为对自变量不变的实常数。下表均为 r1、来源待绑定；数学上的前置成立不证明具体学生已掌握前置。

| 编号与名称 | 元问题与完整知识核 | 条件与边界 | 引用和停止拆分理由 |
| --- | --- | --- | --- |
| K-CONST 常数函数求导 | 问：常数函数在某点的变化率是什么？若 `h(x)=c` 在 `x₀` 的邻域成立，则 `h′(x₀)=0` | `c` 不随自变量变化；非恒定函数即使某点取值为 c，也不能据此判断该点导数为零 | 引用导数含义；“函数值是常数”和“导数为零”共同组成该完整规则，不拆成词语叶子 |
| K-MUL 常数倍求导 | 问：函数乘以固定常数后，导数怎样变化？`(cf)′(x₀)=c f′(x₀)` | `f` 在 `x₀` 可导，`c` 为常数；变系数 `a(x)f(x)` 不能直接套本规则 | 与 K-CONST 内容不同：一个求常数函数导数，一个描述乘法运算的求导性质；系数识别是检查项 |
| K-ADD 和函数求导 | 问：两个函数之和如何求导？`(f+g)′(x₀)=f′(x₀)+g′(x₀)` | `f、g` 在 `x₀` 均可导；本规则只陈述充分条件，不主张和可导必然推出各项可导 | 与 K-MUL 可分别理解和检查；差函数通过 K-MUL 的 `c=-1` 与本规则组合，先作应用检查 |
| K-PROD 两函数乘积求导 | 问：两个函数的乘积如何求导？`(fg)′(x₀)=f′(x₀)g(x₀)+f(x₀)g′(x₀)` | `f、g` 在 `x₀` 均可导；不能把乘积导数写成两个导数的乘积 | 两项与对应求值共同表达一个乘积规则；拆成“先求左边”“再求右边”会得到残缺叶子 |
| K-QUOT 两函数商求导 | 问：两个函数的商何时能按商法则求导？`(f/g)′(x₀)=[f′(x₀)g(x₀)-f(x₀)g′(x₀)]/[g(x₀)]²` | `f、g` 在 `x₀` 均可导，且 `g(x₀)≠0`；约分后的延拓函数不能直接替代原函数在缺失点的导数 | 非零条件、分子顺序、分母平方随完整规则保留；它们可分别观察，但不各自新增规则身份 |
| K-COMP 函数复合 | 问：`f(g(x))` 的输入输出顺序是什么？先由 `x` 得到 `g(x)`，再将其作为 `f` 的输入；`(f∘g)(x)=f(g(x))` | `x` 属于 g 的定义域，且 `g(x)` 属于 f 的定义域；复合分解可能不唯一，须按题目给定分解或接受等价合理分解 | 复用已有概念；内外函数名称、顺序和定义域共同构成概念，不按字词拆分 |
| K-CHAIN 复合函数求导 | 问：复合函数的导数如何由内外函数导数表示？`(f∘g)′(x₀)=f′(g(x₀))g′(x₀)` | g 在 `x₀` 可导，f 在 `g(x₀)` 可导，复合在邻域内有定义；不能把外层求值位置写成 `x₀` 或漏掉内层导数 | 引用 K-COMP 与导数记号；条件、外层求值位置和内层因子组成一个完整规则，多层重复应用不自动新增叶子 |

可独立讲清的规则不因彼此可以推导就一律归并；例如 K-MUL 可以借助其他规则说明，仍有独立运算含义。是否保留该节点取决于本课内容与学习起点，不能把“可推导”当作所有知识都应合并的理由。

## 检查项与实际任务

检查项描述要观察什么，不进入知识树叶子；下列任务是人工设计的检查示例，不是已采用的正式题目。每项在使用前还要绑定真实知识、题目、评分及检查修订，核对适合该学习者的前置与语言要求。内容表正确不等于取得 `atomic_assessment_v1` 或其他单点证据资格。

| 检查项编号 | 目标知识与观察内容 | 示例任务及参考判断 | 能说明什么，不能直接说明什么 |
| --- | --- | --- | --- |
| C-CONST-1 | K-CONST：区分函数值与变化率 | `h(x)=7`，求 `h′(2)` 并说明理由。答：0，因 h 在邻域为常数函数 | 可观察规则理解；仅写 0 不能充分区分理解与记忆 |
| C-MUL-1 | K-MUL：执行常数倍规则 | 已知 `f′(x₀)=2`，求 `(3f)′(x₀)`。答：6，说明 3 为固定系数 | 已给基础导数，减少其他求导技能干扰；一次通过不证明所有系数情境都稳定 |
| C-MUL-2 | K-MUL：识别规则适用边界 | `xf(x)` 能否直接按固定常数倍规则求导？答：不能，系数 x 随自变量变化 | 观察条件辨析；本问不要求完成乘积求导，也不据此判定 K-PROD |
| C-ADD-1 | K-ADD：执行和函数规则 | 已知 `f′(x₀)=2、g′(x₀)=-5`，求 `(f+g)′(x₀)`。答：-3 | 负号运算也可能导致错误；需要过程或解释，不能从错误结果直接诊断规则不懂 |
| C-LINEAR-1 | K-MUL、K-ADD：综合应用 | 同上，求 `(3f-g)′(x₀)`。答：11；先分别使用常数倍与和函数规则 | 是多目标检查；没有逐点依据时不把整题结果分摊为两点对错 |
| C-PROD-1 | K-PROD：构造两项并保持因子位置 | 用 f、g 及其导数写出 `(fg)′`，解释每项中哪个因子求导 | 可观察规则结构；机械背写不能单独证明应用能力 |
| C-PROD-2 | K-PROD：在给定数值下执行 | `f(x₀)=2、f′(x₀)=3、g(x₀)=5、g′(x₀)=7`，求 `(fg)′(x₀)`。答：`3×5+2×7=29` | 过程可定位漏项或算术错误；结果错误仍可能来自代入和计算 |
| C-QUOT-1 | K-QUOT：分子顺序与分母 | 使用上一行数值，求 `(f/g)′(x₀)`。答：`(3×5-2×7)/25=1/25` | 多个观察点仍属于同一商规则；需保留过程以区分符号、公式和计算问题 |
| C-QUOT-2 | K-QUOT：判断适用范围 | 问原函数 `(x²-1)/(x-1)` 在 `x=1` 能否直接按商法则求导。答：原函数在该点未定义，不能；其延拓函数是另一个对象 | 条件检查而非新知识叶子；不能把约分后函数的导数回填给原函数缺失点 |
| C-COMP-1 | K-COMP：解释复合结构 | 对 `sin(x²)`，在指定 `f(t)=sin t` 时写出 g。答：`g(x)=x²`，先平方再取正弦 | 不要求求导，用于区分结构问题与求导执行问题；接受符合题目约束的表达 |
| C-CHAIN-1 | K-CHAIN：外层求值与内层因子 | 已给 `g(x₀)=4、g′(x₀)=3、f′(4)=5`，求 `(f∘g)′(x₀)`。答：15 | 减少基本函数求导干扰，观察规则执行；一个答案不能确证具体错误策略 |
| C-CHAIN-2 | K-COMP、K-CHAIN 及基本求导：应用 | 对 `sin(x²)` 求导并标出所用结构。答：`2x cos(x²)` | 综合应用；若基本求导出错，不直接归因链式规则 |
| C-CHAIN-3 | K-CHAIN：改变函数记号后的应用 | 已知 `F′(t)=2t`，求 `F(3x+1)` 的导数。答：`6(3x+1)` | 观察从显式熟悉函数到函数记号的变化；是否足以称迁移取决于此前接触与帮助暴露 |
| C-CHAIN-4 | K-CHAIN：多层复合执行 | 对 `sin((3x+1)²)` 求导。答：`6(3x+1)cos((3x+1)²)` | 是多层应用情境，包含基本求导；不单凭难度增加新增元知识点 |

每个检查项保留情境、预期表现、可接受解释、替代错误原因及帮助情况。检查可按实际需要选取，不要求每个学生逐项作答，也不要求每次问答诊断完所有知识。

### 同一知识下的困难如何区分

| 后续可观察的组合 | 可以形成的有限判断 | 有针对性的帮助及验证方向 |
| --- | --- | --- |
| 在明确题意下仍无法按指定外层写出内层，并在解释中颠倒先后顺序 | 对 K-COMP 的结构理解存在困难迹象；仍需排除题意和符号理解问题 | 解释输入输出顺序，再换表达式让学生独立辨认 |
| 能解释复合，也能单独求内层导数，但在不同适当任务中重复漏乘 | 支持 K-CHAIN 执行不稳定的候选判断；不能据此宣称概念完全掌握 | 先分步标记各层与因子，随后撤去提示，用新任务观察 |
| 熟悉显式函数任务可独立完成，改成函数记号后失败 | 对该变化情境存在应用困难；不能概括为所有迁移能力不足 | 比较两种表示的共同结构，之后用未见的新表示检查 |
| 后续多项相关任务能独立完成，甲能指出并解释原遗漏 | 原错误也可能是偶发遗漏，不宜持续标为确定概念缺失 | 可选自查提示，保留历史；不安排无依据的大量补学 |

这些组合不构成固定次数阈值。实际可采用程度仍按已有证据准入、评价有效性、来源与画像规则判断；相同任务的重复分析不能算多项独立表现。

若 E-03 仍漏乘，记录“本次帮助后仍未独立通过，效果尚不明确”，重新核对结构、前置和执行假设，不能因为展示过讲解就宣布补齐。若后续发现甲其实不懂内层幂函数求导，则新增更正关系修订 J-01 的解释，保留原错答、原假设和更正依据。

本人笔记或对话提到 E-01 时，只增加来源引用；AI 整理后的正确笔记不是新的本人独立作答。同一活动的红绿批改历史保留，不能相消后伪装成从未发生过错误。
