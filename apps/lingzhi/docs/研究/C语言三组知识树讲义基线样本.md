## 三条易错诊断

### 数值类型转换

- 错误信念A：误以为两个int的除法也保留数学上的小数商。
- 错误信念B：知道int除法会截断，但误以为左侧double接收变量会反向把右侧int除法变成浮点除法。

| 检查阶段 | 正确输出 | 按A预测 | 按B预测 |
| --- | --- | --- | --- |
| 共同表现 | `2.00` | `2.33` | `2.33` |
| 区分题 | `2.00` | `2.33` | `2.00` |
| 变式复测 | `2.00 2.75` | `2.75 2.75` | `2.00 2.75` |

正确输出来自原程序执行，A/B来自固定错误规则的反事实模拟，不是C语言的另一种正确解释。

**共同表现代码**

```c
double x=7/3; printf("%.2f\n",x);
```

**区分题代码**

```c
printf("%.2f\n",(double)(7/3));
```

**变式复测代码**

```c
printf("%.2f %.2f\n",(double)(11/4),(double)11/4);
```

- 补救A：先判定运算操作数类型：两个int相除在有定义时得到向零截断的整数商；需要小数时先转换一个操作数。
- 补救B：区分右侧表达式求值与接收转换：左侧double只转换已经算出的值，不会恢复已丢弃的小数。

观察结果只支持某种错误解释；还可能存在猜测、粗心或其他知识缺口，不能直接判定学生的真实错因。

### for 控制流

- 错误信念A：误以为continue等同于break，遇到后直接退出整个for，不再更新。
- 错误信念B：误以为continue只跳过本轮剩余循环体和第三部分更新，直接回到条件判断。

| 检查阶段 | 正确输出 | 按A预测 | 按B预测 |
| --- | --- | --- | --- |
| 共同表现 | `7 4` | `6 4` | `6 4` |
| 区分题 | `6 5` | `4 4` | `6 6` |
| 变式复测 | `8 4` | `7 4` | `7 4` |

**共同表现代码**

```c

```

```c

 hits++;

```

```c

```

## 综合应用

分别判断内层for中的break和continue转移到哪里，之后外层从哪里继续。

没有更内层包围结构时，内层for的continue执行该内层for的第三部分再判断；break结束内层for，并从其后的语句继续。二者均不自动转移或结束外层for。
