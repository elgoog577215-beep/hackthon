### c_continue

在一个 for 循环中，如果某轮循环体内遇到 continue 语句（且非最后一轮），紧接着下一步会执行 for 循环头部的哪一部分？

```c
int x = 0;
for(int i = 0; i < 5; i++) {
    if(i == 2) {
        continue;
    }
    x += i;
}
printf("x=%d", x);
```

模型预测：`'x=14'`

实测答案：`'x=8'`

状态：sample_verified；仅证明该样例在本机执行结果。

模型解释（待审）：continue 语句跳过了当前轮次循环体中 continue 之后的所有代码（此处为 x += i）。但程序控制权会转移到 for 循环头部，首先执行迭代表达式（i++），然后重新判断控制条件（i < 5）。在此题中，i 为 0, 1, 3, 4 时正常累加到 x 中。0+1+3+4=8。修正：由于是 i=0,1,2,3,4。当 i=2 时，不执行 x+=i，但继续执行 i++，变为 3；i=3 时，x+=3；i=4 时，x+=4。总计 x = 0+1+3+4 = 8。

### c_break

在一个 for 循环中，如果在循环体内执行 break 语句跳出该循环，循环头部的迭代/更新表达式（第三部分）在 break 之后会被执行吗？
