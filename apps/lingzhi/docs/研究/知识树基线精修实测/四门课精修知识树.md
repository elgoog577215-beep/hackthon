### 元知识

#### P1 列表赋值不复制

对列表执行赋值 b=a 会使 b 和 a 指向同一个列表对象，该操作本身不会复制列表的内容。

元问题：列表赋值操作是否创建了新列表？

核心回答：不创建新列表，两个名字指向同一对象。

生效条件：Python 3基础；普通内置列表，不涉及自定义复制协议。；只讨论这些普通列表操作。；a引用普通列表；执行赋值语句b=a

- 原文 `M1 / C1`：赋值b=a使两个名字指向同一列表，不会复制列表。
- 附件 `scope / C9`：只讨论这些普通列表操作。

#### P2 共享列表内容修改同步

当两个名字指向同一列表时，通过其中一个名字对该列表对象进行内容修改，另一个名字访问时会观察到同一对象的变化。

元问题：修改共享列表的内容时，另一个引用该列表的名字能否看到变化？

核心回答：能看到，因为它们指向同一对象。

生效条件：Python 3基础；普通内置列表，不涉及自定义复制协议。；只讨论这些普通列表操作。；两个名字指向同一列表对象；通过其中一个名字修改列表内容（非重新绑定名字）

- 原文 `M1 / C2`：通过其中一个名字修改该列表，另一个名字会看到同一对象的变化
- 附件 `scope / C9`：只讨论这些普通列表操作。

#### P3 变量重新绑定独立性

当 b=a 时，将 b 重新绑定到一个全新的列表上，不会使 a 指向新列表，a 仍保持指向原来的列表对象。

元问题：重新绑定变量 b 到新的列表后，原变量 a 的指向会发生改变吗？

核心回答：不会，a 仍指向原列表，b 指向新列表。

生效条件：Python 3基础；普通内置列表，不涉及自定义复制协议。；只讨论这些普通列表操作。；初始状态 b 和 a 指向同一列表；执行 b = 新列表 操作

- 原文 `M1 / C3`：将b重新绑定到新列表不会重新绑定a。
- 附件 `scope / C9`：只讨论这些普通列表操作。

#### P4 浅拷贝创建新外层对象

调用a.copy()会创建一个新列表，该新列表是原列表的浅拷贝，即外层列表对象是新建的。

元问题：list.copy()操作创建的外层对象与原列表的外层对象是否相同？

核心回答：不同，copy创建新的外层列表对象。

生效条件：Python 3基础；普通内置列表，不涉及自定义复制协议。；只讨论这些普通列表操作。；a是列表；调用a.copy()方法

- 原文 `M2 / C4`：a.copy()新建外层列表
- 附件 `scope / C9`：只讨论这些普通列表操作。

#### P5 浅拷贝外层独立性

对 a.copy() 返回的新外层列表执行 append 操作，不会影响原外层列表的内容。

元问题：在浅拷贝的列表上添加元素，原列表会增加该元素吗？

核心回答：不会，原列表外层内容不变。

生效条件：Python 3基础；普通内置列表，不涉及自定义复制协议。；只讨论这些普通列表操作。；b 是 a 的浅拷贝 (b = a.copy())；对 b 执行 append 操作

- 原文 `M2 / C5`：对新外层append不改变原外层。
- 附件 `scope / C9`：只讨论这些普通列表操作。

#### P6 嵌套元素共享引用

对于包含嵌套列表的列表，使用浅拷贝后，新列表中的对应元素仍然引用与原列表完全相同的内层列表对象。

元问题：浅拷贝列表中嵌套的子列表对象，与原列表中的子列表对象是同一个吗？

核心回答：是同一个，引用相同。

生效条件：Python 3基础；普通内置列表，不涉及自定义复制协议。；只讨论这些普通列表操作。；原列表包含嵌套列表；执行浅拷贝操作

- 原文 `M2 / C6`：对于嵌套列表，浅拷贝的对应元素仍引用同一个内层列表
- 附件 `scope / C9`：只讨论这些普通列表操作。

#### P7 共享内层修改同步

如果一个内层列表被原列表和浅拷贝后的列表共同引用，对该共享的内层列表执行 append 操作，两个外层列表都能观察到该内层元素的变化。

元问题：修改浅拷贝列表中嵌套的子列表，原列表中的对应子列表会变化吗？

核心回答：会变化，因为内层对象是共享的。

生效条件：Python 3基础；普通内置列表，不涉及自定义复制协议。；只讨论这些普通列表操作。；原列表和浅拷贝列表共享同一个内层列表对象；对该共享的内层列表执行 append 操作

- 原文 `M2 / C7`：对共享内层append会同时从两个外层观察到变化。
- 附件 `scope / C9`：只讨论这些普通列表操作。

#### P8 浅拷贝元素重新绑定独立性

对浅拷贝后的列表 b 的某个元素（如 b[0]）重新赋值为一个新的列表，这个操作只会修改 b 的对应元素引用，不会改变原列表 a 的对应元素（a[0]）。

元问题：将浅拷贝列表中某个嵌套元素替换为新列表，原列表的对应元素会变吗？

核心回答：不会变，只改变了浅拷贝列表中的引用。

生效条件：Python 3基础；普通内置列表，不涉及自定义复制协议。；只讨论这些普通列表操作。；b 是 a 的浅拷贝；对 b[i] 执行 b[i] = 新列表 操作

- 原文 `M2 / C8`：对浅拷贝的b[0]重新赋一个新列表，只改变b的该元素引用，不改变a[0]。
- 附件 `scope / C9`：只讨论这些普通列表操作。

函数在点a处连续当且仅当同时满足f(a)有定义、x趋于a的双侧有限极限存在，且该极限值等于f(a)。

#### P3 可导性的判定条件

生效条件：实函数在内点a的双侧有限导数与连续性；不讨论端点单侧定义。；本单元只讨论定义域内点a。；点a属于定义域

- 原文 `M1 / C3`：点处可导意味着差商[f(a+h)-f(a)]/h在h趋于0时存在有限双侧极限。
- 附件 `scope / C1`：本单元只讨论定义域内点a。

#### P4 左右导数不一致的后果

元问题：左右差商极限不相等对导数存在性有何影响？

#### P1a 同次相互作用力等大

#### P6 系统内力定义

若将物体A和B共同选为一个系统，它们之间产生的相互作用力属于该系统的内力。

元问题：当A和B作为一个系统时，它们之间的相互作用力属于什么性质的力？

核心回答：属于系统内力。

- 原文 `M2 / C7`：若将A+B一起选为系统，A/B相互作用属于内力

#### P7 系统内力抵消与外力关系

在系统内力中，成对的作用力与反作用力求和相互抵消，但这并不等同于该系统的总外力合力为零。

生效条件：经典力学，宏观低速情境；分析系统的内力与外力关系

- 原文 `M2 / C8`：其配对求和抵消不等于外力合力为零。
