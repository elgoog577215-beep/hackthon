# 求导时，固定倍数保留，各项分别求导后相加减

看到一个长一点的式子，先不用着急。例如：

$$y=3x^2-2x+5.$$

它是几项相加减。我们把它拆开，分别求导，再按原来的加减号合起来。

先把下面三件事弄清楚，这类题就容易做了。

## 知识点一：固定的数，导数是0

例如 $y=7$。不管 $x$ 怎样变化，$y$ 都是7，没有变化。

所以：

$$\boxed{(7)'=0.}$$

导数问的是“怎样变化”，不是“这个数原来是多少”。因此，7的导数不是7。

只要 $c$ 是不随 $x$ 变化的固定数，就有：

$$\boxed{(c)'=0.}$$

如果只是某个函数在一个位置的值恰好是7，不能因此说它的导数就是0；这里说的是整个函数都等于固定的数。

## 知识点二：前面乘着固定的数，就保留这个数

例如：

$$y=3x^2.$$

3是固定的数。先保留3，只对 $x^2$ 求导：

$$\boxed{y'=3\cdot2x=6x.}$$

这里求导的是整个 $3x^2$，不能把前面的3求导成0，再把后面全部乘没了。

如果把后面的函数叫作 $f(x)$，公式就是：

$$[cf(x)]'=cf'(x).$$

使用这条规则时，$c$ 必须是固定的数，$f$ 在要求导的位置能够求导。比如 $-4x^3$ 中的 $-4$ 也要完整保留：

$$(-4x^3)'=-4\cdot3x^2=-12x^2.$$

## 知识点三：几项加减，就分别求导，再按原来的符号合起来

回到开头这道题：

$$y=3x^2-2x+5.$$

先分别看三项：

- $3x^2$ 的导数是 $6x$。
- $2x$ 的导数是2。
- 固定的数5的导数是0。

保留原来的减号和加号：

$$y'=6x-2+0.$$

所以：

$$\boxed{y'=6x-2.}$$

也可以把原式看作 $3x^2+(-2x)+5$，对三项分别求导，得到的还是 $6x+(-2)+0$。

用两个函数来写，就是：

$$[f(x)+g(x)]'=f'(x)+g'(x),$$

$$[f(x)-g(x)]'=f'(x)-g'(x).$$

这里要求各项在你要求导的位置都能求导。把固定倍数和加减的这几条放在一起，就称为**线性法则**。

## 如果你把原来的5留在了答案里

可以先这样一起看：

> 先只看最后这一项5。它会随着 $x$ 改变吗？这一步我们要写的是它的导数，还是把原来的5抄下来？

如果是减号写丢了，就先把原式的三项和符号各占一行，再分别求导，不用重做其他已经写对的部分。

## 注意：固定的3，和会变化的 x，不是一回事

比较下面两个式子：

$$3\sin x,\qquad x\sin x.$$

第一个式子里，3是固定的数，可以保留3：

$$(3\sin x)'=3\cos x.$$

第二个式子里，$x$ 和 $\sin x$ 都随 $x$ 变化，要用[乘积法则](乘积法则学生学习稿.md)：

$$(x\sin x)'=\sin x+x\cos x.$$

所以，先看清楚式子里是**固定倍数、加减，还是两个函数相乘**，再选择做法。这里的三角函数都采用弧度。

## 选一道题自己试试

1. **只看常数：** $y=9$ 的导数是多少？
2. **保留固定倍数：** 求 $y=-2x^4$ 的导数，再求 $y=5x^2$ 的导数。
3. **把几项合起来：** 求 $y=2x^3-3x+7$ 的导数。
4. **留意负号：** 求 $y=3\sin x-2\cos x$ 的导数。
5. **函数名字换了也一样：** 已知 $f'(2)=4$、$g'(2)=-1$，两个函数在2处都能求导。对 $y=2f(x)-3g(x)+5$，求 $x=2$ 时 $y$ 的导数。

<summary>做完后，再展开看答案</summary>

1. $y'=0$，因为9是固定的数。
2. $(-2x^4)'=-8x^3$；$(5x^2)'=10x$。两个固定系数都保留，负号也保留。
3. $y'=2\cdot3x^2-3\cdot1+0=6x^2-3$。
4. $y'=3\cos x-2(-\sin x)=3\cos x+2\sin x$。第二项原有一个减号，cos求导后又有一个负号，合起来变成加号。
5. $y'(2)=2f'(2)-3g'(2)+0=2\times4-3\times(-1)=11$。
