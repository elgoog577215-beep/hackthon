# 复合函数求导：别漏掉里面这一步

这份内容适合已经学过导数、正在练习复合函数求导的同学。我们从一道题开始：

$$y=\sin(x^2)$$

它的导数怎么求？

## 先看清：这个式子分几步算

看到 $\sin(x^2)$，先别急着求导。想一想，如果给你一个 $x$，你会怎样算出这个函数的值？

1. 先算 $x^2$。
2. 再对这个结果取正弦。

所以，**里面是平方，外面是正弦。**

例如，$x=2$ 时，先得到 $x^2=4$，再算 $\sin 4$。

这种“一层套一层”的函数叫作**复合函数**。注意，$\sin(x^2)$ 和 $(\sin x)^2$ 不一样：前者先平方，后者先取正弦。

## 再分别看：里面和外面怎样求导

这道题需要用到两条基本规则：

$$ (x^2)'=2x,\qquad (\sin u)'=\cos u. $$

这里用 $u$ 暂时代替里面的整块 $x^2$，不是又多出了一道题。

求导时，先把 $x^2$ 看成一整块：

- 对外面的 $\sin$ 求导，得到 $\cos(x^2)$。**里面的 $x^2$ 先保留。**
- 再求里面 $x^2$ 的导数，得到 $2x$。
- 最后把这两部分乘起来。

$$y'=\cos(x^2)\cdot 2x=2x\cos(x^2).$$

**外面求导后，还要乘里面的导数。** 这就是这道题用到的链式法则。

这道题里的平方函数和正弦函数都能在相应位置求导，可以使用这条规则。遇到其他函数时，也要先确认它们在对应位置能求导；三角函数的角度采用弧度。

## 如果只写了 cos(x²)，接下来怎样学

假设你写的是：

$$y'=\cos(x^2).$$

这时，我们先分开看看是哪一步需要再练，而不是让你把整章重学一遍。

**可以先这样问：**

> 你写出了 $\cos(x^2)$。我们再看里面的 $x^2$：它的导数是多少？

接下来，根据你的回答，再决定讲哪一步。

| 你现在的情况 | 我们先做什么 |
| --- | --- |
| 分不清里面和外面的函数 | 先不求导，把“先平方、再取正弦”这两步写出来。 |
| 不会求 $x^2$、$x^3$ 的导数 | 先单独练平方和立方的求导，再回到原题。 |
| 对 sin、cos 的导数还不熟 | 先把这两条分开练，尤其留意 cos 求导后的负号。 |
| 外面求导后，不知道括号里该放什么 | 把里面的式子当作一整块，先完整保留，别直接换成 $x$。 |
| 两部分都会求，但最后漏乘 | 把“外面的导数”和“里面的导数”分别写在一行，再写出最后的乘积。 |
| 换成 F、A 这样的函数名字就不会了 | 先说明这些字母也是函数的名字，再按里面、外面两步做。 |

只凭一次答案，还不能确定你卡在哪里。你也可以直接说自己哪一步没想明白，我们就从那里开始。

## 外面求导后，为什么里面先不动

再看一道题：

$$y=(x^2+1)^3.$$

里面是 $x^2+1$，外面是“取三次方”。

先把括号里的内容当成一整块。对外面的三次方求导，得到：

$$3(x^2+1)^2.$$

注意，括号里的内容仍然是 $x^2+1$，不能直接换成 $x$。

再乘里面 $x^2+1$ 的导数 $2x$（常数1的导数是0）：

$$y'=3(x^2+1)^2\cdot 2x.$$

如果题目只给了函数名字，道理也一样。例如 $y=f(g(x))$，在 $x=1$ 时算出 $g(1)=9$，外面的 $f$ 接收到的就是9，因此要看 $f'(9)$，不是直接看 $f'(1)$。

## 换成 F，就还是同样的做法

$F$ 和 $\sin$ 一样，都是函数的名字。题目写成 $F(3x+1)$，仍然是先算里面的 $3x+1$，再把结果放进 $F$。

假设题目已经告诉你：

$$F'(u)=2u.$$

这句话说的是：$F$ 的导数在 $u$ 这个位置的值是 $2u$。

现在里面是 $3x+1$，就把它完整放进导数里的 $u$：

$$F'(3x+1)=2(3x+1).$$

再乘里面 $3x+1$ 的导数3：

$$[F(3x+1)]'=2(3x+1)\cdot3=6(3x+1).$$

函数名字换了，先看里面、再看外面的做法没有变。

## 听懂以后，换一道题自己试试

不用一次做完所有题，先选你刚才需要再练的那一步。

1. **认里面和外面：** $\sin(3x)$ 是先做哪一步，再做哪一步？先不求导。
2. **练基本求导：** $x^3$ 的导数是多少？$\cos x$ 的导数呢？
3. **练最后的乘法：** 求 $\cos(3x)$ 的导数，把外面和里面的导数分别写出来。
4. **换个函数名字：** 已知 $F'(u)=u^2$，求 $F(2x-1)$ 的导数。

1. 先算 $3x$，再取正弦。
2. $(x^3)'=3x^2$；$(\cos x)'=-\sin x$，角度采用弧度。
3. 外面求导得到 $-\sin(3x)$，里面的导数是3，所以结果为 $-3\sin(3x)$。
4. 外面求导得到 $F'(2x-1)=(2x-1)^2$，再乘里面的导数2，结果为 $2(2x-1)^2$。这里假设 $F$ 在所需位置可以求导。

如果看了提示或答案，可以再换一道题自己试试。你这次能自己做出来，是这次的进步；过一段时间再做一道，才能知道是不是还记得。

## 学习过程中，会怎样和你说

- **暂时没看懂：** “我们先只看里面的 $x^2$，暂时不用把整题做完。”
- **只写了一半：** “这个5是你最后的答案，还是先算出来的一步？”
- **跟着提示做对了：** “刚才我们一起做完了。下一道你可以自己试试，也可以先再看一个例子。”
- **新题自己做对了：** “这道新题你自己做出来了。刚才练的那一步，这次用上了。”
- **换题后又卡住了：** “这道题还需要一起看看。你觉得是里面没认清，还是求导时漏了一步？”

你可以选择继续练、先看讲解，或者稍后再学。
