### 本轮知识点

- **P1 赋值操作不创建副本**：执行赋值语句b=a时，系统不复制列表内容，而是使变量b指向与a相同的列表对象。
- **P2 共享对象的状态同步**：当两个变量指向同一列表对象时，通过其中任一变量修改该列表的内容（如修改元素），另一个变量读取时将观察到同样的变化。
- **P3 重新绑定的独立性**：将其中一个变量（如b）重新赋值绑定到一个新创建的列表对象，不会影响另一个变量（如a）原有的指向。
- **P4 浅拷贝创建新外层**：调用a.copy()会在内存中创建一个全新的列表对象（新外层），该新对象初始包含原列表的元素引用。
- **P5 外层操作的隔离性**：对通过copy()创建的新外层列表执行append操作添加新元素时，不会改变原外层列表的内容。
- **P6 嵌套元素的共享引用**：对于包含嵌套列表的浅拷贝，新列表与原列表在对应索引位置仍引用同一个内层列表对象。
- **P7 共享内层修改的全局影响**：对浅拷贝结构中共享的内层列表执行修改操作（如append）后，通过原列表和新列表观察内层，均会显示出变化。
- **P8 元素引用的独立重绑**：对浅拷贝列表的某个索引位置（如b[0]）重新赋值为一个新列表，仅改变新列表中该位置的引用，不改变原列表在相同位置的引用。

### 本轮知识点

- **P1 连续性判定条件**：在定义域内点a处，函数f(x)连续当且仅当f(a)有定义，且x趋于a的双侧有限极限存在并等于f(a)。
- **P2 可导性定义**：在定义域内点a处，函数f(x)可导当且仅当差商 [f(a+h)-f(a)]/h 在h趋于0时存在有限的双侧极限。
- **P3 左右差商判定导数**：若在点a处左差商极限和右差商极限不同，则点a处的导数不存在。
- **P4 可导必连续**：若实函数在定义域内的点a处可导，则它在该点必然连续。
- **P5 连续不保证可导**：实函数在定义域内的点a处连续，不能保证其在点a处可导。
- **P6 f(x)=|x|在0处的反例**：函数f(x)=|x|在点0处是连续的，但左导数为-1，右导数为1，故在0处不可导。
- **P7 不连续则不可导**：若实函数在定义域内的点a处不连续，则该函数在点a处不可导。
- **P8 不可导不反推不连续**：实函数在定义域内的点a处不可导，不能反向推断出它在该点不连续。

#### 连续与可导的操作性判定

给定函数f(x)=|x-2|，判断其在x=2处是否连续及是否可导。若可导给出导数，若不可导需通过计算左右差商极限说明原因。

- P1 → Q1：明确计算出x趋于2时|2-2|=0，并指出f(2)=0，因0=0判定连续。
- P2 → Q2：正确写出差商 [|2+h-2|-|2-2|]/h = |h|/h，并指出其双侧有限极限存在与否是判定核心。
- P3 → Q3：准确计算当h<0时|h|/h=-1，当h>0时|h|/h=1，并依据左右极限不等判定导数不存在。
- P6 → Q3：结论明确指出在0（或平移后的2）处不可导，且归因于左右差商极限分别为-1和1，与标准反例一致。

错因：计算差商极限时忽略h趋于0的方向性，直接将|k|/k约分消去绝对值符号（等同于默认k=|k|）。

预测：学生可能回答：差商|k|/k=1，极限为1，因此可导。

补救：重新阅读定义，强调双侧极限要求分别计算h>0和h<0时的差商。；手动代入h=-1/2, h=1/2等具体数值，验证|k|/k的结果在负数和正数方向是否相同。；核对计算出的左右极限值是否真正相等。

### 本轮知识点

- **P1 作用力与反作用力的大小关系**：在两物体A与B的一次相互作用中，A对B的力与B对A的力大小相等。
- **P2 作用力与反作用力的方向关系**：A对B的力与B对A的力方向相反。
- **P3 作用力与反作用力的受力对象**：A对B的力作用于B，B对A的力作用于A，即两个力分别作用在两个不同的物体上。
- **P4 作用力与反作用力成立的独立条件**：A对B的力与B对A的力等大反向，这一关系不以两物体质量相等或处于静止状态为前提。
- **P5 单物体受力图绘制原则**：画单个物体的受力图时，只列出该物体所受的力，不将该物体施加给其他物体的力画入图中。
- **P6 区分平衡力与作用反作用力**：作用反作用力作用在不同物体上，不能在单物体受力图上当作平衡力相消；平衡力必须在同一受力对象上考察。
- **P7 系统内力判定**：若将A和B一起选为系统，A与B之间的相互作用力属于该系统的内力。
- **P8 内力抵消与外力求和的区别**：在A+B系统中，A与B相互作用力的配对求和抵消，不等于该系统所受的外力合力为零。

- **P3 避免对手持材料价值的二元判断**：不能仅因材料是一手来源就认为其完全客观，也不能仅因其有立场就认定其毫无价值。
- **P4 互证的独立性标准**：判断两份材料能否互证时，必须检查来源是否独立以及记载的对象和时段是否可比。
- **P5 转载不构成独立见证**：两个文本如果仅仅是转载了同一报道或观点，它们不构成两份独立的见证。
- **P6 矛盾材料的处理方法**：当材料之间存在矛盾时，应列出具体差异、考察背景并寻找新证据，不能仅凭多数数量或预设立场判定真假。
- **P7 结论强度与证据边界**：有限的来源只能支持有限强度的结论，分析时必须区分“已能确定的”、“不能确定的”以及“下一步需要查证的”。
- **P8 材料A的立场与受众分析**：材料A（工厂经理年度报告）的受众是投资人，目的是展示产量增加及其对生活改善的推断，因此该主张受其受众和目的影响。
- **P9 材料B的观察与推断区分**：材料B（工人日记）提供了“收入增加”和“工作时间更长”这两个可观察到的私人记录，但缺乏对“生活质量”的总体推断。
- **P10 材料C的独立性判定**：材料C（报纸转载）与材料A源自同一内容，不构成独立见证，不能与A互证。
- **P11 材料间矛盾的初步处理**：材料A（所有工人都改善）与材料B（工作时间更长，可能隐含负面变化）在结论上存在差异，需列出差异并考察各自背景，不能直接判定谁真谁假。
- **P12 现有证据的有限性判断**：在没有其他工人记录、物价、工资账簿或工时统计的情况下，现有材料A/B/C仅支持有限强度的结论，不能确定全体工人的整体生活状况。

### 本轮能力与标准

#### 史料辨析与来源属性评估

阅读虚构材料A（经理年报）与B（工人日记）。1) 分别列出每份材料中作者直接陈述的内容与作者添加的推断；2) 解释A的受众与目的如何影响其主张的可信度，并说明为何不能因此将其全盘作废；3) 分析B中的可观察记录与推断边界。

- P1 → Q1：明确区分A中产量与生活改善的陈述为推断，而非可证实事实
- P2 → Q2：说明A的受众（投资人）和目的（年报展示）使其可能选择性呈现，但主张需按具体点评价而非全盘作废
- P3 → Q2：论证A有立场但仍有部分信息价值，B私人记录有局限但非毫无价值，避免'一手=客观'或'有立场=无价值'的二元判断
- P8 → Q2：指出A的受众、作者身份和目的使其'所有工人改善'主张受特定语境限制，不能视为客观全面观察
- P9 → Q4：识别B中'收入增加'和'工时更长'为个人可观察记录，推断全体工人状况则超出材料支持范围

错因：将作者的主观陈述（'生活改善'）直接当作可证实的事实，不区分观察与推断

预测：回答中A的观察项与推断项混同，或推断被表述为作者写出的客观描述

补救：重新标注A文本，将'产量增加'列为可观察，将'所以生活改善'标为推断并说明依据缺失；核对：A中是否有'所有工人生活改善'的原始数据支撑？若否，归为推断

错因：因材料A是经理年报（有立场）就断定其毫无价值，完全拒绝使用

预测：回答中未说明A的受众目的如何具体影响其主张，也未讨论为何不能仅凭立场作废

补救：列出A中即使有立场仍可提取的信息（如产量数据），说明哪些主张受目的影响而需谨慎；核对：若A是中立第三方的年报，其主张可信度是否变化？差异在哪里？

#### 证据互证与矛盾处理

1) 判断材料A与C是否构成两份独立证据，说明理由。2) 当A（所有工人改善）与B（工时更长）出现张力时，列出具体差异，说明为何不能按数量或预设立场定真假，并提出下一步查证方案。3) 在无其他工人记录、物价或工时统计的情况下，说明现有证据能支持多强的结论，区分'已能确定'、'不能确定'和'待查证'。

- P4 → Q3：检查A与C的来源独立性及记载对象时段可比性
- P5 → Q3：明确指出C是A的转载，不构成独立见证，不增加独立来源
- P10 → Q3：判定A与C同源，C不能作为独立证据支持A的主张
- P6 → Q5：列出A与B的具体差异（全面改善vs工时增加），说明不能按多数或预设立场判真假，提出查新证据
- P11 → Q5：处理A（所有工人改善）与B（某工人工时更长）的矛盾，考察背景而非定论
- P7 → Q6：区分能确定（经理认为改善、某工人记录）、不能确定（全体工人生活水平）及待查证项，结论强度与证据有限性匹配
- P12 → Q4：说明现有A/B/C仅支持有限强度结论，不能确定全体工人整体状况

错因：认为A和C因为出现在不同文本载体（年报 vs 报纸）就是两份独立证据，可互证

预测：回答中A和C被视为独立证据，或C被当作对A的独立佐证
