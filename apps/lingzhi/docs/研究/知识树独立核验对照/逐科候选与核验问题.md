#### P1 赋值不复制对象

在Python中，执行赋值语句 `b = a` 后，变量名 `b` 指向与 `a` 相同的对象，即两个名字关联同一个列表实例，并不创建新的列表数据副本。

**检查：** 执行以下代码：
a = [1]
b = a
print(a is b)
输出结果是什么？

**模型答案：** True。因为b=a使b指向了a指向的同一列表对象。

**错规则：** 赋值操作（=）会自动创建一个新的列表副本，b将拥有与a内容相同但独立的列表。

**预测：** False

**补救：** 画出对象指向图：画一个列表盒子，在a和b下方画箭头均指向该盒子，强调箭头指向同一实体。

**不可扩大：** 不能推断`a.append`会改变b，也不能推断`b=[9]`会改变a，这些属于后续操作规则。

**迁移：** 执行以下代码：
d = {'k': 1}
e = d
print(d is e)
输出结果是什么？（注意：虽然材料只讨论列表，但请基于“赋值指向同一对象”这一元知识推导，且假设Python字典行为与列表赋值逻辑一致）

**模型答案：** True。赋值操作使e指向d所指向的同一字典对象。

#### P2 别名共享原地修改

当两个名字指向同一个列表对象时，通过其中任意一个名字对该列表执行原地修改（如append、元素赋值），另一个名字在后续访问时会观察到相同的变化。

**检查：** 执行以下代码：
a = [1]
b = a
b.append(2)
print(a)
输出结果是什么？

**模型答案：** [1, 2]。因为b和a指向同一列表，b的append操作改变了该列表对象，a也随之改变。

**错规则：** 每个变量名拥有独立的内存空间，通过b修改数据不会影响a的数据内容。

**预测：** [1]

**补救：** 在指向图上，将列表盒子内的内容从[1]变为[1,2]，强调盒子内容变了，所有指向盒子的名字看到的都变了。

**不可扩大：** 不能推断重新绑定（b=[2]）也会让a看到变化，因为那是改变指向而非改变对象。

**迁移：** 执行以下代码：
x = [10]
y = x
x[0] = 20
print(y)
输出结果是什么？

**模型答案：** [20]。索引赋值是原地修改，y和x共享同一列表，y看到变化。

#### P3 重新绑定不改变原对象指向

当两个名字指向同一个列表时，对其中一个名字执行重新绑定操作（如 `b = [9]`），仅改变该名字指向的对象，不会改变另一个名字指向的对象，也不会修改原列表的内容。

**检查：** 执行以下代码：
a = [1]
b = a
b = [9]
print(a)
输出结果是什么？

**模型答案：** [1]。b被重新绑定到新的列表[9]，a仍然指向原来的列表[1]。

**错规则：** 修改变量的值（包括赋值新对象）会同步更新所有指向旧对象的引用，或者认为a会指向b的新值。

**预测：** [9]

**补救：** 在指向图上，画一个新的列表盒子[9]，将b的箭头拉向新盒子，保持a的箭头仍指向旧盒子[1]。

**不可扩大：** 不能推断a的内容变了，也不能推断b和a仍指向同一对象。

**迁移：** 执行以下代码：
m = [100]
n = m
m = [200]
print(n)
输出结果是什么？

**模型答案：** [100]。m被重新绑定，n仍指向原对象。

#### P4 浅拷贝创建独立外层

调用 `a.copy()` 会创建一个新的外层列表对象 `b`，`a` 和 `b` 在外层结构上是独立的；对 `b` 进行外层结构的原地修改（如 `b.append(...)`）不会改变 `a` 的结构。

**检查：** 执行以下代码：
a = [[1]]
b = a.copy()
b.append([2])
print(a)
输出结果是什么？

**模型答案：** [[1]]。b是新的外层列表，对b的append不影响a的外层结构。

**错规则：** 浅拷贝完全等价于赋值，或者认为浅拷贝创建的对象与原对象在任何操作下都完全无关（忽略内层共享）。此处错规则聚焦于外层：认为append会共享外层。

**预测：** [[1], [2]]

**补救：** 画两个独立的外层列表盒子A和B，A和B中第一个槽位都指向同一个内层列表对象，但A和B本身是两个不同的盒子。

**不可扩大：** 不能推断内层元素独立，也不能推断b[0]=[9]不影响a。

**迁移：** 执行以下代码：
c = [1, 2]
d = c.copy()
d.append(3)
print(c)
输出结果是什么？

**模型答案：** [1, 2]。d是新的外层列表，c保持不变。

#### P5 浅拷贝共享内层引用

对于包含嵌套列表的列表，使用 `.copy()` 进行浅拷贝时，新列表 `b` 中对应索引位置的元素仍然引用原列表 `a` 中对应索引位置的内层列表对象，即内层列表未被复制。

**检查：** 执行以下代码：
a = [[1]]
b = a.copy()
print(b[0] is a[0])
输出结果是什么？

**模型答案：** True。浅拷贝只复制外层引用，b[0]和a[0]指向同一个内层列表对象。

**错规则：** 浅拷贝会深度复制所有层级，或者认为copy()后所有元素都是新对象。

**预测：** False

**补救：** 在指向图上，明确标出A和B两个外层盒子，它们的第一个格子里的箭头都指向同一个内层盒子，强调内层盒子只有一个。

**不可扩大：** 不能推断对b[0].append会影响a，虽然这是共享的结果，但此点仅指引用关系。

**迁移：** 执行以下代码：
x = [{'v': 1}]
y = x.copy()
print(y[0] is x[0])
输出结果是什么？（假设字典行为类似，考察浅拷贝引用原理）

**模型答案：** True。浅拷贝不复制内层对象（字典），y[0]和x[0]指向同一对象。

#### P6 共享内层修改双向可见

在浅拷贝的两个列表中，由于内层列表对象是共享的，通过任意一个外层列表（a或b）访问该共享内层列表并执行原地修改，另一个外层列表在访问该位置时会观察到相同的修改。

**检查：** 执行以下代码：

b = a.copy()
b[0].append(2)

**模型答案：** [[1, 2]]。b[0]和a[0]指向同一内层列表，b[0]的append修改了该内层列表，a因此看到变化。

**错规则：** 浅拷贝完全隔离了两个列表，修改b不会影响a（无论是外层还是内层）。

**预测：** [[1]]

**补救：** 在指向图上，找到共享的内层盒子，将其内容从[1]变为[1,2]，强调两个外层盒子的箭头都指向这个变了的盒子。

**不可扩大：** 不能推断外层append也会这样，因为外层不是共享的（见P4）。

**迁移：** 执行以下代码：
p = [[10, 20]]
q = p.copy()

print(q)
输出结果是什么？

**模型答案：** [[20]]。p[0]和q[0]共享同一列表，pop修改了共享对象，q看到变化。

#### P7 内层引用重绑定不改变原指向

在浅拷贝列表中，对 `b` 的某个索引位置（如 `b[0]`）重新赋值为一个新的列表对象，仅改变 `b` 中该索引位置的引用，不会改变 `a` 中对应索引位置的引用，也不会修改原内层列表对象。

**检查：** 执行以下代码：

**模型答案：** [[1]]。b[0]被重新绑定到新的列表[9]，a[0]仍指向原来的内层列表[1]。

**错规则：** 修改列表的某个元素（索引赋值）等同于修改该元素所指向的对象内容，或者认为a[0]会随b[0]的值改变而改变。

**预测：** [[9]]

**补救：** 在指向图上，画一个新的小盒子[9]，将b的第一个格子的箭头拉向新盒子，保持a的第一个格子箭头仍指向旧盒子[1]。

**不可扩大：** 不能推断a的内容变了，也不能推断b[0]和a[0]仍指向同一对象。

**迁移：** 执行以下代码：
list_a = [[100]]
list_b = list_a.copy()
list_b[0] = [200]
print(list_a)
输出结果是什么？

**模型答案：** [[100]]。list_b[0]被重绑定，list_a[0]不受影响。

#### P1 函数在定义域内点a处连续的定义

函数f在定义域内点a处连续，当且仅当f(a)有定义，且x趋于a的双侧极限存在、有限并等于f(a)。

**检查：** 设f(x)=x (x≠0)，f(0)=1。判断f(x)在点0处是否连续。

**模型答案：** 不连续。当x趋于0时，双侧极限存在且等于0，但f(0)=1。由于双侧极限(0)不等于f(0)(1)，所以不连续。

**错规则：** 只要f(x)在a附近的x趋于a时左右极限存在，函数在a就连续，不用看f(a)。

**预测：** 判断f(x)在点0处连续。

**补救：** 在笔记中划出连续性定义的三个并列要素：f(a)存在、极限存在有限、极限等于f(a)。在判定流程中加入核对点值的步骤。

**不可扩大：** 不能将'极限存在'泛化为'连续性'，极限存在只是连续性的必要条件之一。

**迁移：** 设f(x)={x+1 (x<1); 3 (x=1); 5-x (x>1)}，判断f在1处是否连续。

**模型答案：** 不连续。左极限为 lim(x->1-) (x+1) = 2，右极限为 lim(x->1+) (5-x) = 4。左右极限不相等，故双侧极限不存在。不满足连续定义中'双侧极限存在'的条件，故不连续。

#### P2 函数在定义域内点a处可导的定义

函数f在定义域内点a处可导，意味着差商[f(a+h)-f(a)]/h在h趋于0时存在有限的双侧极限。

**检查：** 设f(x)=x²，写出f在点0处的差商并求f'(0)。

**模型答案：** 差商为[f(0+h)-f(0)]/h = h²/h = h (h≠0)。当h趋于0时，h的极限存在且有限，等于0。因此f在0处可导，f'(0)=0。

**错规则：** 只要函数f(a)有定义，差商的分母不为0，差商的极限就一定存在，函数在a就可导。

**预测：** 直接得出可导的结论，未进行极限计算。

**补救：** 在判定流程中强制包含'计算双侧极限'的步骤，并检查极限是否为一个有限实数。

**不可扩大：** 不能将'差商代数化简'等同于'极限存在'，必须验证极限的数学性质。

**迁移：** 设f(x)=√x，判断f在点1处是否可导，并说明理由。

**模型答案：** 可导。差商为(√(1+h)-1)/h，乘以共轭式得h/((1+h)+1)，当h趋于0时极限为1/2，存在且有限。

#### P3 左右导数不同时不可导的判定

若函数在定义域内点a处的左差商极限与右差商极限不相等，则该点处的双侧导数不存在，即函数在该点不可导。

**检查：** 设f(x)=|x|，计算其在0点的双侧差商极限。

**模型答案：** 左侧h<0时，[|0+h|-|0|]/h = (-h)/h = -1；右侧h>0时，[|0+h|-|0|]/h = h/h = 1。左极限-1，右极限1，左右极限不等，双侧极限不存在，故不可导。

**错规则：** 如果左侧极限和右侧极限都是有限的，就认为双侧极限存在，从而可导。

**预测：** 判定f(x)=|x|在0可导，导数为0或平均值0。

**补救：** 在笔记中强调：双侧极限存在的前提是左右极限必须相等。将判定流程修改为：先算左极限，再算右极限，最后比较是否相等。

**不可扩大：** 不能将'左右极限都有极限'泛化为'双侧极限存在'，必须验证相等性。

**迁移：** 设f(x)={x² (x≤1); 2x+1 (x>1)}，判断f在1处是否可导。

**模型答案：** 左极限：h趋于0⁻时(f(1+h)-f(1))/h = ((1+h)²-1)/h = (1+2h+h²-1)/h = 2+h，极限为2。右极限：h趋于0⁺时(f(1+h)-f(1))/h = (2(1+h)+1-1)/h = (2+2h)/h = 2/h + 2。当h->0时，2/h趋向无穷，极限不存在（或视作无穷大，非有限实数）。因此左右极限不同（一个为2，一个不存在/无穷），双侧极限不存在，故不可导。

#### P4 点a可导则必连续的逻辑关系

在定义域内点a处，若函数可导，则必然在该点连续。

**检查：** 已知某实函数f在内点a处存在有限的双侧导数，能否断定f在a处连续？

**错规则：** 可导和连续是两个独立的性质，知道可导不能推断出任何关于连续性的结论。

**预测：** 不能断定，需要额外验证连续性。

**补救：** 建立逻辑映射图，标注'可导'指向'连续'的箭头，标明这是充分条件。在推理练习中强制使用该映射。

**不可扩大：** 不能将'可导'泛化为'连续'的唯一充分条件（虽然材料只提供了这一条），也不能反推连续必可导。

**迁移：** 若证明f在a处可导，为了检查f在a处是否连续，还需要额外计算什么吗？

**模型答案：** 不需要。根据'可导必连续'的定理，可导性已经蕴含了连续性。

#### P5 点a连续不一定可导的逻辑关系

函数在点a处连续，不能作为其在该点可导的充分条件；存在连续但不可导的反例。

**模型答案：** 不能。连续不能保证可导。

**不可扩大：** 不能将'连续'泛化为'可导'的等价条件，它只是必要非充分条件（由可导必连续推出）。

**模型答案：** 说法结论正确，但逻辑不严。仅凭连续不能保证可导（如|x|），对于y=x，必须通过求差商极限证明其可导。

#### P6 不连续则不可导的逆否命题应用

如果函数在定义域内点a处不连续，则必然不可导；这是'点处可导必连续'的逆否命题。

**检查：** 设g(x)=x-2 (x≠2)，g(2)=5。判断g在2处是否连续及是否可导。

**模型答案：** x趋于2时极限为0，点值g(2)=5。极限(0)不等于点值(5)，故不连续。根据'不连续则不可导'，g在2处不可导。

**错规则：** 不连续只意味着连续性的否定，与导数是否存在无关，导数可能依然存在。

**预测：** 判定不连续，但可能可导。

**补救：** 画出逻辑推理链：A(可导)→B(连续)。逆否：¬B(不连续)→¬A(不可导)。在遇到不连续时，直接引用此链条得出结论。

**不可扩大：** 不能将'不连续'泛化为'导数无穷大'，只是说双侧有限导数不存在。

**迁移：** 若已知函数h在定义域内点b处x趋于b的极限不存在（不连续），能直接断言h'(b)不存在吗？

**模型答案：** 能。极限不存在即不连续，由逆否命题'不连续则不可导'，必然推导出h'(b)不存在。

#### P7 不可导不能反推不连续的逻辑边界

函数在点a处不可导，不能反推其在该点一定不连续，存在不可导但连续的反例。

**检查：** 已知f在内点a不可导，能否据此断定f在a不连续？

**模型答案：** 不能。不可导不能反推不连续，存在连续但不可导的反例（如|x|在0）。

**错规则：** 可导与连续是等价的：只要不可导，就一定是不连续的。

**预测：** 能断定，不可导即不连续。

**补救：** 在'不可导'下方画出问号，提醒其状态不确定。在练习中，专门针对'不可导'的条件寻找连续反例进行自我反驳。

**不可扩大：** 不能将'不可导'泛化为'图像必有断点'，断点（不连续）只是不可导的充分条件之一。

**迁移：** 判断命题'函数f在a点有断点（不连续）是f在a点不可导的必要条件'的真假，并说明理由。

**模型答案：** 假。断点（不连续）导致不可导（充分），但不可导不一定有断点（如|x|在0点）。因此不连续不是不可导的必要条件。

### 最终候选逐点卡片（未通过采用）

#### P1 相互作用力的等大反向性

在两物体的一次相互作用中，A对B的力与B对A的力大小相等、方向相反。

**检查：** 甲乙相互推，甲质量为乙的两倍，谁对谁的相互作用力更大？

**模型答案：** 二者大小相等。

**错规则：** 施力者质量越大，其施加给受力者的相互作用力越大。

**预测：** 甲对乙的力更大。

**补救：** 重读材料中'大小相等'的表述，核对受力图中甲乙间接触力箭头的长度，确认两者一致。

**不可扩大：** 不能由'等大'且'甲质量大'反推'甲受到的合力一定更大'，因还需考虑其他外力。

**迁移：** 一辆卡车与一辆轿车在冰面上发生正碰，在碰撞瞬间，卡车对轿车的力与轿车对卡车的力大小关系如何？

**模型答案：** 两者大小相等。

#### P2 相互作用力的作用对象区分

A对B的力只作用于物体B，B对A的力只作用于物体A，两者受力对象互不相同。

**检查：** 甲对乙和乙对甲这两个力分别画在哪个物体的受力图？

**模型答案：** 前者画在乙上，后者画在甲上。

**错规则：** 作用力和反作用力虽然由两物体相互作用产生，但都集中作用在受力物体（被推者）上以便计算合力。

**预测：** 两个力都画在乙（受力者）上。

**补救：** 在受力图草稿中，用红笔圈出'甲对乙'，将箭头画在乙上；用蓝笔圈出'乙对甲'，将箭头画在甲上，检查箭头起点是否在受力物表面。

**不可扩大：** 不能据此推断画在物体上的所有力都是该物体施加给外部的力，必须严格依据箭头起点所在物面判定。

**迁移：** 宇航员在空间站漂浮时用手推舱壁，手对舱壁的力和舱壁对手的力，分别作用在哪个物体上？

**模型答案：** 手对舱壁的力作用在舱壁上，舱壁对手的力作用在宇航员（手）上。

#### P3 作用反作用定律与运动状态/质量无关

相互作用力等大反向的结论成立，不要求两物体质量相等，也不要求物体处于静止状态；静止状态本身不能否定反作用力的存在。

**检查：** 手推墙但墙未移动，能否据此说墙未对手施力？

**模型答案：** 不能；静止不否定反作用力。

**错规则：** 力是改变物体运动状态的原因；物体保持静止说明其受到的合力（或反作用力）为零。

**预测：** 能；墙未移动说明墙没有对手施力。

**补救：** 列出'静止'、'匀速运动'、'加速运动'三种状态，逐一核对'手对墙'和'墙对手'的力大小是否依然相等。

**不可扩大：** 不能将'墙未移动'扩展为'墙受到的所有力合力为零'，因未分析墙受地面的摩擦力等其他外力。

**迁移：** 一个质量为10kg的木块在光滑桌面上以5m/s做匀速直线运动，此时它受到桌面的滑动摩擦力（非零）与它的运动状态之间是否存在因果联系？若此时突然用50N水平力推它（接触瞬间），它与桌面间的相互作用力大小关系是否受其'匀速'状态影响？

**模型答案：** 匀速运动说明其受到的水平力平衡，但接触瞬间的相互作用力大小相等、方向相反，与物体处于'匀速'状态无关。

#### P4 由等大反向不能推断加速度相等

两物体间作用力与反作用力大小相等，不能直接推断这两个物体的加速度大小相等。

**检查：** 甲（质量10kg）推乙（质量5kg），在水平光滑冰面上，甲对乙的作用力为20N。若仅考虑这对相互作用力，甲与乙的加速度大小是否相等？若不等，哪个更大？

**模型答案：** 不相等。乙的加速度更大（乙a=4m/s²，甲a=2m/s²）。

**错规则：** 作用力与反作用力大小相等，根据牛顿第二定律，两物体的加速度必然大小相等。

**预测：** 相等。

**补救：** 用公式 a = F/m 代入 m甲=10kg 和 m乙=5kg 的数值，计算并对比 a甲 和 a乙 的具体值，记录差异。

**不可扩大：** 不能由此推断'任何质量不同的两物体在相互作用时加速度必不同'，因为还需考虑是否有其他外力或初速度约束。

**迁移：** 一辆货车和一辆摩托车发生碰撞，碰撞过程中车与车之间的相互作用力大小相等。若货车质量远大于摩托车，碰撞后谁的速度变化率（即加速度）更大？

**模型答案：** 摩托车的加速度更大。

#### P5 单物体受力图的列力规则

绘制单个物体的受力图时，只画出施加在该物体上的力，不画该物体施加给其他物体的力。

**检查：** 脚蹬地面时，地面对脚的力与脚对地面的力如何配对？只画人的受力图应保留哪一个？

**模型答案：** 人的受力图保留地面对脚/人的力；脚对地面的力不画在人的受力图上。

**错规则：** 受力图应画出该物体参与的所有力学作用，包括它对外界施加的反作用力，以便于后续计算动量。

**预测：** 应同时保留地面对脚的力和脚对地面的力。

**补救：** 用'作用在谁身上？'的过滤器过一遍草稿上的所有箭头，擦除所有起点不在人脚底部（即不作用在人上）的箭头。

**不可扩大：** 不能将此规则泛化为'分析系统内力时不能画出内力'，因若选A+B系统，内力可以画（视目的而定），此处仅针对单物体图。

**迁移：** 分析悬挂的吊灯（灯A）受力时，天花板对灯A的拉力与灯A对天花板顶钩的拉力，哪一个应该画在灯A的受力图上？

**模型答案：** 天花板对灯A的拉力应画在灯A的受力图上。

#### P6 作用反作用力不能作为同一物体上的平衡力

一对作用力与反作用力分别作用在两个不同物体上，不能在分析其中一个物体的平衡或合力时，将二者作为同一物体上的平衡力相消。

**检查：** 桌上的书所受重力与桌面对书的支持力，是否为作用反作用力对？

**模型答案：** 不是；二者都作用在书上。

**错规则：** 作用力与反作用力大小相等方向相反，因此无论作用在哪个物体上，都可以像平衡力一样抵消掉。

**预测：** 是作用反作用力对，且能在受力分析中抵消。

**补救：** 在草稿纸上画出书的重力与支持力，分别用括号标出受力者（书、书），对比作用反作用对（支持力、压力）的受力者（书、桌），确认平衡力必须括号内文字相同。

**不可扩大：** 不能据此推断'任何等大反向力都必然是作用反作用对'，还需检查施力物体是否为同一对物体。

**迁移：** 电梯加速上升时，乘客受到的重力与电梯底板对乘客的支持力大小不等。这两个力是平衡力吗？乘客对底板的压力与底板对乘客的支持力能抵消吗？

**模型答案：** 重力与支持力不是平衡力（因大小不等且运动状态非平衡）；乘客对底板的压力与支持力是作用反作用力，不能抵消（因受力对象不同）。

#### P7 内力在系统内的抵消性质

当A与B被选为一个整体系统时，A与B之间的相互作用力属于内力；内力在配对求和时互相抵消，其矢量和为零。

**检查：** 把两相互推的车选为整体，内部推力相消是否证明整体外力合力为零？

**模型答案：** 不能；内部推力相消是内力抵消，仍需单独检查外力（如地面摩擦、空气阻力）是否为零。

**错规则：** 内力在系统内互相抵消，说明该系统内部没有任何净力，因此系统整体不受任何力，外力合力也必然为零。

**预测：** 能证明外力合力为零。

**补救：** 列出整体的受力清单：1. 内力A->B（抵消）；2. 内力B->A（抵消）；3. 外力：地面摩擦、空气阻力（未抵消）。强调内力抵消只是划去清单第1、2项，不划去第3项。

**不可扩大：** 不能由此推断'内力抵消的系统一定处于静止状态'，因系统可能受恒定外力而匀加速运动。

**迁移：** 两人站在冰面上互相推，把两人作为系统，他们之间的推力会改变系统的总动量吗？系统总动量变化的原因是什么？

**模型答案：** 不会因内力改变总动量；若系统总动量改变，只能是因为存在外力（如地面摩擦）。

### 最终候选逐点卡片（未通过采用）

#### P1 陈述文本与已证事实的区分

区分史料中作者声称发生的文本记录，与分析者确认已发生的客观事实；仅因材料有文字记录不能将该记录直接作为已证实的事实，需说明验证依据与限制。

**检查：** 材料A写道：“产量增加，所以所有工人的生活都改善了”。A中哪些是作者写出的说法，哪些还不能直接当作经证实的事实？

**模型答案：** “产量增加”和“所有工人的生活都改善”均是作者写出的说法；不能据此证实“所有工人生活改善”这一事实。

**错规则：** 史料中记录的具体细节，只要出现在文本中，就自动成为该事件已发生的已证实事实。

**预测：** “产量增加”和“所有工人的生活都改善”都是已证实的事实，因为它们在A中被明确写出。

**补救：** 阅读材料A，将“产量增加”和“所有工人的生活都改善”圈出，并在旁边标注“作者声称”，然后写下：在没有工资账簿或工时统计的外部核验下，不能将其标为已证实的事实。

**不可扩大：** 不能因为B（日记）中“我家收入增加”也是文本记录，就将其直接等同于“该工人收入客观上确实增加”的已证实事件；同样，不能因为A的陈述未被证实，就断定A所述内容一定为假。

**迁移：** 虚构材料D：一位商人的公开演讲称“铁路开通让全城都富裕”。D中哪些是作者写出的说法，哪些还不能直接当作经证实的事实？

**模型答案：** “铁路开通让全城都富裕”是作者写出的说法；不能据此证实“全城都富裕”这一事实。

#### P2 全称主张的逻辑限制

从单一或部分样本的文本记录进行推断时，推断的强度受限于样本范围；将个别样本直接扩展为“所有”个体的全称结论，必须说明涵盖所有个体的证据边界，否则属于越界推断。

**检查：** B是同年度一名工人的私人日记，写道“我家收入增加，但工作时间更长了”。B是否足以证明“所有工人生活改善”或“所有工人生活恶化”？请说明B的结论强度受限于什么。

**模型答案：** 均不足以证明。B仅是一个人的记录（样本限制），应限定对象为“该工人”，且需区分“收入”与“工时”这两个独立的生活指标，不能直接推断“所有工人”的情况。

**错规则：** 一份来自单一具体个体的记录，可以直接作为验证或否定“所有”该群体成员状况的充分证据。

**预测：** B足以证明“所有工人生活恶化”，因为它记录了收入增加和工时变长，这与A相反，且B是个人真实记录，代表性强。

**补救：** 阅读材料B，在“我家收入增加”下划线并圈出“我家”，然后在旁边标注：这是“个体样本”，不能推断“所有工人”。接着阅读材料A，圈出“所有工人”，标注：这是“全称结论”，两者逻辑范围不匹配。

**不可扩大：** 不能因为B中“收入增加”和“工时变长”同时出现，就推断出B的主人一定认为自己的“生活变差”；材料B并未直接陈述“生活变差”这一主观判断。

**迁移：** 虚构材料E：一户居民信中说“我家房租上涨且通勤更快”。E是否足以证明“全城都富裕”或“全城都变穷”？请说明E的结论强度受限于什么。

**模型答案：** 均不足以证明。E仅是一户居民（个体样本）的记录，且仅涉及“房租”和“通勤”指标，不能推断“全城”（群体）的整体经济状况。

#### P3 作者立场与材料效度的关系

史料的作者、受众和目的决定了其特定主张的语境与限制；评估材料时，需说明其语境如何影响其可靠性，但不能仅因存在特定目的或立场，就直接判定该材料的全部记载均虚假或毫无价值。

**检查：** 材料A是某工厂经理致投资人的年度报告，写道“产量增加，所以所有工人的生活都改善了”。解释A的受众（投资人）与目的怎样影响A中关于“所有工人的生活都改善了”这一主张的评估，并说明能否因此把A中的这句话判定为绝对虚假。

**模型答案：** 受众为投资人的目的可能导致经理选择性呈现对资本有利的信息（如夸大或概括）；因此“所有工人生活改善”这一全称结论必须接受更严格的证据检验。不能仅凭“受众是投资人”就直接判定这句话绝对虚假，而是说明其缺乏独立证据支持且需被检验。

**错规则：** 材料作者的特定受众或目的，可以直接作为证据，证明该材料中与该受众相关的所有具体陈述均不成立。

**预测：** 因为A的受众是投资人，经理为了投资必然有夸大动机，所以“所有工人的生活都改善了”这句话可以被直接判定为绝对虚假，无需进一步检验。

**补救：** 阅读材料A的受众设定，写下：目的可能使其夸大。然后写下：但我不能因此直接说它100%是假的，我需要看是否有其他证据（如B）来检验这句话的准确性。

**不可扩大：** 不能因为A的受众是投资人，就推断A中关于“产量增加”的陈述一定比关于“工人生活改善”的陈述更不可信；“产量增加”和“生活改善”都应作为A的主张，但检验它们的外部证据标准可能不同。

**迁移：** 虚构材料D：一位商人的公开演讲（面向当地居民）称“铁路开通让全城都富裕”。D的受众（居民）与目的怎样影响对“全城都富裕”这一主张的评估？能否直接判定D为假？

**模型答案：** 面向居民的演讲可能为了吸引支持或粉饰形象而夸大（或缩小）问题，因此“全城都富裕”的全称结论需受语境限制，证据要求更高。不能仅凭受众是居民就直接判定D为假，而应要求提供更广泛的独立证据。

#### P4 独立见证的判定标准

在史料互证中，判定来源是否独立时，需考察其是否源自同一个最终源头；对同一报道的转载（Reprint）不构成两份独立见证，不能为原报道增加互证的证据强度。

**检查：** C是报纸对A的原文转载。A和C是否是两份独立证据？C能为A提供额外的互证支持吗？

**模型答案：** 不是两份独立证据。C是A的转载，不构成独立来源，不能为A提供额外的互证支持，两者在证据强度上算作同一份来源。

**错规则：** 只要两份材料在物理上是独立的文本（如两份不同的报纸或报告），它们就构成了两份独立的证据见证。

**预测：** A和C是两份独立证据，因为一个是年度报告，一个是报纸，它们分别由工厂和报社发行，可以相互印证，从而增强了“产量增加”的真实性。

**补救：** 阅读材料A和C的设定，画出C的文字内容并标注“来源于A”，然后在旁边写下：C不能为A增加独立证据强度，它只能证明A的内容被报纸复制了。

**不可扩大：** 不能因为C是A的转载，就认为C的内容一定比A更不可信或更可信；C的可信度取决于A的可信度。C的价值在于证明A的内容在特定时间被特定媒体传播，而不是证明A内容的客观真实。

**迁移：** 虚构材料F：如果F只是一份网络博客对D（商人的公开演讲）的原文转载，D和F是否能算作两份独立的证据？F能为D提供额外的互证支持吗？

**模型答案：** D和F不能算作两份独立证据。F是对D的转载，不满足独立性，不能为D增加互证强度，两者在来源上视为同一份证据。

#### P5 矛盾证据的解析路径

当材料出现矛盾或张力时，应通过列出差异、比较记载对象与时段、寻找新证据来解析，而不能通过比较材料的数量进行“投票”，也不能通过预设某类材料的优先地位（如“私人”优于“官方”）来直接定真伪。

**检查：** A写道“产量增加，所以所有工人的生活都改善了”，B写道“我家收入增加，但工作时间更长了”。当A（官方报告）和B（私人日记）出现张力时，应如何处理？能否直接判定A假或B假？

**模型答案：** 应列出差异（A强调群体生活改善，B强调个体收入与工时），考察背景，并寻找新证据（如物价、更多工人记录）。不能直接判定A假或B假，也不能按来源数量（如A+C）或预设立场（如私人日记绝对可信）来定真伪。

**错规则：** 当材料冲突时，可以通过预设立场（如“私人记录比官方文件更可信”）或比较支持该立场的材料数量，直接裁定其中一方为绝对真理。

**预测：** 可以直接判定A假、B真。因为B是私人日记，而A是官方报告，官方报告通常为了利益而说谎，且B是真实记录；同时A的立场有C支持，但私人日记在反映个人生活方面具有不可辩驳的优先权。

**补救：** 阅读A和B的差异，在表格中列出A的说法（所有工人改善）和B的说法（个体收入与工时变化），然后写下：我需要找工资账簿和更多工人日记来检验，而不是直接说A或B一定对。

**不可扩大：** 不能因为B是私人日记且是“一手材料”，就认为B记录的“收入增加”一定是客观发生的事件；B的主张同样需要与A一样接受证据检验。

**迁移：** 虚构材料D称“全城都富裕”，E称“我家房租上涨且通勤更快”。当D（公开演讲）和E（居民信）出现张力时，应如何处理？能否直接判定D假或E假？

**模型答案：** 应列出差异（全城整体富裕 vs 个体房租与通勤），比较对象与时段，寻找新证据（如全城物价统计、更多居民信）。不能直接判定D假或E假，也不能按来源数量或预设立场（如居民信绝对比商人演讲真实）来定真伪。

#### P6 暂定解释与验证方案的设计

在证据不足时，应提出能回应现有材料（包括个例与全称）的暂定解释，明确证据的限度，并设计能具体检验该解释的查证方案；查证方案可以是多种的，且必须指向能填补证据空白的独立信息。

**检查：** 现有A（报告）和B（日记）存在张力，且没有物价、工资账簿或工时统计。提出一个关于“工人生活状况”的暂定解释，说明其证据限度，并设计一个下一步查证计划。

**模型答案：** （示例）暂定解释：工人可能经历了“收入增长但被工时延长/物价上涨抵消”的状况。限度：目前仅有个体记录，无法代表全体。查证计划：查阅该年度的工资账簿和物价指数，并访谈其他工人，以检验“生活改善”是否被高估。

**错规则：** 在证据不足时，为了得出一个明确答案，应当选择其中最具体的单一材料（如日记）的记录作为解释的绝对核心，并以此排斥其他可能的解释。

**预测：** 暂定解释：工人生活肯定变差了，因为B的日记说工时更长了。证据限度：B非常具体，所以足以说明一切。查证计划：不需要更多证据，B已经解释了A的错误。

**补救：** 针对A和B，写下：目前可以说该工人收入增加且工时变长；不能确定所有工人的生活状况。下一步需要查证：工资账簿和物价记录。

**不可扩大：** 不能因为B中提到“收入增加”，就在暂定解释中直接断言“工人的实际购买力一定增加了”，因为缺乏物价数据，无法推断实际生活水平。

**迁移：** 虚构材料D称“全城都富裕”，E称“我家房租上涨且通勤更快”，缺乏全城物价和通勤统计。提出一个关于“居民生活状况”的暂定解释，说明证据限度，并设计查证计划。

**模型答案：** （示例）暂定解释：居民可能经历了“通勤效率提升但住房成本/经济压力增加”的状况。限度：仅有个体记录，无法代表全城。查证计划：查阅全城租金指数、通勤时间统计，并访谈不同区域的居民，以检验“全城富裕”的说法。
