## 改动及适用范围

- 已采用原子知识基线默认每点规划三题，分别为直接判断、对照辨析、迁移应用；课程内部 `assessment_variant_count` 可限定为 1—3 的整数。未采用原子基线的旧课程继续原有规划。按知识点生成会选择该点全部题位，按题目修复只处理指定题位。
- 首题保留原 `generation_key`，其余题位按首题身份和变式角色派生。知识修订变化不改变题位身份，但题目继续冻结原知识修订；旧作答不会被重绑到新知识。
- 测量设计提示词按规则语义选择变式结构，不按这九个知识 ID 打补丁。对照/迁移计划不再被首题的单实例构造器压回同一模板。现有独立求解、语言、观测、解析及证据准入仍全部执行。
- 支持的单选测量计划在独立求解前由程序安排正确选项位置，同一生成器运行中按选项数量分别平衡，随机处理并列位置；同题位的修复保留已分配位置。题目保存后不重新洗牌，私有回执记录原顺序及排列关系，不进入公开题面。
- 增加同一点的实质变式检查：C 代码去掉注释，规范变量名和数值后，若其他题位仍是同一结构，则阻止采用并要求重设计。保留运算符、控制结构、变量引用关系和整数/浮点区别。它是保守词法检查，不是 C 解析器，也不能证明所有语义近似题都被发现；原通用相似度警告仍保留。
- 作答 API 从服务端题目冻结 `assessment_evidence_key`，不接受客户端自造证据身份。画像以题位身份合并新修订和重复作答；不同变式分别累计证据。同题位后续有效答错替换先前结果，答案揭示后的反馈不擦除原有效检查。旧记录只有题目修订时，若同修订已有服务端冻结的新身份，则在重算时对齐，防止升级后首次重答把新旧记录算作两份；不凭空推断旧记录之间的跨修订等价关系。
- 题量进入任务续作来源哈希，避免改变题量后误复用旧检查点。最终引擎提交 `00112efa`；策略版本为 `assessment_generation_policy_v10`，提示模板 v25，画像规则 `knowledge_mastery_v2`。题目合同和知识身份延续已有版本，不迁移历史学习事实。
