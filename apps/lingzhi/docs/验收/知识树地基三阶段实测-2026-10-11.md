## 现在生成到了什么程度

Python 的实际分类为：

```text
列表赋值与引用共享
├─ 列表赋值不复制
├─ 共享列表内容修改同步
└─ 变量重新绑定独立性
浅拷贝机制
├─ 外层对象特性
│  └─ 浅拷贝外层独立性
├─ 嵌套元素行为
│  ├─ 嵌套元素共享引用
│  ├─ 共享内层修改同步
│  └─ 浅拷贝元素重新绑定独立性
└─ 浅拷贝创建新外层
```

这保留了模型实际归属，尚未将“创建新外层”人工挪进外层子类。一个具体叶子是：

- **名称**：浅拷贝元素重新绑定独立性。
- **核心结论**：替换浅拷贝列表 `b` 的元素引用，只改变 `b` 的该引用，不改变原列表 `a` 的对应元素。
- **条件**：`b` 是 `a` 的浅拷贝，操作为给 `b[i]` 赋一个新列表。
- **元问题**：将浅拷贝列表中某个嵌套元素替换为新列表，原列表的对应元素会变吗？
- **原文**：M2“对浅拷贝的b[0]重新赋一个新列表，只改变b的该元素引用，不改变a[0]。”

微积分已将四个方向分别生成：可导→连续、不连续→不可导、连续不能推出可导、不可导不能推出不连续。历史已把“一手不保证客观”“有立场不等于无价值”“转载不独立”分别作为规则，A/B/C放入案例附件，没有再次将案例事实与通用规则混成叶子。

## 明确剩下的修改

- **Python**：P4仅保留“新建外层”，将元素引用交给P6；补足实际支撑引用；把P4/P5放在同一外层分类下。“b是列表变量”的条件也应避免被读成b必须事先存在。
- **微积分**：把范围P1转为全局元数据，并让独立展示的叶子继承内点、双侧及有限导数限制；将P8“不可导不包含不连续”改为“仅知不可导不能推出不连续”。
- **物理**：将P1的大小、方向、受力对象拆为三个判断，将P2的等质量/静止拆开；平衡元问题明确只问受力对象这一必要条件；重要加速度边界不能在展示时省略。
- **历史**：分开观察/推断区分与论证要求、来源独立性与可比性、数量投票与预设立场；将“可信度强度”“数量与强度对应规则”收回到原文的结论支持边界，保留不确定性；P8移入互证与矛盾处理类。

这些是本轮复核发现的待修订项，尚未偷偷改入原始结果。下一轮可按具体字段和拆分意图处理，无需重新扩展教学包。
