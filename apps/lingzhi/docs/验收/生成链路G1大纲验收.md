# G1 大纲生成收敛验收

日期：2026-10-05。改造前源码：`0c8faaa0`。范围为[生成链路收敛](../../../../changes/生成链路收敛.md)的 G1；这是代码、隔离测试及小样本实测记录，不是整套生成链或生产发布验收。

## 行为与退出结果

- 默认 `outline_mode=full`，原 `CourseService` 一次请求返回完整课程字段和全部讲次；任务直接完成，不强制等待方案确认。
- 主动选 `plan_first` 才先生成标题、简介并等待；继续使用原 task/job 和教师编辑过的方案，再一次展开完整大纲。恢复保存使用原响应检查点，不能另建课程或自动跳到教案/讲义。
- 本地检查讲次身份、课程目标与成果关联、模块覆盖、考核权重、逐讲必需字段及总学时。原自动编辑器中的确定性学时分配移入本地编译：按模型分配比例配平总学时并记录调整；教师已填写的分配固定不动；无法满足约束时停止。
- 删除教师 course-contract/detail-batch 的模型提示词、逐讲并行 executor、详情批次配置、专属规范化/预览函数及默认两轮自动优化器。保留正式 schema 的本地投影、教师主动修改与只读历史判定。灵知旧整课执行仍属于 G5，不能宣称灵知所有旧入口均已退出。范围已于 2026-10-06 纠正为仅灵知，启智不纳入后续改造。
- 每次 provider 调用最多一次底层尝试；结构错误最多一次修复，携带原结果与错误，单独计数；断流不自动追加请求。流式预览不能冒充已保存大纲。开始实际请求后才计算活动期限，队列等待不占期限。
- 增加输入、输出和安全余量合计检查；当前 tokenizer 计数仍为估算，结果明确标识。没有宣称取得模型匹配的精确 tokenizer。

## 服务能力与真实调用

只读 `/v1/models` 返回 `qwen3.8-27b`，`max_model_len=131072`。当前应用有效输入预算为 16,000 tokens / 32,000 字符，完整大纲请求输出预算 16,384 tokens，活动总期限 600 秒，连续无输出期限 90 秒。代码默认上下文设置与当前服务一致，并允许部署覆盖，预留 1,024 tokens。

16,384 是请求预算；本次并未探测服务最大单次输出，也没有证明可以稳定生成 32,000 tokens 或千讲大纲。模型输入估算和 provider 实际 tokens 分别记录。实测进程禁用了本地残留的外部文本回退配置，仅访问项目指定千问，不改写本地 `.env` 或生产配置。

输入取自[固定输入](../评测/课程与课件样例/生成链路收敛/固定输入.json)中的 `statistics_basic`：标题、学习者、合成来源和要求，总计 2 讲、2 学时；以 requirements 提供来源，未测试上传解析，也未执行教案/讲义的知识检查。串行运行，每轮独立临时课程。
