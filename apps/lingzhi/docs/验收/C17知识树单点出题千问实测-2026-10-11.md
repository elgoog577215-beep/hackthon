### K-T09 显式转换的位置

C语言中，算术运算符两侧的实参在运算前会进行类型统一（通常算术转换）。显式类型转换（如 `(type)表达式`）只应用于括号内或紧随其后的具体子表达式，不会改变运算符本身的类型属性，也不会影响表达式的整体求值顺序。

考虑以下代码片段：

```c
#include <stdio.h>

int main() {
    int a = 7;
    int b = 2;
    double result = (double) a / b;
    printf("%g\n", result);
    return 0;
}
```
在上述代码中，显式类型转换 `(double)` 实际上优先作用于哪个操作数？请选择最准确的描述。

- A. 作用于第一个操作数 `a`
- B. 作用于第二个操作数 `b`
- C. 同时作用于 `a` 和 `b`
- D. 作用于整个表达式，不改变任何单个操作数的类型

模型答案：**A**。本轮复核：**降为提示练习并修订解析**。题干已给出显式转换只作用于具体子表达式的规则；解析称“改变了a的类型”，应说明转换的是表达式所得值，变量a仍为int。
