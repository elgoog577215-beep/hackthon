# 课程读取性能与错误恢复

本轮处理课程工作台、知识树、发布面板的重复历史复制，以及前端读取与错误恢复状态。没有修改课程正文、题目答案、生成准入、任务恢复规则或正式学习记录。

## 根因与改动

真实样例的教师资产文件约 121 MB，其中包含历次教案、讲义、PPT 和冻结生成输入。普通页面读取调用完整资产 `load()`，状态编译还会深复制任务中的冻结正文。并行读取争用课程锁和 Python 执行时间，造成页面超时；健康接口仍然正常。

- 正文、知识树和可发布 PPT 清单通过原仓储 `read_projection()` 读取所需状态，不复制完整历史。返回正文及候选仍与仓储隔离，历史文件不改写。
- 生产状态编译只增加任务所属来源标记，读取嵌套状态，不复制冻结输入或生成正文。
- 工作台后台只补摘要；进入具体讲次按现有接口读取该讲，题库入口不加载全部讲次正文与 PPT 历史。
- 题库首次加载、读取失败、确实为空互斥展示。读取失败可直接重试，已有题目刷新失败时仍可阅读。
- 成功重试同一 GET 后清除对应错误提示；匹配课程地址、参数、身份范围和用户，较旧请求不能清除较新错误。GET 成功不清除保存或生成失败。

## 验证结果

| 检查 | 结果 |
| --- | --- |
| 修复前真实 API：讲次摘要 | 约 2.29 秒 |
| 修复前真实 API：课程题库 | 顺序读取约 4.34 秒，并行约 6.06 秒；浏览器多项读取同时执行时出现超时 |
| 修复后真实资产直接调用：正文投影 | 热读取约 0.036 秒，正文结果与原路径相同 |
| 修复后真实资产直接调用：生产状态 | 约 0.001～0.002 秒 |
| 学生课程正文、题库、历史、笔记、学习衔接、反馈 API | 均返回 200，约 0.19～0.59 秒 |
| 真实教师预览 AI 流式回答 | 首个回答约 4.29 秒，约 12.84 秒完整结束，无流式错误，不写正式学习记录 |
| 后端相关回归 | 362 项通过 |
| 前端相关回归 | 261 项通过 |
| 前端类型检查与构建 | 通过；本地运行副本的类型检查亦通过 |

后端回归覆盖正文来源变化、教师预览隔离、知识树候选隔离、发布与 PPT 私有内容过滤、任务恢复与旧版本保护。前端回归覆盖讲次切换、题库加载和重试、结构化错误、请求身份与错误清除范围。

## 运行验收边界

上述修复后投影耗时来自真实资产的直接调用，不是运行中旧后端的 HTTP 耗时。代码已准备好，仍须加载至本地教师和学生后端，再验证页面并发读取、刷新、师生发布和反馈。本地重载脚本先校验备份、文件摘要、服务身份和活动任务；有活动任务时拒绝停止服务。

本轮不重启 Qwen，不改变其上下文设置。样例中待刷新的知识树和 PPT 继续显示真实来源状态，不能因历史文件存在就标成当前可发布版本。整课生成、新版本发布及采用需要按各自产物合同另做真实验收，不能用本轮性能回归替代。
