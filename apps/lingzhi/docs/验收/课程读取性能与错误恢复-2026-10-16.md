# 课程读取性能与错误恢复

本轮处理课程工作台、知识树、发布面板的重复历史复制、手动保存阻塞服务，以及前端读取与错误恢复状态。修复已加载到本地教师和学生后端，并完成真实接口、页面和学习闭环验收；未部署生产环境。

## 根因与改动

真实样例的教师资产文件约 121 MB，其中包含历次教案、讲义、PPT 和冻结生成输入。普通页面读取调用完整资产 `load()`，状态编译还会深复制任务中的冻结正文。并行读取争用课程锁和 Python 执行时间，造成页面超时。手动保存还在异步路由中同步执行大文件处理，保存期间健康接口也会超时。

- 正文、知识树和可发布 PPT 清单通过原仓储 `read_projection()` 读取所需状态，不复制完整历史。返回正文及候选仍与仓储隔离，历史文件不改写。
- 生产状态编译只增加任务所属来源标记，读取嵌套状态，不复制冻结输入或生成正文。
- 工作台后台只补摘要；进入具体讲次按现有接口读取该讲，题库入口不加载全部讲次正文与 PPT 历史。
- 题库首次加载、读取失败、确实为空互斥展示。读取失败可直接重试，已有题目刷新失败时仍可阅读。
- 成功重试同一 GET 后清除对应错误提示；匹配课程地址、参数、身份范围和用户，较旧请求不能清除较新错误。GET 成功不清除保存或生成失败。
- 手动保存教案与讲义使用同步路由，由框架在线程池执行；响应仅投影目标讲次，大纲版本一致时不重复设置。资产写入使用紧凑 JSON 一次编码写入，仍保留原有临时文件、刷盘、原子替换和完整历史。

## 运行验收边界

本地重载前已核验仓库外备份、文件摘要、服务身份和活动任务；无活动任务后重载教师及学生后端，保留 Qwen 进程与配置。以上 HTTP 和手动保存耗时均来自重载后的真实服务。本轮浏览器中的教师、学生页面未发现控制台错误。

样例第一讲此前已改为实践操作并调整环节顺序，旧教案和讲义来源因此过期。通过原有领域服务和保存接口对齐当前安排，保留教师选择、正文和历史版本；现在六讲教案及讲义均为当前来源，页面显示 6/6。

在既有发布版本上真实完成：答错得 0 分并进入错题本，针对该次作答再练得 100 分后移出待巩固列表；两次作答反馈到达教师，学生也收到教师回复。验收新增两次正式作答和一条明确标注的联调提问，原有三次作答与私人笔记完整保留。既有发布版本的六份 PPT 共 204 页均下载成功，大小、摘要和压缩包校验通过。

本轮不重启 Qwen，不改变其上下文设置。当前验证的学生发布版本保留原内容，并非最新教师草稿的重新发布。新版整课知识树仍受上下文容量限制，部分讲次尚未生成；教师 PPT 也需按更新后的教案、讲义重新确认内容稿并渲染。页面保留真实来源状态，不能因历史文件存在就标成当前可发布版本。新版整课生成、发布及学生采用尚未完成，不能用本轮性能和既有发布版本验收替代。

## 学生过期会话恢复

再次启动验收时，学生会话自然过期。前端将过期凭据附加到登录配置和登录请求，中间件提前拒绝请求，页面因未读取到配置而误报本地登录未启用。公开的登录配置、登录及注册请求现在不携带旧会话；受保护的数据请求仍携带会话并拒绝过期访问，不放宽服务端权限。

真实浏览器已恢复登录表单，使用原测试账号重新登录后回到原授权课程，学习现场显示已同步。新增三项接口回归，连同学习空间、身份范围和 HTTP 身份测试共 27 项通过，前端类型检查通过。此次恢复无需重启后端或修改账号、课程及记录。
