## 原因与处理

原讲义回调在事件循环内调用同步仓储。实际课程文件约 85 MB，单次保存中位 1.859 秒；周期检查点以开始时间计算，保存本身接近周期时持续触发写入，健康检查、状态和任务请求一起受阻。

处理后的责任如下：

| 环节 | 责任 |
| --- | --- |
| 模型接收 | 更新原任务的短锁接收缓冲，不等磁盘或课程锁 |
| 流式投影 | 每个任务一个执行中的投影、一个可替换的最新快照，不累计 token 保存队列 |
| 持久化 | 在工作线程调用原仓储，沿用课程锁、原子文件替换与正式内容身份 |
| 完成与失败 | 先等正在执行的投影写入结束，再保存结果或终态 |
| 暂停与取消 | 保存尚未投影的最新接收文字；重复取消仍等待在途事务，不遗留晚到写入 |
| 显式继续 | 核对原任务与冻结输入，只补缺失范围或恢复已收到结果，不自动重跑模型 |

真实输出另暴露了标题公式跨 JSON 编码边界的问题：未转义的 TeX 反斜杠既可能触发解析失败，也可能被当成制表符等 JSON 转义。公共教学块解析器现只规范化标题明确数学范围中的转义，保留正文、身份、重复键和引用检查。已转义的数学不重复转义；普通文字及身份中的无效 JSON 不放行。
