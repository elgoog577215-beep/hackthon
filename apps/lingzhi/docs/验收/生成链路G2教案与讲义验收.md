## 多小节与失败记录

同一固定案例的均值与中位数小节合为一讲，另做多小节实测。教案 2 次物理请求（主请求 1、结构修复 1），214.67 秒，正式保存成功。讲义 1 次请求，70.27 秒，模型在第一节后提前插入整讲结束标记；即使后面仍输出第二节并返回 stop，也因协议错误未发布。失败正文保留。

修改提示词后，将上述失败任务及其教案修订恢复到隔离仓储，以原 job ID 主动继续：1 次物理请求，模型耗时 73.63 秒，两个小节完整解析并正式保存；估算输入 25142 tokens、输出 6270 tokens，完成原因 stop。原失败尝试和调用记录仍在任务历史中。这个多小节案例合计教案 2 次、讲义 2 次（首次失败 1 次＋主动继续 1 次）。这是隔离检查点恢复与真实模型证据，不是真实进程终止或生产恢复实验。

前置调试三轮全部保留：第一轮教案成功，讲义标记 ID 前空格导致结构拒绝；第二轮教案结构修复所带原响应超过首次请求输入预算；第三轮教案成功，讲义被旧的逐块输入预算拦截，模型调用 0 次。修正为本地去除 ID 两侧空白、修复请求单独计算原响应预算、整讲输入预算 32768 tokens / 64000 字符、输出 16384 tokens。所有请求仍检查输入＋输出＋余量不超过 131072 上下文，不静默丢弃来源。

多小节失败后进一步明确提示词：按列出的既有小节标记顺序输出，整次只允许最后一个结束标记；解析器仍拒绝提前结束，不通过放宽准入掩盖错误。

## 团队复验

从应用目录运行现有 `scripts/teacher_generation_benchmark.py`。用 `--stage outline --case statistics_basic --runs 3` 生成隔离大纲，取返回 `runs[i].result` 保存为合成大纲 JSON；再运行：

```sh
python scripts/teacher_generation_benchmark.py \
  --app-root "$PWD" --env-file .env --stage g2 \
  --course-json /tmp/accepted-synthetic-outline.json \
  --runs 3 --output /tmp/g2-evaluation.json
```

环境值由维护者按 README 提供。基准脚本仅使用临时数据目录，输出必须在仓库外。不要把用户课程或含凭据的环境文件作为共享评测附件。
