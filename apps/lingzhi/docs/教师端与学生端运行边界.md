# 课程工作区统一与兼容边界

> 文档状态：当前运行边界说明
>
> 核验日期：2026-09-04

## 1. 当前结论

灵知不把“教师端”和“学生端”做成两套课程产品。教师在文件空间管理大纲、教案、正文、练习、资料和 PPT；学生学习现场在运行时读取同一 `course_id` 下的 `CourseDocument + CourseBlock[]`、正式题目和教学表达。

角色与权限仍然存在，但角色差异应表现为操作权限、默认入口和可见动作，不应再复制课程库、课程外壳、生成状态或正式资产。

## 2. 活动入口

| 入口 | 用途 |
| --- | --- |
| `/courses` | 教师首页：我的日历 / 我的课程双入口；日历与完整课程库分别呈现 |
| `/course/:courseId/workspace/setup` | 课程文件空间：目录树、当前文件、文件详情与教师智能体；`setup/build` 只是兼容实现名 |
| `/course/:courseId/learn/:nodeId?` | 正式学习现场：目录、正文、练习、笔记、AI 老师、错题与进度 |
| `/course/:courseId/learn/:nodeId?teacherPreview=1` | 学生视角预览：复用完整学习现场，但使用教师预演身份并可原路返回 |
| `/course/:courseId/ppt` | 同源 PPT 专用工作台 |

旧 `/teacher/courses` 和 `/teacher/course/:courseId/...` 已退役，不再注册兼容地址；现役页面只生成上表路由。

## 3. 共享真源与术语

- 文件空间中的大纲、教案、正文、练习和配套 PPT 是固定资产位，不是重复顶层 Tab。
- 文件单击只选中并更新右侧详情，双击或右侧主操作才打开、生成或编辑；文件夹单击直接进入。
- 教学设计的全课视图读取 `CourseTeachingPlan.overall`，分小节视图读取 `CourseTeachingPlan.sections`。
- “教案”指当前、结构可用且来源未过期的分讲教案，不再存在人工确认指针。
- 大纲继续来自生成工作区蓝图或 `CourseDocument` 投影。
- 练习继续使用正式题目、尝试和诊断状态。
- PPT 继续使用来源绑定的 `TeachingRepresentation / SlideDeckSpec`。
- 资料包保存稳定 `course_id`，默认按 `owner_id + course_id` 查找；课程标题不是长期关联键。
- 教师首页、课程文件空间与带 `teacherPreview=1` 的学习现场使用稳定教师工作身份；普通学习入口继续使用学习者身份。
- 学生视角预览产生的笔记、进度、作答和 AI 对话只属于当前教师预演身份，不读取或写入真实学生记录。

`TeacherLessonAuthoringRepository` 保存分讲教案、讲义当前修订和 AI 候选；`CourseDocument + CourseBlock[]` 保存学生学习正文。两者不得互相回填或伪装成对方的当前产物。

## 4. 性能边界

统一工作区首屏只阻塞课程主干和当前子模块。资料、日历、大纲与教学方案在首次打开时加载；同一课程内已打开的模块保持挂载，避免切换时重复读取整套课程、任务、教案、PPT 和发布状态。正式课程的学习资产、记录、进度与 AI 会话并行读取。

后台任务轮询属于全局生成状态投影，不得触发整页遮罩或重建当前模块。

## 5. 剩余兼容边界

1. 无 `course_id` 的旧资料包只能在当前 owner 下存在唯一同名候选时兼容绑定；多个候选必须人工选择。
2. 学生历史课程、PPT 独立版本和学习记录仍按各自合同保留，不属于旧教案历史。
3. 正式身份、RBAC、组织和班级发布关系仍是后续权限合同，不能用当前本地教师身份代替。

## 6. 删除完成门

旧教师页面、兼容路由、人工确认 API 和教案历史恢复已从源码删除。现存数据只能由一次性工具先在仓库外备份，再删除旧整课工作台包、确认字段和旧导入修订；不得删除学生课程、学习记录或 PPT 独立真源。
