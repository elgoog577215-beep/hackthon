# 灵知

1. **入口**：[README](README.md)提供运行与测试，[产品蓝图](docs/产品蓝图.md)与[产品状态](docs/产品状态.md)说明设计及差距；仓库与部署要求见[根规则](../../AGENTS.md)和[发布说明](../../deploy/README.md)。设计与实现状态分别维护，历史材料不直接作为当前需求。
2. **课程与权限**：教师备课和学生学习共同构成闭环；每门课程只有一份正式正文和一个写入拥有者，不建平行 Store 或任务系统。`LearningEvent` 保存事实，`LearnerModel` 可重算；预览不写学习记录，正式修改校验权限并保护旧笔记、作答和题目修订。学生可创建和修改自有课程，不能覆盖未获编辑授权的教师正文。
3. **教学与生成**：新课程层级为“课程 → 第 N 讲”，讲义是教材式材料；教学分类与术语沿用正式设计。讲义只检查结构与来源，不追加内容审核、模型改写或失败自动重跑；保留完成块，由有权限的发起者继续缺失块。 PPT 内容稿独立确认，最终渲染不重新生成知识；产品内 AI 修改通过领域命令保留范围、影响、用户决定、回执和恢复。
4. **模型与任务**：文本模型只用自建 `qwen3.8-27b`，不接外部兜底；联网来源冻结，未经授权不启用、扩展或删除。操作前核对工作树、服务、课程及占用；其他任务使用的课程只读，不另起同目标任务或通过重启绕过保护。任务用真实 task/job ID、单一同步入口管理，关闭页面不终止任务；暂停、取消或来源冲突不自动继续，恢复实验使用隔离数据。
5. **界面与验收**：保持蓝紫视觉、共享组件、连续阅读布局和中英文；当前只做桌面端，教师正文与常用操作原则上不低于 15px。按影响验证师生流程、权限和恢复；完整后端回归分开运行 `pytest backend/tests` 与 `pytest tests`，模拟、真实模型、浏览器与生产证据分别报告。
6. **部署与维护**：正式数据迁移使用显式工具和可恢复备份，部署不顺带迁移课程；保护拓途主站与独立应用，分别验证 SPA 和哈希资源缓存。遵循根目录提交发布要求，不自动生成事实日志、经验或规则。
