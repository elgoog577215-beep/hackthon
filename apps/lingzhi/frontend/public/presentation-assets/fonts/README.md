# 教学 PPT 字体

`NotoSansCJKsc-Regular.otf` 为 Noto Sans CJK SC Regular，字体内部版本为 `2.004`。

- 上游：[Noto CJK Sans2.004](https://github.com/notofonts/noto-cjk/tree/Sans2.004)
- 原始文件：[SimplifiedChinese/NotoSansCJKsc-Regular.otf](https://raw.githubusercontent.com/notofonts/noto-cjk/Sans2.004/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf)
- SHA-256：`2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`
- 许可：同目录 `OFL.txt`，SIL Open Font License 1.1；许可原文来自上游 `Sans/LICENSE`。

页面预检、浏览器预览和 LibreOffice 渲染使用这个文件。PPTX 保存可编辑文字和字体名称；接收电脑也需要安装该字体才能稳定复现排版，当前输出器不声称已经把字体嵌入 PPTX。

更换字体或测量工具后必须重新测量并认证模板。公式当前以经过转换和来源核验的可编辑符号文本输出，不声明为 PowerPoint 原生公式对象；不支持的 LaTeX 命令在内容稿预检阶段报错。
