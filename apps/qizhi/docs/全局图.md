# edu_ai_home · 全局图（项目全景）

> **维护规则**：本文件是项目的"活地图"。**每次改动代码（功能、接口、数据模型、部署、外部依赖），都要在同一个 commit 里同步更新本文件对应章节**，并在末尾「变更记录」追加一行。改了代码不改这里 = 改了一半。

启智主平台代码位于统一 GitHub 仓库的 `apps/qizhi/`，灵知课程子应用位于 `apps/lingzhi/`，联合部署配置位于 `deploy/zju/`。联合作业入口为根目录 `scripts/qizhi.sh`；部署与私有配置见[接入与部署说明](./灵知新版课程接入与部署.md)。

---

## 一句话定位

面向高校教师的 **AI 教学助手平台**（浙大 ZJU 场景）：以「课程 → 大纲 → 教案 → PPT / 题库」的**版本化资源**为骨架，自建 vLLM(Qwen) 集群驱动 AI 生成与对话，集成超星 / 智云课堂视频分析、论文检查微服务，带完整 RBAC + 取证级审计。

## 系统拓扑

```
浏览器 (Vue3 + TS + Vite + Pinia + vue-router)
   │ /api/*  （开发走 vite 代理 / 生产走 Nginx 反代，去掉 /api 前缀）
   ▼
FastAPI 后端 :8000  (async, uvicorn 多 worker)
   ├─ 13 个带前缀路由模块（ai/user/course/feedback/resource/session/video/auth/essay/agents/admin/audit/document）+ common(无前缀) → Service 层 → SQLAlchemy(async) ─▶ PostgreSQL 17
   ├─ AI Agents 层  (ReAct 对话 + 4 步精炼流水线)
   ├─ 异步任务队列  (task_queue 表 + Worker；视频分析串/并行)
   ├─ 运维探针  /api/version（部署校验，main.py 直挂，返回版本串 + status）
   ▼  外部依赖
   ├─ vLLM 集群（地址由环境变量提供） 文本(qwen3.8-27b) / ASR(Qwen3-ASR-1.7B)  【6×A800，多实例负载均衡】
   ├─ essay-check 微服务（ESSAY_CHECK_SERVICE_URL）  （论文 / 作文检查）
   ├─ 超星 Chaoxing / 智云课堂  （课堂视频导入 + 分析，HMAC 签名）
   ├─ ZJU OAuth  （统一身份登录，签发 JWT，3 天过期）
   └─ Dashscope（RAG 知识库）/ 阿里云 SLS（日志汇聚）

部署：Docker Compose 四服务 = server(FastAPI) + db(Postgres17) + website(Nginx) + lingzhi(根目录课程应用)
```

## 核心抽象：版本化资源模型（整个产品的中枢）

```
Course 课程 ──< CourseUnit 单元(树, parent_unit_id)
   └─< Resource 资源   ← 一张表四种类型，用父子链表达层级
        resource_type : OUTLINE → TEACHING_PLAN → PPT / QUESTION_BANK
        parent_resource_id : 子版本指向父（教案→大纲，PPT→教案）
        version_number : 按 (creator, course, type) 作用域自增 (v1/v2/…)
        唯一约束 uq_resources_root_scope_version（parent 为空的根资源）
```

前端层级页面：`MyCoursesView → CourseView → OutlineDetailView → PlanDetailView → ResourceView`，
用 `HierarchyStepper`(面包屑) + `CollapsibleSection`(可折叠版本列表) 表达层级。

## 角色与权限（RBAC）

`admin`（白名单 `ADMIN_ZJU_IDS`，启动回填）⊃ `teacher` ⊃ `student`（新用户默认）。
后端守卫：`get_current_user`（全员）/ `get_current_teacher`（教师+admin）/ `get_current_admin`（仅 admin）。
审计：`audit_logs` 取证级流水，8KiB 截断 + PII 脱敏；前端路由守卫按 `requiredRoles` / `admin` 拦截。

## 技术栈

- **后端**：FastAPI + SQLAlchemy 2.0(async) + asyncpg + PostgreSQL 17 + asyncio 任务队列
- **AI**：vLLM（OpenAI 兼容）Qwen3.6-35B-A3B（文本）/ Qwen3-ASR-1.7B（语音）
- **前端**：Vue 3 + TypeScript + Vite + Pinia + vue-router；SSE 流式消费；MD/KaTeX 渲染
- **部署**：Docker Compose（server + db + website-nginx）；ZJU OAuth(JWT) 认证
