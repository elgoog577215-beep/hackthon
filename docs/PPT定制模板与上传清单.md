# 课程 PPT 定制模板与上传清单

## 一、启智课堂模板清单

一套可稳定生成课程 PPT 的主题至少应覆盖以下 18 类页面。模板名称是语义角色，不要求教师按固定顺序使用。

| 序号 | 模板角色 | 主要用途 | 推荐背景 |
| --- | --- | --- | --- |
| 01 | 课程封面 | 课程名、副标题、主视觉、授课信息 | 封面主视觉 |
| 02 | 课程路线 | 章节或学习路径 | 通用内容背景 |
| 03 | 章节转场 | 章节编号、核心问题、本章主线 | 章节主视觉 |
| 04 | 核心判断 | 一页一个重要结论 | 通用内容背景 |
| 05 | 学习目标 | 问题、知识目标、能力目标、评价标准 | 通用内容背景 |
| 06 | 概念定义与边界 | 正式定义、成立条件、正反例 | 通用内容背景 |
| 07 | 方法流程与推导 | 步骤、顺序、解题过程、思维链路 | 推演背景 |
| 08 | 图文解释 | 图片、示意图与解释文字 | 证据背景 |
| 09 | 误区修复 | 错误判断、原因、正确路径 | 练习背景 |
| 10 | 课堂练习 | 问题、提示、作答要求 | 练习背景 |
| 11 | 答案与反馈 | 答案、判断依据、评分标准 | 练习背景 |
| 12 | 代码/公式 | 高对比证据区和低负担解释区 | 证据背景 |
| 13 | 并列示例 | 正例、边界例、迁移例 | 通用内容背景 |
| 14 | 表格/图表证据 | 数据、对照表、图表与结论 | 证据背景 |
| 15 | 应用映射 | 将概念或方法映射到真实情境 | 通用内容背景 |
| 16 | 来源附录 | 引用、数据出处、素材说明 | 通用内容背景 |
| 17 | 章节回顾 | 提取问题、知识路径、关键结论 | 复盘主视觉 |
| 18 | 课程收束 | 课程主线、迁移建议、结束信息 | 复盘主视觉 |

## 二、文本框样式清单

主题至少需要定义以下可复用文本框样式。文本框应保持可编辑，不应把文字烘焙进背景图。启智课堂统一采用“前层纸卡 + 轻微错位底板 + 柔和投影 + 顶部高光 + 语义色标记”的浅立体结构。

| 样式 | 语义 | 启智课堂处理 |
| --- | --- | --- |
| Standard | 普通正文、列表 | 白色纸卡、蓝灰错位底板、轻投影 |
| Message | 核心判断、关键提示 | 浅蓝纸卡、蓝色竖向强调线、顶部高光 |
| Definition | 定义、正式表述 | 白底、蓝色标记 |
| Boundary | 条件、边界、正向反馈 | 浅薄荷底、绿色标记 |
| Reasoning | 推导、步骤、过程 | 极浅蓝底、路径型编号 |
| Practice | 问题、任务、检查项 | 浅琥珀底、橙色标记 |
| Feedback | 答案、判断依据 | 浅薄荷底、绿色标记 |
| Misconception | 错误观点、风险 | 浅红底、红色标记 |
| Evidence | 代码、公式、关键数据 | 深蓝高对比纸卡、深色底板 |
| Note | 备注、来源、补充说明 | 中性浅灰白底 |

## 三、生成定制 PPT 需要上传的内容

### 最小可生成包

只要具备以下内容，就可以生成结构完整的课程 PPT：

1. 课程正文：PDF、DOCX、Markdown、TXT 或已有 PPTX，至少包含清晰的章节结构。
2. 课程名称。
3. 授课对象：例如小学五年级、大学一年级、企业新员工。
4. 课时或目标页数：例如 45 分钟、约 16 页。
5. 选择主题：例如“启智课堂”。

### 推荐教学包

若希望结果更接近可直接授课版本，建议同时上传：

1. 教学大纲或章节目录。
2. 学习目标、能力目标和评价标准。
3. 必讲概念、重点、难点及常见误区。
4. 示例、案例、练习题、参考答案和评分标准。
5. 公式、代码、表格和图表的原始文件；数据优先使用 XLSX/CSV，不要只上传截图。
6. 图片、示意图、实验照片或产品截图的原图。
7. 引用来源：教材名称、页码、论文 DOI、网页链接或数据集说明。

### 品牌定制包

若希望生成机构或个人专属风格，还应上传：

1. Logo：优先 SVG 或透明 PNG，建议同时提供深色版和浅色版。
2. 品牌色：主色、辅助色、强调色的 HEX 值。
3. 字体：字体名称；若必须使用非系统字体，可上传有合法授权的 OTF/TTF 文件。
4. 参考模板：一份代表期望风格的 PPTX，建议至少包含封面、普通内容页、章节页、图表页和结束页。
5. 视觉参考：2–5 张高质量参考图，注明“仅参考风格”或“必须使用”。
6. 页眉页脚要求：机构名、课程编号、保密标记、日期、页码格式。
7. 固定文案：版权声明、免责声明、讲师信息或联系方式。

## 四、推荐上传目录

```text
课程名称/
├─ 01-课程正文.pdf
├─ 02-教学大纲.docx
├─ 03-练习与答案.docx
├─ 04-数据表.xlsx
├─ brand/
│  ├─ logo-dark.svg
│  ├─ logo-light.svg
│  ├─ brand-colors.txt
│  └─ fonts.txt
├─ images/
│  ├─ chapter-01/
│  └─ chapter-02/
├─ reference/
│  └─ 参考模板.pptx
└─ sources.txt
```

## 五、上传时应明确的使用规则

- 哪些内容必须原文保留，哪些内容允许压缩改写。
- 哪些图片必须使用，哪些图片只用于风格参考。
- 是否允许自动生成补充插图。
- 是否需要教师讲稿、学生版课件或无答案版本。
- 是否需要中英双语、公式编号、代码高亮或特定引用格式。
- 是否包含未授权字体、图片或数据；系统不应默认获得第三方素材的再发布权。

建议网站最终将上传内容分成“课程内容、教学设计、视觉品牌、素材数据、输出要求”五个区域，而不是只提供一个文件上传框。
