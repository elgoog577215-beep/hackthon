## 1. 当前判断

灵知已经跨过功能原型拼装，课程数据和主要生成入口已经统一；当前重点是整理旧写入、补齐异常恢复，并用多学科真实课程检查生成质量。

课程生成、结构化课程、正式练习、学习事实、AI 老师、课程调整和 PPT 同源表达都已有真实代码与入口；当前主要问题不再是功能是否存在，而是异常恢复、修改影响计算和跨模块验收还未全部达到可发布标准。真实“微积分”课程已经贯通大纲、分讲教案、讲义、正式题库和教师学生视角预览，但一次数学课程成功不等于跨学科质量已经完成。

当前不能对外宣称“完整课程 Agent 已完成”，原因集中在四处：

1. 课程知识仍缺完整的独立修订仓库、知识命令，以及课程与知识双向变化时的影响计算和处理。
2. 课程生长已有样板纵向链，但完整操作代数、部分接受后的依赖重算、跨域恢复和广域真实验收仍在建。
3. 教师端产品路径已收束为“我的课程（默认）/ 我的日历 → 课程空间 → 学生视角预览”。新课程的正式层级只有“课程 → 第 N 讲”，知识点与教学块只存在于讲内；历史章/节课程保持兼容读取，不执行迁移。课程工作台主链为“大纲 → 教案 → 讲义 → PPT”，题库、教学日历、评分细则和自查清单归入其他课程文件。大纲、教案和讲义已经删除人工确认门：结果非空、结构可用且来源未过期，就成为当前可编辑修订并开放下一步；审阅报告只供参考并由低强调按钮打开弹窗。大纲现在按“课程表单 → 可编辑轻量课程方案并停留 → 教师明确继续后先生成课程级正式合同，再生成逐讲详情并汇编完整大纲”运行；逐讲详情和全课教案均把全部讲次一次入队，由统一容量并发调度并按讲独立流式、失败与重试。教案入口先显示当前大纲的全课同源预览，不重复课程表单或强制步骤条。左栏使用一级阶段与逐讲阶段的双行讲次目录；右栏不再常驻 AI 助手和重复讲次列表，而是按生成前资料准备、生成中当前讲任务、生成后版本与依据切换。每份文件可独立设置全部讲次、连续范围或指定讲次，任务启动时冻结各讲资料范围；监听器不得自动继续、关闭编辑、切换阶段或重生成下游。课程联网来源当前冻结：前端不显示入口、不加载调研组件、不发送相关请求，后端不执行课程检索，历史来源不进入新的课程生成；实现代码和历史数据继续保留。课程级状态仍只显示“备课中 / 备课完成”，由当前大纲及所有计划讲次的当前教案、讲义和 PPT 确定性推导。
   准备弹窗和课程文件系统已共用正文解析与整批 AI 理解：同一工作包统一返回文档用途、课程/章节位置、版本角色和原件关系，并持久化依据、置信度、缺失材料、低置信结果与明确降级状态。现有解析管线已补齐旧 `.doc/.ppt/.xls` 隔离临时转码、扫描 PDF 本地逐页 OCR，以及 PPTX 对象位置、图表系列、讲者备注、图片数量/替代文本和动画存在性证据；原件保持不可变，无法确定的图片、复杂公式、动画和完整视觉语义只记录边界与降级警告。文件管理已补齐多选、批量移动、重命名、自定义文件夹管理和回收站；低频操作放在选中后的批量栏与右键菜单，被正式文件引用的原件仍禁止移入回收站。教师修正优先于后续 AI 批次；当前已用真实模型验证名称模糊的中文教案及同讲关系，跨学科、复杂扫描表格/公式和超大型文件包质量仍需继续验收。
   PPT 工作区按资料情况支持三种处理：当前讲义生成完成后即可进入 PPT；有主参考或参考资料但无 PPTX 时，用独立 `ppt-v6:{lesson_unit_id}` 关系保存本次资料，讲义仍是内容语义真源；已有 PPTX 时保留原件，对照当前大纲、当前教案、题库、讲义和 PPT 工作区资料生成审阅报告，不默认重生成整套 PPT。无原版 PPT 的内部生成仍分两步：第一步独立生成、完整展示并确认 `ppt_manuscript_v1`；第二步读取已确认的页面内容稿修订确定性生成 deck，不能再次调用内容规划器改写。页面内容稿质量门、上传 PPTX 的原件保护和 PPT 自身修订确认维持原合同；本轮只取消大纲、教案和讲义的人工确认门。
   生产 AI 修改已进入统一能力链：正式内容画布承载候选与高亮，助手在教师明确调用后分流含糊要求、当前对象小改与整课/跨资产修改，继续复用各资产候选接口和 `/evolution/course-plans`，不增加平行正式数据 Store、公开 API 或课程真源。现有前端仍把助手放在右侧栏；最终合同要求它退出生产右栏，只在教师主动调用时按需出现，既有方案、影响、采用、回执和撤销能力保持不变。教师全课要求可以编译为精确内容补丁或一次结构重建，并通过 `CourseEvolutionPlan` 返回 applied / failed / unchanged 回执；跨仓储写入不是单一数据库事务，部分失败必须保留 last-good，不能把预计影响冒充已应用结果。
   教案精确字段修改已经改为对象旁触发：输入框在字段或条目下方向下展开，字段候选在原位采用或保留原文，不再用整小节背景表示单处变化。请求以基础修订、小节、字段和教学块/列表条目身份锁定目标，并消费课程知识库的前置关系等局部知识上下文；服务端字段快速分支只要求模型返回一个 `value`，资料限制为相关片段，输出预算从整小节合同的 6000 tokens 降到 800/1600 tokens，并把 SSE 心跳和已等待时间显示在原位。整讲、跨对象和跨资产要求仍进入原助手或课程调整工作区。

4. 教学语义已经深化为“课程合同 → 讲次合同 → 教学块实施合同”：`学习目的 × 一级学科类型 × 课程教学类型` 形成整课结构，`本讲目标 × 本讲课型 × 学科规则 × 课程约束` 形成课堂主弧，每个教学块必须写清教师动作、学习者行动、学习证据、检查、反馈调整、进入支持与前后衔接。第三版统一语义编译器已接入 `subject_standard_pack_v1`，大纲、教案、讲义和题库共用学科标准包，PPT 只从当前讲义和课程块提取学习者需要看到的内容。新讲次式课程使用 `formal_syllabus_v2`，保存学习目标、育人目标、可测量结果、成果关联、结构化考核、知识模块、应用载体、拓展资源、学习任务和分类学时。大纲审阅改为不阻断下一步的参考报告，只保留低强调按钮并在弹窗展开；大纲手工保存或采用 AI 候选后，都会基于当前修订重审。大纲、教案和讲义都不提供历史浏览或任意恢复。教学日历与大纲导出继续读取同一结构；固定样本已经通过编译检查，但真实模型跨学科质量、历史兼容和生产导出仍需完整发布验收。
5. 产品还缺真实长期学习样本证明“课程调整后确实改善，失败时能够回退”。

本轮已建立服务端唯一 `course_production_state_v1` 纯投影：课程库、工作台、教学日历和课程文件都以它为状态权威；资产主状态只使用“未生成 / 生成中 / 可使用 / 生成失败”，暂停、过期、待核对和最近失败单独表达。二次真实缺口审计进一步把动作与任务身份纳入同一合同：每项写操作必须同时命中 `allowed_actions` 和对应 `action_targets`，教案、讲义与大纲恢复接口接收并校验精确 task ID，不再自行查找 latest job；未知、缺 ID 或不合法投影只读失败。教案和讲义默认只保留全课生成按钮，失败后原位变为“重新生成”并只恢复失败或缺失单元。历史章/节课程仍保持只读兼容，但已有非破坏性升级路径：只读预检并生成讲次映射，显式确认后在隔离工作区编译、验证，通过后才发布为新 course ID；旧课程 checksum 和历史不变，失败半成品不进入课程列表。这些能力已有合同、单元、并发和故障演练测试；但目前仍保留旧状态字段和单讲兼容能力，尚未完成生产观察与退场。只有经过至少一个完整生产观察周期，证明新旧投影差异和外部单讲调用均归零，才能删除旧推导和兼容路径。

大纲、教案与讲义已补充交付前自动修正：大纲修复全零学时阻挡详情并接入有限轮次优化；教案最终质量问题回到既有优化器；讲义语言建议与整讲重复、衔接和深度问题回到既有块修复。每次采用后按相同规则复验，未通过硬校验不写正式修订。新增链路验收与发布结果以本次执行记录为准。

本轮全局修改与失败恢复修复已在独立数据目录验收：入口直接进入修改中心，支持完整文本查找替换、明确讲次删除/移动、同讲教案到讲义候选、逐项回执和撤销；候选生成已接入持久任务，关闭页面与刷新不会取消。失败恢复区分按原要求续办与补充要求后新尝试，保留错误详情及最后可用正文。课程库保留“备课中 / 备课完成”，学生视角预览保留。轻量讲次方案完成但仍属于草稿时，继续生成完整大纲的入口已按服务端 provide_input 授权恢复。完整大纲步骤依据同一任务持久化的继续事实维持第三步，不因课程目标、考核方案等内部子阶段、暂停、失败或刷新退回第二步。真实指定模型与中文桌面连续流程已验证；PPT 改造未纳入此次范围。生产发布另行核对对应提交的 CI、部署回执与线上健康状态。

## 2. 成熟度口径

| 状态 | 含义 |
| --- | --- |
| 稳定基座 | 真源、写入链、异常合同和主要回归已经稳定，可被其他能力依赖 |
| 主链可用 | 正常路径已进入生产主链，仍有边界、兼容或完整验收缺口 |
| 样板可用 | 已有真实使用样板，但尚未覆盖任意范围、异常组合或大规模场景 |
| 在建 | 正在由活动 OpenSpec 实施，不能作为完成能力承诺 |
| 待验证 | 实现或设计存在，但缺真实用户、真实模型、长期效果或视觉证据 |

成熟度描述的是当前证据，不是百分比，也不替代 OpenSpec 任务状态。

## 5. 当前攻坚顺序

为 Mermaid 补一份固定导入回归样本，并在真实课程 UI 中确认标题、公式标签、错误降级和横向裁切。当前本地课程没有 Mermaid 图，不能用“页面能打开”替代这条验收；样本与 UI 证据齐全后再归档。

### 5.2 当前主攻

教师端三段主路径已经收束产品入口；当前主攻转为文件空间内的领域作者能力和兼容退场：

1. 已完成第一版新旧教学字段适配，继续补齐历史课程批量对账、回滚和全部兼容调用的来源记录。
