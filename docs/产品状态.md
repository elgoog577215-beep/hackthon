## 1. 当前阶段判断

灵知已经跨过“功能原型拼装”阶段，进入**统一真源后的主链收束期**。

课程生成、结构化课程、正式练习、学习事实、AI 老师、课程调整和 PPT 同源表达都已有真实代码与入口；当前主要问题不再是功能是否存在，而是这些能力的正式合同、异常恢复、影响分析和跨模块验收还没有全部闭合。

现阶段不能对外宣称“完整课程 Agent 已完成”，原因集中在四处：

1. 课程知识仍缺完整的独立修订仓库、知识命令和双向影响闭环。
2. 课程生长已有样板纵向链，但完整操作代数、部分接受后的依赖重算、跨域恢复和广域真实验收仍在建。
3. 教师端课程与教案生产工作台 V1 已进入实施；教案已形成可编辑纵向样板，但课程要求、目录、正文作者命令和完整下游重建仍未闭合。
4. 产品还缺真实长期学习样本证明“课程调整后确实改善，失败时能够回退”。

## 2. 成熟度口径

| 状态 | 含义 |
| --- | --- |
| 稳定基座 | 真源、写入链、异常合同和主要回归已经稳定，可被其他能力依赖 |
| 主链可用 | 正常路径已进入生产主链，仍有边界、兼容或完整验收缺口 |
| 局部闭环 | 已有真实纵向样板，但尚未覆盖任意范围、异常矩阵或规模化场景 |
| 在建 | 正在由活动 OpenSpec 实施，不能作为完成能力承诺 |
| 待验证 | 实现或设计存在，但缺真实用户、真实模型、长期效果或视觉证据 |

成熟度描述的是当前证据，不是百分比，也不替代 OpenSpec 任务状态。

## 5. 当前攻坚顺序

### 5.1 立即收尾

完成 Mermaid 已知导入样本的真实 UI 验收。该工作没有新的产品设计依赖，完成后应归档规格，减少活动变更噪音。

### 5.2 当前主攻

以教师端课程与教案生产工作台 V1 为当前总控，先收束其教案前置能力，再展开其他作者链：

1. 在已合并的课程生成与教案成果上，先交付简化填写/过程体验和正式教案默认视图。
2. 补齐教案模块增删排序、知识结构操作、字段级恢复，以及下游复用、过期、定向重建和失败保留状态。
3. 将课程依据高保真解析、两段式联网补证和课程局部知识图谱前移接入首次生成主链。
4. 扩展课程要求与目录结构命令，再接入正文作者命令和统一版本恢复。
5. 完成完整课程质量建议、真实模型性能、遥测、灰度、告警、回滚和多端纵向验收。

### 5.3 下一主链

教案工作台收束后，回到结构化自适应课程 OpenSpec 的前置缺口：

```text
课程知识独立修订与命令
-> 证据治理与来源回跳
-> 课程操作组和依赖索引
-> 任意范围课程生长
-> 独立效果复验
```

不能先扩张自主 Agent、自由多模态或新顶层入口，因为这些能力仍依赖上面的真源、命令和效果合同。

## 6. 横向风险

| 风险 | 当前控制 | 仍需验证 |
| --- | --- | --- |
| 平行真源复发 | 蓝图、状态、架构、OpenSpec 和历史归档分工；课程对象有唯一拥有者 | 新页面、Store、兼容 API 是否再次复制状态 |
| Demo 领先于产品 | Demo 必须走正式修订、表达编译和复验链 | 录屏专用数据是否被误述为生产普适能力 |
| 模型成功掩盖系统失败 | 检查点、硬预算、质量门、降级标记和最后可用产物 | 真实提供方限流、长时间生成和跨模型差异 |
| 测试通过掩盖体验问题 | 要求中英文、桌面、移动端和真实浏览器验收 | 活动 OpenSpec 中尚未完成的视觉与恢复门 |
| OpenSpec 长期膨胀 | 完成项归档，当前任务只在有效规格维护 | 大规格是否需要按前置完成门继续切分 |
| 有调整无效果 | 保存证据、修订和后续等待状态 | 长期样本、独立复验与失败回退 |

## 7. 状态更新门

只在以下情况更新本文：

- 能力首次进入正式主链。
- 主链从局部闭环升级为稳定基座。
- 关键缺口、风险或当前主攻发生变化。
- OpenSpec 新建、归档、替换或范围发生实质变化。
- 真实验证推翻原有完成判断。

普通提交、测试数量、Prompt 版本、单个 bug 和每日进度不进入本文。它们留在 Git、架构文档、OpenSpec 或验收记录中。
